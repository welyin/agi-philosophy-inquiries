# 00 知行闭环的分化与物质生成猜想

本专题考察一条生成顺序：一个知行闭环内先区分提出判断与接受检验的角色，一次交互可能留下可重遇的关系，之后其他反馈路径才可能利用它。多主体可以共同核查的物质性，仍是要解释的目标。

**当前研究问题。** 寻找一种知行闭环，给出可独立说明的内部更新规则、种子和成立条件，检验它自行运行后能否形成与我们宇宙相符的可观测结构和物理规律。这是一个构造性存在问题。其它闭环可以生成不同的世界。已有反例限定了哪些条件还允许竞争模型，可用来挑选和比较候选。各阶段分别登记输入了什么、运行产生了什么、哪些读数还能独立检验。现实宇宙是否采用这样的机制，取决于模型与观测的比较。

**当前候选定义。** 继承“区分、使用、返回、更新”。一项差异能改变对行动后果的预期，行动将可比较的证据带回，而不同证据可以改变下一轮的判断或行动。对分化后的整体使用同一个检验：原成员能够提出什么问题，整体能够发起什么行动，哪些返回会纠正这个整体？希望与他者建立关系是认知动机；哪些主体能发起复查、能读到什么证据、如何落实纠正，是待指定和检验的操作要求。[知行哲学稿](../../知行哲学研究/论文/从可理解性到操作关系——一种知行闭环的本体论建构（匿名修订稿）.md)

**反思。** 第 35—36 篇把自己的判断规则也列入对异常的候选解释。如果自己的证据同时允许“应当修正”和“应当保留”，可以找拥有不同干预权的主体共同复查，再用归因结果修正下一次行动。联合体必须能说明哪些来源的变化可以区分、哪些仍会同时骗过所有复查。两篇分别检验了复查动作稳定和有界数量端口可以改变的情形。这是对闭环能力的候选描述，尚未列为公理。
