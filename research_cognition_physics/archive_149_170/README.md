## 核心问题

在固定读取、消息和门预算中，如何认证完整恢复通道的最坏误差？

## 本段成果

- 将完整外部恢复误差化为低维Gram谱，区分局部代价之和与同一未知输入的真正损失。
- 用解析导数和区间覆盖认证全局误差；确定四角度类别的界，并构造跨类别改善及门成本。

## 适用范围

最优性只在明示恢复器类别或固定策略中成立，不证明复数表示的必要性，也不覆盖一般CPTP恢复器。
