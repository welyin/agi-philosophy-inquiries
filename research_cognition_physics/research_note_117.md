# 第一百一十七轮：更新策略、检查来源假设并回退

日期：2026-09-16

## 1 有限执行流程

本轮把第 116 轮变化约束变成可运行流程。源族和门不变，声明每次源准备的条件参数变化不超过 ℓ=1/4096。每批执行：

1. 新准备 512 份校准源，用原噪声实探针取得记录。
2. 更新这一批的平均条件参数区间，再加上到下一份源的变化预算 513/8192。
3. 只有未来参数整个区间位于 [0.1,R] 或 [−R,−0.1]，才启用对应增强策略；否则本次只查询 N。
4. 比较相邻两批区间是否与声明的变化速率相容。一旦发生冲突，后续全部增强查询锁定为基础查询，等待来源模型重新评估。
5. 共执行 8 批，每批之后做一次新 H 任务。锁定后仍按固定计划采完数据，以便审计，成本照计。

控制器只用实际记录、事先声明的变化界和预定窗口。真实来源路径只用于生成理论评估分布，不向动作选择器公开。

512 不是上一轮的 621 最优窗口；本轮固定同一批大小以核对整个流程，也没有优化不同检查阶段的窗口配置。

## 2 记录可以反驳来源假设，但不能证明未来稳定

设相邻两批平均参数的区间分别为 A=[a_-,a_+]、B=[b_-,b_+]。相等长度的窗口中心相隔 Δ 个源步骤时，变化约束意味着

\[
|\bar\kappa_B-\bar\kappa_A|\le\ell\Delta.
\]

若

\[
\boxed{\max(0,b_--a_+,a_--b_+)>\ell\Delta},
\]

则这两份区间与声明速率不相容。控制器保守地暂停增强查询。物理范围交集为空也触发锁定。

在所有置信区间覆盖各自平均条件参数的事件上，满足速率约束的来源不会被错误拒绝。因此整段流程的错误锁定概率不超过同一个总覆盖失败界 β≈0.00288515；审计不是额外偷偷花费的一套未计风险测试。

反过来，没有观察到冲突，不能证明未来一定遵守速率。突变也可能发生在最后一次校准之后。这正是第 115 轮过去不能单独决定未来的边界。

可复算拒绝例：两批各 512 次读取，正号数分别为 385、127，使用第 1、2 次检查的置信预算。两批平均参数区间的最小间隔超过 0.67，而声明允许的间隔只有 513/4096≈0.12524，故锁定。这是输入记录示例，不是已采集的现实数据。

## 3 缓慢反向变化的完整例子

为了评估性能，选择确定性路径

\[
\kappa_t=\operatorname{clip}\!\left(R-\frac{t-1}{4096},-R,R\right),
\qquad R=64/125.
\]

t 是源准备顺序。正式查询本身也使用一份新源，必须推进 t；不能在计算变化时跳过这些步骤。

各份源独立但不具有相同参数。每批正号数使用完整非同分布二值递推，原噪声概率逐份进入。审计状态还保留“此前未锁定且上一批计数为 k”的概率质量。下一批与前一批不相容的全部质量移入永久回退集合，所有后续任务都照计。

递推使用 100 位向外舍入整数；小规模计数树和两批审计树另以精确分数穷举核对。没有用模拟轨迹估算极小误判概率。

在通用覆盖事件和速率假设同时成立时，每个被启用的增强查询至少改善 C·0.1≈0.00293802，其余使用基础查询。该条件保证与表格对具体路径求出的无条件平均值应区分。

## 5 整体和资源账

这八次任务共使用：

| 资源 | 固定总量或编译上界 |
|:---|:---:|
| 校准源准备 | 4096 |
| 正式查询源准备 | 8 |
| 两系统旋转 | 139568 |
| 额外局部旋转 | 168304 |
| 累计新纯槽，含封闭纯化 | 28736 |
| 原读取次数 | 4112 |
| 校准记录位 | 4096 |
| 策略传输位 | 16 |
| 正式查询环境返回位 | 8 |

每次查询都保留原 E_0–M 共同逆门。过去的源、记忆和纯化可以停止被访问，但仍留在整体。缩短决策窗口没有执行对整体的物理删除。

在该路径上，八次正式任务总共只比八次基础查询多约 **0.0249303 个期望正确答案**。这个数很小，而校准成本很大。成功率提升不能直接说明按总资源衡量划算，更不能说认知边界无成本扩大。

经典算术、完整历史存储、物理运输及源刷新硬件成本尚未建模。两系统旋转和新纯槽均已计入，未将 4096 次校准当作完成的 H 任务。
