## 2．强生成要求还不是一份微观更新规则

检验须先独立列出：普通交换的完整实施、保留状态及关联、关系初值、几何读口，以及允许比较的规则族。不能用下列替代制造结论：

- 只固定归一化条件通道，却声称已经固定完整普通交互；1171已给反例。
- 固定背景依赖的物质算符，就宣称几何参数自己的演化也已确定；591及同源历史筛查明确区分了两者。
- 把完整几何Hamiltonian、未来几何读数或另选的几何作用塞进输入，再称其为生成结果。
- 只改引力参数，却不核验共同初值仍满足各自约束及完整来源，然后宣称推翻用户猜想。

具体而言，[1267几何证明§2式(5)](../../1267/geometry_proof.md)已有$H_0(\kappa)=\sqrt{\kappa\rho_0/3}$、$\pi_{Q0}(\kappa)=-\sqrt{12\rho_0/\kappa}$。旧参数族是合法的约束相容准备族，但完整几何初值随$\kappa$改变；1270／1272承接它，并没有把它变成新强猜想下的共同完整初值反例。保留旧可辨性结果，不能扩大其量词。

**目前真正缺的对象**是一份具体微观交换模型：其事前规定的内部交互、接触/短时资料和必要初态，能给出独立几何读口的后继规律；在其有效域中还要检验该规律是否进入Einstein/Jacobson接口。条件性存在这样的模型与现行认知公理必然选择它，是不同命题。

用户的强要求排除把几何更新作为任意第二份输入；它没有直接指定应使用哪个生成函数。因此本次不能将“尚未构造出”写成“已经证明不存在”，也不能把既有局部匹配资料直接认定为永远不可消除的自由。

## 3．停止线与真实下一步

前项的逐线固有时调节只作为图系数处方，没有领取完整Lorentz母过程。因此现在另做它的正谱或反射正性排除，只会删除未采用的加强，不解决当前独立输入问题；本次不启动该检验。

不再重复FDT、吸收谱、纯几何加项、相干相位、自由物种补偿、任意尺度分账或1195单胞接法。新的准入须给出一条此前尚未检验的具体微观规则或一项有独立认知动机的选择条件，并说明它会改变哪个原几何预测。可保留误差受控的有限有效域；不要求先完成全宇宙、无限高能或任意精度装置。

这是一处尚未解决的研究问题，当前没有需要用户或外部状态改变才能解除的执行阻碍，也没有仍在计算的任务。故不标记goal blocked，不以本次审计冒充阶段进展。目标的三个共同交付及Jacobson同对象连接依然未全部完成。
