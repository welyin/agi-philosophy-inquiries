## 新结果

**同一份完整受约束的三维集体初值，能够同时支撑单调钟变量与非退化的候选几何。** 这补上了两站结果不能直接承接三维背景的问题；三维格点结构及微观约束在此仍是候选输入，并非再次推导空间维数。

在Lee模型的原集体规则中，我们明确补出两个正定$p$部门和相应动量，初始$p_1=I/4$，其后由同一原方程演化。对$0\le\tau\le1/100$：

| 同一窗口的量 | 解析保证 |
|---|---|
| 完整原约束、$U$定义及原ODE | 同时成立 |
| 两个$p$部门 | $p_1\ge I/4$，$p_2>(1/8)I$ |
| 站点集体钟$C=(p_1)_{ii}$ | $3<C'<5$ |
| 原解析符号所定义的逆空间度规系数 | $59<g^{ii}\le60$，选定字典下为Lorentz符号 |
| 几何符号的二阶空间展开 | 当$0<|k|\le1/10$，相对余项严格小于$1/40$ |

最后一项**只控制几何符号的空间展开**，不含完整张量传播的时间展开误差、有限格点到该几何字典的误差或量子测量误差。不能称已获得“物理预测精度2.5%”。

解析证明和独立审阅之外，程序在8、16、32、64边长的周期采样上核验同一约束及ODE，最大网格为262144站点；另诊断轴向及非轴向有限波矢。全窗结论来自解析界，数值采样不替代证明，也不为有限周期几何领取额外身份。
