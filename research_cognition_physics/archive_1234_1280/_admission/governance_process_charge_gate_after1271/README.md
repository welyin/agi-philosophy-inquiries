## 结果

旧候选的两态“熵差＝左面积荷差”保留，但**不能直接升级为原固定区域内、全部结果保留的实际内部反馈**：若内部仪器保持同一完整荷，其全部结果保持该荷的分布；条件筛选可以改变成功支，不能隐去其他支。若增加供能辅助，必须改用完整总荷，不能继续沿用只变$q$而固定其他来源的面积差。

另有两个明确有限界：

- 原两态的正向转换，在密度侧保持归一迹且保持单位的CP类中，半迹距误差严格大于$31/256$。这不排除所有带资源操作。
- 在声明的有限辅助张量实现类中，初始独立辅助精确完成转换须增加至少1 nat熵；目标误差不超过$0.01$时仍须增加超过$0.9$ nat。二维辅助不足，较大辅助仅满足必要条件，尚无实际实现。

**这是对具体升级方式的限定排除，不是治理猜想、动态几何或整个研究纲领的反证。** 限制代数态不独自确定补区荷的完整扩展；左面积荷也不等于任意瞬时面积。没有新增实际几何读口，因而不计为新引力轮次。
