- [此前三交付差额审计](scope_audit_after1266.md)关于停止无穷精度修补、保留有限同源资格的结论。

## 下一候选必须证明什么

候选采用原杆场的局部标量标定尺度，再以有界内部指针耦合。相同读取作用须给出独立的来源、压力和反作用，而不能由目标场方程倒定义。只登记这一候选，不把它公理化。

新研究须同时给：

1. 实际参与者、指针准备、固定采样量、全部结果/后态及许可输出事件。
2. 同一材料作用的独立变分来源；预部署记录的基线和调用交互均不能删除。
3. 有限读取窗内的真实自由演化、量子误差、信号对比、来源反馈和有限资源共同预算。

可接受有限有效材料输入；不能以“存在全部预测都合格的装置”代替上述相容证据。候选失败只约束该候选。若仅重复有限CP、矩阵扩张或换一种关系称呼，则不另开科学轮次。
