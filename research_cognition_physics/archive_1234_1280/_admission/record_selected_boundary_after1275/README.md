# 记录选区后的共同参考与非平衡熵账

## 1. 结论：已有同对象正链可以继续使用

本次不另造边界材料。旧[724](../../../archive_702_741/research_note_724.md)已经以原物质壁的同一次有限精度记录选择原图节点区域，保全部规范边界资料、条件后态、完整原材料能源及来源。[725](../../../archive_702_741/research_note_725.md)还证明选区读取会改变原壁法向平方，给出了共同域和反作用；不能把读前法向直接贴到读后边界上。

[637](../../../archive_629_652/research_note_637.md)和[1221](../../../archive_1219_1233/1221/proof.md)的任意有限能源态结论，允许将这批实际条件后态接入区域熵及保中心互信息分账。[638](../../../archive_629_652/research_note_638.md)的固定区域信息预算则可经记录控制的区域映射接到这里。具体推导见[proof.md](proof.md)。

若输入是同一完整有限图Gibbs参考$\sigma_\beta$，$\rho_\ell$为724的真实有限标签后态，$A_\ell$为事前规则按标签选出的节点区域，则
$$
\sum_\ell p_\ell
D\!\left(R_{A_\ell}\rho_\ell\middle\Vert R_{A_\ell}\sigma_\beta\right)
\le \beta B_{\rm meas}+H(p).
$$
这里$B_{\rm meas}$是原完整材料$H$上的测量注能上界，$H(p)$是有限经典记录熵；两者不能当成同一能源单位或重复计账。参考和真实后态使用同一条区域切分，不把各分支重新热化。

## 3. 最重要的更正：不能把条件后态当作热参考

[1226](../../../archive_1219_1233/1226/proof.md)的规模一致边界上界依赖完整平移Gibbs参考。724的条件后态通常不满足该前提，记录还可能偏向局部高能源配置。

逐记录采用1221原比较态$\tau_\ell=\tau[\rho_\ell]$，准确身份是
$$
\beta\,\operatorname{Tr}[(\tau_\ell-\rho_\ell)H_{\partial\ell}]
=D(\rho_\ell\Vert\tau_\ell)
 +D(\tau_\ell\Vert\sigma_\beta)-D(\rho_\ell\Vert\sigma_\beta).
$$
最后一项是同一完整参考下的真实非平衡修正，不能置零。左侧是非线性比较处方的边界能源差，可能有符号；既不是已经发生的热流，也不是免费去关联操作的功。

这使“面积、参考和后态都存在”推进为一份同对象、保记录的可计算余额，同时阻止直接将1226的平衡面积系数搬给选择后的过程。没有计算原全$H$的热谱或实际熵数值，也没有新增普遍面积系数。

## 4. 研究动作与停止线

本次净增是旧定理的接续：在原记录选择区域以后，给出有限区域相对熵预算和必保的非平衡项。一般Gibbs恒等式、数据处理和规范熵分解均属成熟或已证工具，不重新计为发现。

记录改变选区可以改变切边面积，即使背景度规固定。反之，若背景或阈值一起变化，必须使用724、725已有的状态、来源及端点导数；不能将选择效应称为度规反作用。本报告没有把固定图选区升级为连续移动世界管。

这条链与1274—1275的SU(2)边界载体没有已证的共同映射，也不拼接1270—1272的实际钟及曲域源证书。它未证明几何熵等式、同观察者温标、Clausius、Einstein或用户强生成猜想。
