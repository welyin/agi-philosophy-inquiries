# 内部共同参考能否选择关系自作用：有限对称模型的范围检验

2026-10-17。非编号候选筛查；接1272后的共同响应研究。正式轮次仍到1272，1273未预约，目标与公理不变，CT仍待验证。

## 结论

**全局对称、内部共同参考和局域相互作用可以同时容纳不同的关系更新律。** 给定任意有限局域Hamiltonian，本文构造一个全局不变的关系码及局域扩展，使其精确承载该Hamiltonian。共同参考因此可以容纳逻辑上的奇相互作用，但不能凭这三项要求选出它的强度或形式。

具体六量子比特例子中，两套规则使用同一参考、编码、时标、已知准备和局部末端事件。一个事件概率为0，另一个为 $\sin^2(1/4)>0.06$；两者均保持完整总对称和总能量。解析证明给出严格差异，小矩阵复算核对算符恒等式。

这回答了1200开放分支中的一个范围问题：相对于内部参考定义的复合模式不必服从原裸奇模式的选择规则。**没有修改原Gu–Wen模型，也没有实现引力子、自作用引力或全部治理机制。** 目标Hamiltonian仍是输入；整份关系码准备和实际仪器的权限未由原规则产生。特别不能把这里的编码免费用于一个已经携带原奇荷的未知裸输入。

## 对主线的影响

社会机制给出的“共同参考属于整体、更新责任不能外置”，可以落实成参考和交互一起保留的精确有限构造。但这项弱要求没有把不同更新律区分开。它不能反证完整治理猜想，也不应被当作已经构建几何。

停止扩建该参考编码。下一项应直接检验**关系改变后，哪些后继交互能力必须随之改变，以及不同主体组合时该改变必须怎样接续**；将要求作用于可比较的物理过程，检查能否排除两套有不同预测的更新律。复用1178的共同钟与互易来源、1185的结合能和1029的条件自耦接口；不把“必须产生Einstein自耦”作为该要求的定义。
