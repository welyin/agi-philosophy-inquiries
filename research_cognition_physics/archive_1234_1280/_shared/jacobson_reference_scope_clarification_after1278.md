# 共同有效参考的范围澄清：KMS不是唯一实现门槛

2026-10-17。作者：`/root/governance_use_audit`。这是[共同完成要求审计](jacobson_joint_requirements_audit_after1278.md)的后继范围澄清，保留该审计及其原哈希，不新增公理、科学轮次或核验组。

## 1. 纠正的具体范围

前审计§5建议以“局部代数上的正归一参考泛函、独立流及KMS／受控近似资格”补共同参考。**这是一条清楚的充分实现建议，不是现行采用条文规定的唯一必要形式。** 若将其理解为每个共同有效实例必须先构造具名量子局部代数及KMS态，会把[当前目标](jacobson_gr_goal_20261017.md)不要求的微观实现形式增加为前置门槛。

[正式采用的HG1](ct_hg_adoption_after1278.md)要求参考族对声明的局部boost流具有热学资格、实际钟归一相容、许可模能响应对应完整来源。条文没有限定这种资格只能通过某一种局部量子场构造取得。宏观局部平衡或明确统计响应的有效模型也可候选；不要求它先扩成一份全球量子态。

## 2. 宏观有效完成所需的最少具体内容

有效层输入可以直接公开，不必先证明其全部微观起源；但须具体到能够检验以下事项。

1. **对象与非空性：** 给出非空有效状态域、参考族、区域及许可扰动。它可以采用明确概率／统计参考或其他有独立资格的热学有效描述，不能只把一条经典轨道称作“热参考”。
2. **独立能源和热学量：** 先由同一完整材料规定来源及boost能源，再给参考的熵、温度或生成量；不能从目标Clausius等式反定义它们。普通物质熵、几何熵和公共记录熵仍须区分。
3. **钟流与许可响应：** 指定实际观察者钟和boost参数的归一，给参考的平衡／稳定热资格及所需模能—完整能源响应。明确概率参考$r_\chi$及$K_\chi=-\log r_\chi$可作为一种有效实现，前提是独立能源与许可扰动确实给出所要求的响应，而非只更换量的名称。相应功、荷流和边界项须同时保留。
4. **共同几何与预算：** 面积及其响应沿原独立几何字典，已采用HG2／HG3按其范围使用。有限读口可采用公开有效仪器和噪声合同，但须与同一状态域、完整来源及资源相容，并给足够的有限误差。

这些是把已采用角色落实为具体实例时的数据要求，不是另外采用四条公理。并非每种有效描述都须显式使用密度矩阵或同一个$K_\chi$公式；若使用其他表示，须证明它承担同一许可响应，而不能省掉HG1的该项内容。

## 3. 仍然有效的原审计结论

- 1250的同历史约束、独立面积、完整来源、有限余额及原误差合同继续有效，既有TR与四律不重开。
- “将HG正式采用”不自动证明任意先前经典模型都已有共同热学参考；只添温度／熵标签仍不足。
- 原误差余量可直接复用，新的匹配阈值不等于已经取得的匹配误差；但可以在明确非空的有效模型中把精度和噪声规律登记为输入，不要求先制造全部微观装置。
- 不要求入射材料先热化、两热库接触、全球精确KMS态或完整UV理论。若局部宏观有效完成已经满足共同身份及预算，不再追加具名局部量子代数作为门槛。
