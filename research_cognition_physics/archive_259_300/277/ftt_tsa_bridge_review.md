## 3. TSA可立即借用的部分：预测充分性

推论1.4更直接：若同一空间读数对应的两段历史，在同一个未来试验上的概率差为δ，则任何只依赖该空间读数的预测，对其中至少一段的误差不小于δ/2。321页证明使用三角不等式，中点预测达到下界；这一局部结果可以独立核验。原文也明确承认最小预测表示有已有文献基础。

原文尝试走两侧筛选：有限能带荷缺陷排除低秩，再以成本比较选择高秩中的最小分支；随后用几何及热核条件连接不同维数。这与当前自然维数缺口有关，但至少有以下待接前提：

|---|---|
| 有限深度延拓语法及不相容成本泛函 | 已有有限端口重写；尚无原文泛函与其唯一选择机制 |
| 有限能、带荷、局域缺陷扇区 | 尚未定义相应物理能量与荷；普通消息任务不能直接替代 |
| 二元接触的精确性、原始三元结构及无第四零成本方向 | 未由我们的量子操作合同或增长规则证明 |

这里没有因其是预印本就排除它，也没有因其标题说“推导三维”就接受其全部结论。参考对象是具体定义和证明。

### 一个已定位的局部证明问题

附录D定理370给相对于秩3的下界：j(r)−j(3)≥g(r−3)，r>3、g>0。第61页在定理164的证明中却将定理370引用为相邻秩增量j(d＋1)−j(d)≥g。这一更强命题不由上述下界单独推出。

例如令g＝1，j(3)＝0，j(4)＝4，其余r≥5取j(r)＝r−3。对所有r≥3，相对秩3的下界成立，但j(5)−j(4)＝−2。可复算：

    def j(r):
        return 4 if r == 4 else r - 3
    assert all(j(r) - j(3) >= r - 3 for r in range(3, 100))
    assert j(5) - j(4) == -2

一般性由r＝4及r≠4两个分支直接证明，有限循环只检查实现。**这不是满足TSA全部公理的反模型，也不推翻由相对秩3下界支持的裸成本选择**；它指出这处引用需要补强前提，或将后续证明改写为与秩3直接比较。导入有效成本结论前须解决这一点，不能用定理名称替代已证明的不等式。
