# 原生材料的共同父接口P971 v0.1

2026-10-07。[971报告](../../research_note_971.md)的采用表。继承957假说v0.2及962应用目标；不是新的认知公理，也不宣称完整共同模型已存在。

## 层级与对象规则

1. 上层是明示Einstein＋标准模型有效理论。规范群、维数、物理参数及适用背景是输入，不是本轮推导。
2. 低能束缚材料由带内部态、运动与偶极的复合物描述替代。保留的轻场继续显式演化；被消去的组成结构写入匹配系数。不能复制同一材料／能源。
3. 内部h、Q、偶极、惯性、来源在同一作用下匹配。有限模型对应分支或近似，不能只因算符名字相同就认作相同自由度。
4. 指定态、准备和误差预算后才可签收共同任务域。本轮仅认证所列顶点、运动学及匹配身份。

## 可立即执行的匹配限制

- 同一内部h决定静止能和运动学质量差，不能光学用一份h、反冲另拟一份能级。
- 同一Q决定静止电偶极和运动磁项；规范横向并不独自保证Lorentz匹配。
- 显式跃迁的响应从完整接触响应中扣除：971有限CAR例直接检验了重复添加会变为两倍。
- 971不会移除965的自极化，也不会把970固定支撑波导认作自由靶真空散射。
- 相应修正若小于声明的总误差预算，可以受控忽略；有限精度不是要求所有近似都精确。
