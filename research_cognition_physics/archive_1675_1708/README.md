# 第1675—1708轮　同一味真空、重伙伴与跨尺度检验

[阶段总目录](../README.md) · [第18篇论文](../18_标准模型的条件选择与现实参数的剩余自由_阶段论文.md) · [全阶段参数账](../archive_1798_1815/_shared/standard_model_coverage.md)

让同一个味真空及同一重谱服务于夸克、带电轻子与中微子后，可以少用哪些校准？

三代带电纹理可用九项 CP 偶输入反求夸克弱相位；允许原味真空中的离散相位后，存在同时通过若干夸克与轻子留出的共同点。离散味物质的混合反常可在指定全部自旋背景上核验；同一软质量谱也同时受到规范、重中性态和 Higgs 阈值的限制。 [第1675轮](research_note_1675.md) · [第1678轮](research_note_1678.md) · [第1685轮](research_note_1685.md) · [第1690轮](research_note_1690.md) · [第1698轮](research_note_1698.md) · [第1708轮](research_note_1708.md)

通过的见证包含指定的源、相位、软谱和输运。一组共同的实验窗并未独立选定这些输入，混合反常的消失也不能决定全部作用。

由三代带电谱留出弱相位开始，以共同夸克与中微子数据点结束。第1709轮改问已测得的夸克混合幅能否决定中性源的相对强度。
