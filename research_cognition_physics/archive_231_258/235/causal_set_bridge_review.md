# 路线核对：对接因果集与量子因果历史

日期：2026-09-22。回应用户关于Rafael Sorkin因果集理论及避免重复研究的建议。本文为文献和研究路线核对，不占第235轮编号，不新增数值实验，不改写231—234轮冻结证据。

## 1. 决定

**把“先查既有定理、再核验适用条件、最后研究缺口”设为后续默认方法。当前优先对接因果集理论（CST）及量子因果历史（QCH）。**

231轮§7已经提到因果集，但仅列为背景。现在将其提升为实际研究入口。233—234轮的作用是限定哪些事件合并合法；不再继续以普通协议为对象重复检验同一个过强K₂。

“对接”分两层：

- 结构层：把现有对象、操作、事件接口映射到文献定义，逐项检查条件；已符合的结论直接引用。
- 生成层：追问偏序、事件计数、几何近似和自然动力学是否由现有工作定义强制产生。不能把对接时追加的条件记为已推导结果。

这两层可分支推进：条件性模型足以使用成熟工具；基础前提的必要性仍单独记账，不必因尚未证明全部前提而停掉所有下游比较。

## 2. 当前成果接到哪里

因果集的基本对象是局部有限偏序：事件之间有传递且无循环的严格先后关系；任意两事件之间的序区间只含有限个事件。自反偏序记法与严格偏序记法等价。这是其出发结构。[Bombelli、Lee、Meyer、Sorkin，1987](https://doi.org/10.1103/PhysRevLett.59.521)

| 本项目对象或结果 | 文献中的对应项 | 现有证据与缺口 |
|---|---|---|
| 231轮给定无环线路的可达关系 | 事件偏序 | 该类有限线路的可达性确实给偏序；无环线路是输入，尚未证明所有认知模型都产生一个固定偏序 |
| 233—234轮的交付次序、多步记忆 | 保留因果接口的量子网络 | 可以使用既有量子记忆理论；主体跨多事件，不能把主体标签直接作为时空事件 |
| 第一、二阶段的复矩阵结构及CP操作 | QCH中的事件代数与CP映射 | 数学材料相近；需指定哪些系统归属哪些事件，并满足QCH额外的一致性条件 |
| 每个对象有限维、每个实验有限步 | CST的局部有限性 | 前者不蕴含所有极限历史的每个序区间有限，不能混为一条假设 |
| 事件数或可区分记录数 | 几何体积 | 尚无对应定理；认知状态数、操作事件数、时空原子数是不同计数 |
| 次序、传播、稳定模式 | Lorentz几何、场与引力动力学 | 次序本身不选择维数、体积密度、作用量或自然演化规律 |

有限事件样本在数学上自动局部有限；把任意这样的样本称为有限因果集没有困难。真正待证明的是：为何其序代表物理因果关系，以及为何扩大样本后仍能进入适当的连续时空近似。

## 3. 优先使用哪些现成成果

### 3.1 几何重建：因果序还需要体积

在已有、满足过去与未来区分性等条件的Lorentz流形上，维数大于2时，适当的因果／时序同构确定共形几何；局部体积元进一步固定共形尺度。离散模型用事件计数近似体积，还要给密度和统计对应。它不是“任意偏序都唯一生成度量”的定理。[Surya，2019，§2—3](https://arxiv.org/html/1903.11544)

因此不重新发明“先后关系如何编码几何”的整套理论。后续先核对流形近似、计数与密度，再使用已有维数、时长和几何估计量。

### 3.2 动力学：增长规则有现成分类，但属于额外条件

Rideout–Sorkin经典顺序增长模型，在内部时间性、离散广义协变、Bell因果性及概率归一化等条件下给出一族增长动力学。生成编号不作为外部物理时钟；Bell因果性是该经典模型的具体约束，不能与本项目的操作非信号性等同，也不能直接移植为量子公理。[Rideout与Sorkin，2000，§3—4](https://arxiv.org/html/gr-qc/9904062)

可将其作为增长模型基准，不再随意提出一个随机加点算法便称为新物理。现有认知合同是否选择这些条件、选择哪组增长参数，另行检验。

### 3.3 场与曲率：直接使用已有算子，但保留近似条件

Benincasa–Dowker构造的因果集标量算子，在相应四维流形近似、尺度和缓变条件下联系连续达朗贝尔算子及标量曲率，并由此构造作用量。[Benincasa与Dowker，2010](https://arxiv.org/abs/1001.2725)

这提供未来的明确目标：核验适用条件并复用算子。引用作用量或其连续极限，不等于已从认知原则选出该作用量，更不等于已证明我们的模型满足Einstein方程。

## 4. 更直接的量子接口：QCH

Hawkins、Markopoulou、Sahlmann的QCH框架以局部有限因果序、事件上的简单矩阵代数、相关事件间的CP映射为材料；还要求扩张、类空可交换及合成条件。其定理在满足这些条件时恢复适当完整切片对之间的酉演化。[2003年论文，§5、§7](https://arxiv.org/html/hep-th/0302111)

这是目前比单独抽去量子信息、只保留一个裸偏序更有针对性的比较入口。**这是一项研究判断，尚非本项目与QCH等价的证明。**

需要逐项核对：

1. 本项目对象是可操作系统；QCH代数附着于事件。要给明确的系统—端口—事件对应，不能仅换名称。
2. 文献用可观测量的Heisenberg方向映射，状态方向相反；须统一迹归一化与对偶约定。
3. 任意CPTP通道的存在不保证文献的同态扩张、可交换及合成要求。
4. 保留开放系统的环境与跨事件记忆；不能默认任意缩减动力学均可独立替换。
5. 该框架以因果结构为输入。用其演化定理不会自动证明偏序从认知原则产生。

本轮只核验了定义与定理入口；下一编号轮次才进行条件映射和必要的反例／代码检查。

## 5. 两个直接影响建模的限制

**局部有限不等于每个事件只有有限个直接邻居。** Bombelli–Henson–Sorkin关于Minkowski空间Poisson撒点的定理，限制了Lorentz协变、可测且从撒点内禀构造的优选方向与有限度图。若将来采用固定有限邻居的通信网络，必须另外检查它是否满足所要求的对称性，不能把它直接当作标准CST实现。[论文](https://arxiv.org/abs/gr-qc/0605006)

**几何重建与几何产生是两件不同的事。** 从一个给定流形撒点并恢复它的几何，是校准工具；从动力学生成的因果集证明其近似流形，是另外的研究任务。Carlip在2024年讨论了非流形类的抑制进展，并明确没有由此完成连续时空的产生；Surya的2025年报告仍将相关路径和的连续对应列为问题。[Carlip，2024](https://doi.org/10.1007/s10714-024-03281-1)、[Surya，2025，报告摘要](https://pirsa.org/25030058)

这两份文献的进展范围不能扩张成“已经证明任意因果集长成四维时空”。后续实际调用具体新定理时，再核对其最新版本。
