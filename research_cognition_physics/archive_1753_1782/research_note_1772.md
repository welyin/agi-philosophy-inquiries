# 第1772轮　在壳底粲弱流、两只底钟与家族标记

在三代幺正、共同左手弱流和标准黄金道相位条件下，**在壳 $W\to c\bar b$ 的实测强度**与重子给出的 $|V_{ub}/V_{cb}|$，足以把两只 $B$ 振荡钟的绝对与相对混合强度分开求出。这个反演无需用半轻子 $B$ 的绝对 $|V_{cb}|$ 来定标。两只色散幅分别允许乘上任意正实因子 $h_d,h_s$。

CMS 2024年 Run 3 初步结果给 $|V_{cb}|=0.0376^{+0.0058}_{-0.0072}$；计算对下误差取向外的 $0.0073$。CMS 已投稿 JHEP 的 Run 2 结果为 $0.0459^{+0.0078}_{-0.0090}$；ATLAS 给 $0.050^{+0.011}_{-0.014}$。三种顶样本分别检验，同一 $W$ 手征顶角的解释适用于近标准的顶衰变与味标记条件。相对树级读数取 LHCb 的 $\Lambda_b$ 部分宽度比加格点形状 $r=0.083(4)(4)$。[Run 3 初步报告](https://cds.cern.ch/record/2972245) · [Run 3 数值](https://indico.cern.ch/event/1742595/contributions/7325319/attachments/3381903/6073897/zevi_CMS_LHCC_Nov2026.pdf#page=8) · [CMS Run 2 投稿](https://arxiv.org/abs/2611.01274) · [ATLAS](https://arxiv.org/abs/2603.16414) · [LHCb 实测比值](https://arxiv.org/abs/1504.01568)

**哪一支能成为实际的味标签？** 正常小 $\beta$ 支的 $h_d/h_s$ 中心为 $1.188$，一宽允许 $[0.935,1.531]$。黄金道的反射角支即使各输入走到两宽，仍要求 $h_d/h_s\ge4.503$。还有一个独立于两钟的检验：同一弱流对该枝要求 $|V_{us}|\le0.08491$，而 $K_{\ell3}$ 两宽下端是 $0.22211$。分开改变两个中性混合强度不会影响这个矢量弱流检验。若黄金道测得的相位本身有额外物理，这一结论需另做分析。[精确三代公式与区间证明](1772/proof.md) · [格点形状与 $K_{\ell3}$](https://arxiv.org/abs/1809.02827)

**六份旧物质接线的实际表现。** 第1766轮六个中央点的 $|V_{cb}|=0.04252161$，三项在壳实验各在一个边际误差内。重子比约 $0.090272$，偏离 $1.29$ 个边际误差。它们的 $|V_{us}|\simeq0.227857$ 比 $K_{\ell3}$ 中心高约 $7.44$ 个边际误差。一般三代弱流却容许一个两宽共同点：$|V_{cb}|=0.04252$、$r=0.08838364$、中央两角及 $|V_{us}|=0.22333$ 同时成立，所需共同 $h=0.99875,\ \xi=1.18694$。该 $\xi$ 距两种格点实现的中心分别为 $1.82$、$1.00$ 宽。高尺度物质接线能否在共同边界下实现这个点仍待检查。[实际读数与同点](1772/results.json) · [原物质结果](1766/independent_results.json)

**独立粲检验。** BESIII 的 $D^+\to\mu^+\nu$ 绝对率配合格点 $f_{D^+}$，在旧底输入一宽、粲输入两宽内独立排除小 $|V_{tb}|$、大 $|V_{ub}|$、反射 $\beta$ 三类假根。单用 $D^+/D_s^+$ 两率之比仍允许一个错误的顶味标记。六个旧材料点均通过两项粲实验的一宽测试。现有在壳 $W$ 与绝对格点精度仍不足以分辨第1765轮留下的 $3.63\%$ 混合归一差。以上窗为逐项登记的边际区间。[独立推导](1772/independent_review.md) · [BESIII](https://arxiv.org/abs/2410.07626)
