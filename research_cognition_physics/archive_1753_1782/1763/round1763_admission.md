# 第1763轮准入　带电和中性底介子对同一弱物质的约束

研究范围为第1755、1757轮 QCDSF 已定标三代 CKM 点、标准模型带电衰变、局部顶夸克主导的 $B_d$ 混合和标准稀有衰变归一。源、胚胎味结构、格点与短程参数沿用其声明的来源。用一次未参与这些端点射击的 $B\to\tau\nu$ 对照中性钟和另一条稀有衰变，给出可区分两端点的测量门槛、物质误差造成的重叠以及相位反演。第1404轮的中性率/钟、第1707轮的两中性钟及第1735轮的带电标量约束作为旧输入复用。[主证明](../1763/proof.md) · [输入](../1763/inputs.json)

新增可核结果包括 $10^4\mathcal B_{+\tau}=1.15969,.89649$ 两个固定端点、双分支比的精确混合归一消元、两组实验的两宽大 $\beta$ 镜像反证以及同 $q,\beta,\gamma$ 的不同 $|V_{cb}|$ 见证。独立复算从 $\rho\rho$ 的两支和黄金道的两支出发，处理任意共同混合相位，再核有向 Dalitz 余弦。带电输入角点跨度、格点和实验边际矩形无联合覆盖率声明。新的衰变相位或电磁匹配可改变特定判据，实验精度尚可容多条物质分支。

复算入口为 [主程序](../1763/check.py) 和 [独审程序](../1763/independent_check.py)，分别用现有 Python 执行 `-B check.py --check` 与 `-B independent_check.py --check`。数据、证明及独审均归在本轮。[编号报告](../research_note_1763.md) · [独审](../1763/independent_review.md)
