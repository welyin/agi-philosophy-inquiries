# 第1772轮准入　在壳 $W$ 与两只中性底钟的味标定

**复用及增量。** 第1346轮用含粲的包容 $W$ 宽度，1707轮用重子与 $B_s$ 的树比作相位对照，1766轮由黄金角、两钟和给定归一解出多族标签，1767轮检查底钟的吸收修正。本轮改取真实在壳 $W\to c\bar b$ 读数，允许两个色散强度独立改变；给出同时反求 $h_d/h_s$ 与 $h_s$ 的精确三代关系，用独立 $K_{\ell3}$ 及直接的粲衰变筛别镜像，并核对六个冻结物质点。

**可验收结论。** CMS Run 3 初步值和原 $\Lambda_b$ 树比在 HPQCD 两宽盒排得反射支 $h_d/h_s\ge4.503$；仅 $K_{\ell3}$ 与不涉及两钟的预测就能排除这支。六份旧物质中央值过在壳及粲读数，但 $|V_{us}|$ 比 $K_{\ell3}$ 高 $7.44$ 宽。另有实际三代弱矩阵共同点，所需 $\xi=1.18694$ 在两份格点各两宽内。粲的绝对率给出只用比值时缺失的家族标签。程序验证端点、复列幺正、材料读数和同点残差。

**范围。** 小 $\beta$ 支仍允许标准共同混合。所用的绝对 $C_s$ 与 $f_D$ 含格点尺度设定；重子树比依赖相对形状因子；在壳实验依赖顶衰变模板。未知的混合相位、非标准轴流、非幺正轻族或新顶点需要其自身的过程匹配。未引入新认知公理或预言新的绝对 CKM 数值。
