# 1120起：局域相对论有效场与共同能动量来源

2026-10-11。用户已明确授权开启下一阶段，目标状态为 **active**。前阶段[1106—1119](../archive_1106_1119/README.md)保持结项。本阶段从1120起，先做共同接口的来源与去重审计，不重新研究已完成的三维空间、Lorentz运动学和质能关系。

## 目标

在同一声明的有限有效域中，将认知操作、原三维端点和实际钟连接到区域操作、局域相互作用、因果传播及局部能动量，并与已取得的总四动量及完整反作用保持一致。判清推论、仍需审议的认知扩展、材料类别和匹配输入，为既有场论及引力条件定理提供同一对象上的可核查前提。

继承F＋U＋C＋P、CO1—CO5、SR-T/A/R/O/F和D-P；SR-S仅用于明示扩展分支，生成完备G未采用。认知原子规则、组合规则和宏观有效表现分别审查。

## 三项交付

1. **区域操作与因果接续：** 区域由原位置和钟认证，说明实际操作、记录、未知输入及参考如何定位、组合和传递；不凭张量分解宣布物理空间局域性。
2. **局域演化与总动力学：** 检验窗口内的局域过程如何实现现有有效边界、原端口和允许后续，哪些性质由当前公理或补充条件保证。
3. **共同能动量来源：** 将局部能量、动量流、应力与总四动量连接，保留相互作用、资源、反作用及有限误差；明确能够接入哪些旧规范／引力定理。

允许受控有限有效描述；不预设微观连续或物理最小尺度。完整QFT、标准模型、GR和无限高能完成不作为本阶段的前置验收条件。仅有全局守恒、一个散射矩阵或内部纤维平移，还不构成局域场论生成。
