# 递归功能闭合：把完整小主体组合成完整大主体

日期：2026-09-24。记录用户在456—457研究中的新补充：大的认知系统与小的认知系统应有自相似的分形结构，小单元的各项功能应在大系统中找到对应的子系统分工。本文为方向及验收合同草案，不编号为科学轮次，不新增实验或宣称已证明新定理。

## 1. 接受的研究方向

**组合后的整体应重新成为同一类认知主体：小主体具有的必要认知功能，在大主体中都有实际承担这些功能的子系统或协作过程；这些功能之间的反馈关系也应重现，使整体能够继续加入更大的整体。**

这里的自相似首先是功能和组织关系的自相似。容量、时标、数量、具体内部联系可以随尺度改变；本次用户补充没有要求各尺度完整状态空间等维、同一个数值Hamiltonian、相同几何形状或特定分形维数。也没有要求现实中存在无限多层、零成本扩张或每个任意组合都成功。

“记忆子系统”可以本身是完整认知主体，而在当前整体中承担记忆角色。相同层级的参与者既可保持完整性，也可有专门分工。角色未必一对一、不必永久分配；若角色重叠，须记录共享的真实载体，不能把同一份未知状态计算成多个独立副本。

## 2. 功能对应必须有操作证据

下表是根据SoCA提出的候选清单，不把其中每项未经论证地追加到既有F＋U＋C＋P。

| 小主体功能 | 大主体中的候选承担者 | 需要核查的实际结果 |
|---|---|---|
| 感知和区分 | 与其他主体交互的接口群 | 对外部输入的区别确实进入整体可用状态，并保留来源 |
| 记忆 | 保存经历、规则和未结义务的主体群 | 后续会用到的信息及关联仍可访问，不能只留下失效摘要 |
| 预测、比较、纠错 | 建模、交叉核验及反馈子系统 | 预测误差能够改变后续状态与行动 |
| 选择和行动 | 协调与执行子系统 | 选择由整体内部状态和规则产生，并发生实际作用 |
| 交流和融入 | 对外接口、伙伴接入与共同关系 | 能同其它整体互动，保留合同要求的原有能力 |
| 资源维持 | 准备、供给、占用与余料处理子系统 | 状态、容量、能量、记忆和关联的去向在整体内部交代清楚 |

功能是否必要、哪些功能可以合并，是后续要说明的内容。给子系统命名不能代替相应输入—更新—读出过程的构造。

## 3. 一个最低限度的形式化方向

先定义“小主体类型”：它的合法输入、可访问读数、记忆、更新及对外组合接口。对大系统，给出实际载体及角色实现，再给整体的对外描述Q。对每个已声明的功能f，要求“大系统真实运行后再读整体”和“在整体描述上执行同类功能”一致；用示意式写为 `Q ∘ Ψ_f = Φ_f ∘ Q`。

Q不能只凭命名任选；须保持真正会调用的读数。Ψ_f须来自同一内部运行规则和实际状态中的触发条件，不能是外部逐项挑选的控制菜单。若Q是预测摘要，沿用221的闭合标准；不把Q自动当作可对未知量子态物理执行的压缩通道。涉及通道时，保真要求须覆盖与整体内部参考的关联。

单个f各自成立仍不足：对应关系还须保持功能之间的接续、反馈和新伙伴加入后的任务。完成后的大主体应能作为下一层的同类型参与者。采用近似实现时，应交代误差、有效时间、资源随层数的变化；不把逐层误差有界自动写成任意层数可用。

这是新增的跨尺度功能要求候选；具体函数、角色划分、误差合同及“所有组合”还是“合格组合”的量词尚未固定。不能声称它已经从前四原则推出，也不先指定某种SoCA层数是唯一实现。

## 5. 下一项优先级

当前不再以“又找到一个量子矩阵子块”为宏观主体成立的标志。先选最小的一项跨尺度功能链，把**接收区别—保留任务记忆—内部更新—对外响应**放在同一过程里，给出各功能承担者与后续接续接口。准备、接触、读取和余料是该过程的内部分工，不能被外部调度替代。

复用456、457的具体持续交换结果和431／434—436的读者工具；只新增真正缺失的接续或反馈，并明确它解决上述哪项功能。如果目前只能做其中一步，就记录为局部进展，不称完整分形认知主体。新的伙伴加入时也要重新核整体描述，不把尚有未来影响的相关性剪掉。

功能自相似本身仍可见于经典分布式系统。若要进一步筛选复量子结构，应继承阶段论文已有重建前提，并证明宏观接口实际保持所需状态、非交换读出、操作和组合；无需重新把普通实量子放回已排除的旧合同中。尚未从本候选推出物理三维、Lorentz结构或GR。
