## 怎样重算

在项目根目录，使用已有的 Python 与 NumPy 环境。复算入口接受轮号、闭区间，或全部轮次。

```text
python -B scripts/run_research_sm_archive.py 1364 1798-1799 1815
python -B scripts/run_research_sm_archive.py --all --verify-only
python -B scripts/run_research_sm_archive.py --all --jobs 4
```

第一条执行选定轮次登记的原始检查。第二条校验历史文件、验收记录和哈希。第三条重新执行全部登记程序。需要逐项保存退出状态时可附加 `--report 新文件.json`。早期有些回执是旧执行环境的任务编号，本次执行单独记录程序退出状态。结果摘要可复验的轮次同时比对已登记值。[复算入口](../../../scripts/run_research_sm_archive.py)

不少程序会读取别轮的相对路径。入口按归档映射建立一次性的旧目录视图，运行原始程序后回查证据文件，退出时释放临时目录。历史 Python、输入、结果、验收 JSON 保持原字节；迁移清单记录 Markdown 引用的原值和现值，旧验收哈希因此仍可独立验证。[迁移清单](manifest.json) · [末次逐轮验收时的导航清单](../../archive_1798_1815/_shared/navigation_manifest.json)
