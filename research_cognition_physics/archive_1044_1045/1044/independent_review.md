## 2. 核对的数学链

### 2.1 自伴域、驻波包与有限准备

H₀=K²/4+p²，0≤V_g≤g≤4。故有界扰动保持D(H_g)=D(H₀)，H_g非负。sin²紧动量包正规；有限动量支撑使自由准备属于D(H₀)。质心／相对坐标乘积通常是两粒子的关联准备，正文已准确列为输入。

驻波包在三段上的二阶导数均平方可积，u及u′在0、1连续，因而全线弱二阶导数没有边界δ。紧谱积分允许对时间求导，得到D(H₀)中的强解。由入端范数收敛和同一自伴H的范数守恒推出每个有限时刻归一，逻辑顺序成立；没有预先用“散射态已经归一”代替所需证明。

共同自由初态在−T准备，真实演化2T；没有准备依g变化的精确入散射态。固定自由准备不保证各g完整初始H谱相同，作者没有领取929的额外全谱资源条件。

### 2.3 完整仪器、未知参考与当地性

内部0分支自由，内部1分支保r_g(k)、t_g(k)的全部复相位和运动依赖。W_R、W_T作用后仍保留两物体、数据及任意参考，完备性由每个k的通量身份给出；不是把实际仪器替换为逻辑效果平方根。

对固定g，透射模在带上不恒定：令E=k²，有

$$
\partial_E\log F_g=-E^{-1}-(q\coth q-1)/q^2<0.
$$

因此|t_g|²随E严格变，Cauchy–Schwarz严格不等式说明只保透射效果平方根确实删掉后态资料。

在渐近支撑上p_x=K/2±k的符号与R／T严格一致，余量.94；本地性指探针张量因子，不是时空紧支撑检测器。正文已声明该限制。有限过程直接使用同一探针PVM，不在有限时态上强行假定相对方向与探针方向完全一致；等距界负责运输误差。

### 2.4 反冲、读后资源及能源缺口

总K守恒；R将相对动量k变−k，因此两有限质量物体的动量变化等量反向。R支上探针负动量与目标正动量是同一联合后态的两个对易效果，不需要重准备目标。冲量均值由同一R_g谱权决定。报告明确区分出射谱积分与未定义的两次测量冲量方差。

预算链独立核对为

$$
\|H_g\psi_t\|\le E_*+g,\quad
\|H_0\psi_t\|\le E_*+2g,
$$

$$
\left(\sum_b\|H_g\Pi_b\psi\|^2\right)^{1/2}\le E_*+3g,
$$

读后分支直和继续演化时H₀范数≤E_*+4g。PVM与H₀、总K及单粒子动量强对易，故非选择自由动能二阶矩保持；V有界保证完整H的另行预算。这里不要求PVM与完整H对易。

## 3. 独立复算与原文范围

已用既有Python／NumPy、`-B -X utf8`及单线程设置运行两份默认入口，均通过；另将`finite_window_bounds.py`的只读`verify()`返回对象与已保存JSON完整比较，一致。散射默认入口也与旧保存的概率和反冲均值对照通过。没有使用任何写结果选项。

另作不导入作者函数的核算：从常势区传播(u,u′)的2×2矩阵独立解r、t，在g=2、4及k=.99、1、1.01共6点比较。幅度最大差8.08×10⁻¹⁶；独立组装的双入射S最大幺正残差5.14×10⁻¹⁶。它核对幅度的相位及右入射反射e⁻²ⁱᵏ因子，不把离散点核算代替连续证明。

可复算独立核心如下，属于审阅回归，不新增科学组：

```python
import math
import numpy as np
from fractions import Fraction as F
for g in (2.0, 4.0):
    for k in (.99, 1., 1.01):
        q = math.sqrt(g-k*k)
        B = np.array([[math.cosh(q), math.sinh(q)/q],
                      [q*math.sinh(q), math.cosh(q)]], complex)
        plus, minus = np.array([1, 1j*k]), np.array([1, -1j*k])
        r,t = np.linalg.solve(np.column_stack((B@minus,
                              -np.exp(1j*k)*plus)), -B@plus)
        D = math.cosh(q)+1j*(g-2*k*k)*math.sinh(q)/(2*k*q)
        assert abs(r+1j*g*math.sinh(q)/(2*k*q*D)) < 1e-14
        assert abs(t-np.exp(-1j*k)/D) < 1e-14
        S = np.array([[r,t],[t,np.exp(-2j*k)*r]], complex)
        assert np.linalg.norm(S.conj().T@S-np.eye(2),2) < 1e-14
a = F(99,50)
assert (900/a+F(12,100)**2/(6*F(99,100)**3))/3 < 169
E = F(5113,5000)
assert 2*(E+8) < (6-F(106,100))**2
assert 2*(E+8)+F(106,100)**2 < 20
```
