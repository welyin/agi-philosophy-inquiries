# 联合条件的合并顺序与卡点处理

日期：2026-09-30。依据用户“先把难度低的条件尽量合并，再解决中间卡点”的最新建议。

本文件调整执行顺序，不另改正在进行的统一研究目标，不新增认知公理，不计为新的科学轮次。继承[条件总账](../531/unified_physics_condition_ledger.md)及[531全条件覆盖表](../531/unified_physics_condition_ledger_531.md)，保留全部冻结记录。

## 1. 优先做什么

**先合并已有证据支持、能够减少独立输入或连接多个部门的条件，再处理合并后仍不可消除的缺口。** 这里的“低难度”指可以复用已证结果或成熟接口、且剩余映射明确，不是先做所有容易但与共同模型无关的题目。

优先级按以下顺序判断，不伪造精确评分：

1. 已有严格蕴涵或等价关系，只需核对共同前提与对象的条目。
2. 已有同一模型的联合实现，能共享变量并减少自由参数的条目。
3. 补一处明确接口，就能同时推进量子、几何、物质、测量中多个部门的条目。
4. 单一部门的精细数值、精度提升和参数优化，除非它决定共同候选能否存活，否则后置。

若发现同一候选内的严格矛盾，立即处理，不能因“困难留到最后”继续在矛盾上搭建。与已知观测的必要相容性同样持续检查；可以后置完整拟合，不能后置已足以否定候选的证据。

## 2. 三种合并必须分别记账

|类型|可以登记的成果|不能据此宣称|
|---|---|---|
|对象和记号统一|给出明确映射，确认两处使用的是同一态、作用、参考、尺度或参数|两个条件已互相蕴涵|
|逻辑压缩|在明确共同前提下，证明一个条件推出另一个，或给双向等价；写出剩余独立输入|把结论改成定义便消除了物理假设|
|同模型联合实现|一个具体候选同时满足多项条件，具有共同变量、动力学和适用范围|这些条件互相等价、候选唯一，或已从认知原则推出|

每次登记至少包括：原条件编号、共同对象、适用尺度、继承的附加输入、证明或反例来源、消除的独立自由度，以及未解决的接口。仅仅把27个条目分成几个工作组，不改变独立公理数。

532是重要的合并反例：在所列表示及非零超荷下，额外要求同一个加权迹同时承担群选择和作用归一化，会迫使等权，破坏531的不等权匹配。共同结构不意味着所有功能都必须使用同一个泛函。保留普通群选择加权作用的候选，不把一个过强合并方案的失败扩大为统一计划失败。

## 4. 全局整理后的工作顺序

1. **收妥已有成果。** 先完成547已形成报告、代码和结果的必要核验；不因整理优先级遗失进行中的研究，也不立即扩张成长期精密拟合。
2. **给出实际的条件压缩表。** 回查所有相关已证材料，先处理规范—物质—反常、同一作用中的参数／真空／尺度等已有连接。逐项标注“同名待映射”“条件性蕴涵”“共同实现”“仍独立”“不相容分支”，明确没有消除的输入。表格整理本身不新增轮次。
3. **优先连接现有部分。** 从物理区域的组合接口、参考与探针的物质身份、共同应力与几何反作用等候选中，选择前提最少、能约束最多部门的一项。必须给同一模型的映射；不能仅凭两边都有Hilbert空间、度规或能量就视为接通。
4. **处理剩余关键缺口。** 在更小而明确的条件账上，比较维数／Lorentz来源、共同几何与引力动力学、物质谱选择、实际记录和尺度转换的相互限制。难题如果能提前排除大类候选，允许提前做；不等到所有小题做完。
5. **再展开必要的精细检验。** 对仍相容的共同候选做受控匹配、误差与数据检验。若精细计算不改变条件账、候选存亡或可区分预测，就不把它作为自动接续的理由。

## 5. 下一轮的验收与范围

后继实质研究需要回答至少一项：独立输入是否减少；以前分离的两个部门是否在同一对象中真正相容；是否严格排除了一个清楚限定的分支；或是否得到可检验的不同预测。新证明、反例或构造继续保存为 `research_note_编号.md`，附必要的复算证据。

当前正式完成状态仍以546的发布记录为准。本文件不增加检查数，不认定三维、GR或统一目标完成，也不撤销旧反例。547草稿关于548电弱精细接续的建议保留为候选；执行优先级按本文件先完成全局条件压缩，再决定是否需要深入该支线。
