# 764—796轮：共同量子态与局部相互作用来源

[研究总目录](../README.md) · [文件索引](文件索引.md) · [复算说明](../_migration/README.md)

## 研究问题

给定同一经典耦合背景，能否共同定义物理量子态、规范一致的局部相互作用及来源？

## 阶段成果

- 完整线性约束约化、物理辛空间和正Hadamard自由态在同一声明背景上接通（764—767）。
- 同一态、来源、插入与局部Ward／BV恒等式获得共同修复，并在声明局部形式类别中推进到任意固定阶（768—783）。
- 经物理切片、量子正规形、实紧支完成和幺正比较，构造原有限源菜单上的正形式态及兼容首阶初值（785—796）。

## 适用范围与未完成项

正则局部片、四维、既定作用及物种仍是输入；形式正性不是有限耦合收敛、实际准备装置、原图连续极限或全局量子引力的证明。

本目录是研究主题分期，不能据此认定其中全部开放问题已解决。原报告的认知动机、额外输入、解析证明、数值校准和物理解释保持区分。
