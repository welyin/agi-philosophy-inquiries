# 788工作稿：先区分在壳量子作用与实际来源的一阶法向jet

日期：2026-10-05。787已签收，本工作及probe暂不增加正式编号/累计检查。

## 当前新的可计算切口

787一般块逆提示：对固定在壳P、K改变线性规范F，原一圈Gaussian规范变分中的玻色混合块给

```
(1/2) Tr(G_F delta D_F)
 = (1/2) Tr(G_A delta A) + (1/2) Tr(G_A† delta A†),
delta log det(ghost A) = Tr(G_A delta A).
```

在有限实矩阵中，两项转置迹相同，因此玻色与ghost恰好抵消；delta N的项因(G_F)bb=0不贡献。在连续场论中应先证明核配对及共同重合延拓，不能直接把发散迹当有限迹循环，也不能用真空Feynman行列式替代771实际态的来源。

即使在壳作用的规范差严格消失，也不能直接推出在壳点的一阶来源相同：第一变分可能沿离壳方向。下面是具体校准，用来避免在788中犯这个错误。

## 精确有限诊断

取S=m(r−q²/2)²/2，sq=c，sr=q c。背景为q=0、r=x，线性规范条件为a*q+b*(r−x)，a非零。Euclidean玻色Hessian与ghost在背景处是

```
H(x)=[[a²−m*x, a*b],[a*b,m+b²]],   A=a.
Gamma1(x) = (1/2) log det H(x) − log a.
```

在x=0，Gamma1=(1/2)log m，所有a,b相同；但是

```
Jr = d_x Gamma1(0) = −(m+b²)/(2a²).
Cqq = (m+b²)/(a²*m),  Crr=1/m.
mean_r_1 = −Jr/m = Cqq/2.
mean_(r−q²/2)_1 = mean_r_1−Cqq/2 = 0.
```

`../source_normal_jet_probe.py` 用Fraction核三个规范点；来源也用原三阶顶点收缩独立计算，完全一致。只比在壳determinant不够，带上非线性关系观测就恢复共同结果。这是与786密度例不同的机制：这里M=1，没有依赖物理量的ghost重标记密度；差来自非线性参考字段与一阶法向来源。

## 接续要求

原对象的下一步应把771的完整实际态来源、原关系字段二阶jet、混合规范/ghost伙伴和局部接触放在同一公式中。先用787物理核恒等式消去真正相同的部分，再核余项是否给P*u及共同观测补偿。切勿仅凭在壳一圈作用相同或真空determinant抵消，就签收实际来源/准备相同。

787形式t路径允许逐项共同修复，但不提供t=1求和。这个probe既未计算原连续量子反常，也未解决端点或物理正态。784相对荷路线与新近BV-BFV参考线索按原范围保留。
