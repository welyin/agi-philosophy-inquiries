## 回查后的具体入口

775已经证明原完整自由导子D与正常序N_W交织。原T₁^H=N_W exp(ℏΓ_C)，C=W−H。这个结论包含反场的自由场方程作用，不能只看字段上的γ；H一般不是双解。

若坐标变化的二阶部分为v₂(Φ)=½U(Φ,Φ)，对应三价生成元G₃=〈Φ*,v₂(Φ)〉，反场无收缩，则

```
Γ_C G₃ = 〈Φ*, k〉， k = Γ_C v₂；
A₁(G₃)/ℏ = s₀ Γ_C G₃ − Γ_C s₀ G₃。
```

在反场零投影中，第一项给〈DΦ,k〉，第二项给同一项加788的ρ，因此候选识别是

```
(A₁(G₃)/ℏ)|Φ*=0 = −ρ。
```

这里A₁表示D T₁−T₁s₀的第一次插入缺陷，不是有限BV的未经重整化Δ。原Γ_W与s₀的交换子为零，故剩余表达仅由H的局部方程余项决定，状态无关；k仍依赖实际态。

## 已执行的精确校准

`../generator_source_probe.py` 复用777分次引擎，对两份满足自由场方程和完整Wick交织的有限核，直接计算上述两个交换子。三价生成元同时改变规范方向、带方程方向和平坦物理方向。所得A₁=−ρ非零且两态完全相同，Γ_C G₃随态变化。

对逆坐标作用S₃,new=S₃−s₀G₃，代码独立验证

```
J_new,raw = J_old,raw − Dk − ρ；
ell_new = ell_old + ρ；
J_new,ren + Dk = J_old,ren。
```

原物理三次顶点与有限线性来源均保留；漏ρ则失败。诊断中的b仅作平坦物理字段w，rho=b*，未包含非最小b部门；报告签收时必须明确它只是符号/机制校准，不能替换原完整模型。
