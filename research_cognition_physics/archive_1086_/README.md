## 已记录的首轮

[1086：回声不能单独固定钟尺尺度，双向滴答给可检验连接](research_note_1086.md)。在明确的有限有效运动学中，同类任意方向回声仍容许共同尺度$\lambda$；同一对已标定钟的双向滴答间隔比恰为$\lambda^2$。这给待论证的运动角色交换要求一个具体预测，尚未由CO1—CO5推出该要求。
