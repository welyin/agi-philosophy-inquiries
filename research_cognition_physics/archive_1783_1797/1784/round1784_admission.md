# 第1784轮准入记录

- **对象与假设**　第1688轮六对 $\mathbb Z_{12}$ 量子数，同一1712带电家族参考，原单次标量插入和实 Wilson 系数。两只重单态的树级匹配提供额外破轻子数来源；沿用1715已登记的齐次输运。
- **新增判别**　逐对筛选允许顶角、零模和弱基零元。相同参考定相与带电数据一起只留下正常排序的 $(0,2)$。这个分支在完整登记矩形上预报 $\delta$ 到 $\pi$ 的圆距离至多 $6.642^\circ$。
- **数值核验**　实系数见证同时达到三个角和两个频率，保存公共标架复原、极分解扰动界与原始系数。以两种步长复算，并核对更新 T2K 的 FC 及 NOvA–T2K 的 HPD 条件。
- **既有工作与范围**　秩二本身、六对的异常枚举和反应堆逆谱分别承接旧轮。本结论限于该带电点、允许算符、有效物质及检验窗。三个形状目标与总尺度已定标，见证的反应堆幅度属于存在性检查。有向 CP 未参与定参。
- **独立检查**　最后重阈值以下，单源在给定两圈标准模型窗口的辐射增秩不足以产生第二个振荡尺度。独审同时给出秩二最轻态的扰动界。[独审](../1784/independent_review.md)
- **复算入口**　分别在本轮目录运行 python -B check.py --check 与 python -B independent_check.py --check。[报告](../research_note_1784.md) · [结果](../1784/results.json)
