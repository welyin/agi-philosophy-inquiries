# 第1786轮准入记录

- **问题**　第1784轮的单标架 CP 判别，在完整带电误差窗与原离散分支中能否保留。
- **既有输入**　第1702、1712、1715轮的实际一圈物质表、非简并阈值、较大模根、公共 CP 标架，第1688与1784轮的单插入重单态，第1782轮振荡窗。十二项带电量各取两份边际误差。
- **新增证明**　从带电质量行及下型余子式推导电子方向的普适上界。谱投影的虚部可精确归到一条复边，从而得到所有源系数和整个带电输入盒的正常排序、$27.817^\circ$ 相位弧及轻交换质量包络。低、上重极之间的同一 Dirac 柱另计实际输运误差。
- **可区别自由**　两个真实离散 $k$ 在同一组半轻子输入下均过独立的树 $\gamma$ 与金通道一宽并给相反的 $J_\nu$。有向 CP 符号仍无法从这些读数选定。
- **范围**　完整盒结论没有扩展到独立的高维算子或任意带电物质。印刷 T2K 边界舍入误差大于本轮名义间隔。独审的较紧双贝塔区间属于原标架。[全域报告](../research_note_1786.md) · [独审](../1786/independent_review.md)
- **复算**　本轮目录内分别执行 python -B check.py --check 与 python -B independent_check.py --check。
