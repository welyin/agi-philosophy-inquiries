# 第1783—1797轮　精密电弱读数、Higgs 表示与两种质量来源

[阶段总目录](../README.md) · [第18篇论文](../18_标准模型的条件选择与现实参数的剩余自由_阶段论文.md) · [全阶段参数账](../archive_1798_1815/_shared/standard_model_coverage.md)

用实测电弱分箱、振荡、Higgs 衰变和中性介子数据，能区分哪些同谱物质和质量来源？

共同带电输入放宽后，特定中性味候选仍有有限的轻子 CP 相位带。两套具有相同质量谱和部分单 Higgs 读数的模型可给不同的三 Higgs 响应；两个带电质量来源也可在相同质量数据下给不同的 Higgs 味衰变及强 CP 响应。 [第1783轮](research_note_1783.md) · [第1786轮](research_note_1786.md) · [第1788轮](research_note_1788.md) · [第1791轮](research_note_1791.md) · [第1793轮](research_note_1793.md) · [第1797轮](research_note_1797.md)

所得到的相位窗属于特定中性源、匹配面和传递范围。对标量作用的识别取决于额外分支、顶角和精度，单 Higgs 或质量谱本身不完备。

从真实精密电弱分箱开始，到相同重标量质量分裂对强、弱 CP 的联合约束。第1798轮改为检验统一张量能否同时生成上型与中性质量。
