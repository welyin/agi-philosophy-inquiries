# 第一百七十八轮：把认知动机与量子重建公理逐项记账

日期：2026-09-16。接续第177轮，交付候选重建公理清单。**本轮整理证明依赖，不把文献公理视为已经从认知推得，也不以检查表替代重建定理。**

## 1 要重建的是完整操作结构

目标对象包括允许的准备、状态区别、带结果的操作、概率、串并行组合以及可逆变化。坐标换成实数，不改变这些对象间的对应时，应归为同一理论。认知日志、数学描述和未知物理输入分别处理。

统一采用以下状态标记：

- **已在基准实现**：有具体模型满足；不是所有认知模型都必须满足的证明。
- **新增候选**：认知动机可以解释它，但目前没有必要性推导。
- **条件定理**：明确输入若干结构后才能得到结论。
- **未闭合**：既没有认知推导，也没有覆盖全部备选理论的排除证明。

有限维、允许随机混合、操作等价的定义、可组合实验及允许的辅助系统同样属于框架输入。随机化支持概率混合的仿射表达，但不能单凭它推出正矩阵状态锥或Born规则。有限记忆实例也不是所有物理系统有限维的证明。

## 2 六条公理的操作含义与认知依据

以下以[CDP有限维重建，第III节](https://arxiv.org/html/1011.6451)为一条充分路线，不声称它是唯一或最少路线。定义采用自己的简写；完整量词和框架以原文为准。

| 条件 | 本次采用的含义 | 原认知要求实际支持到哪里 | 当前身份 |
|:---|:---|:---|:---|
| 因果性 | 后续选择读取方式，不改变此前准备结果的边缘概率 | 原闭环按历史更新，采用这一时间方向；尚未由一般“认知”定义证明所有理论必须如此 | 原基准采用，普遍性未证 |
| 完美可区分性 | 每个非内部态，都有另一个态可与之零误差区分 | 能力边界可见只要求说明误差，不要求理想零误差读取 | 新增候选 |
| 理想压缩 | 对一个状态所在的最小面，存在无损且充分使用编码状态空间的压缩 | 历史轮次给出特定模型中的压缩，未覆盖每个状态面与全部系统 | 新增候选 |
| 局部可区分性／局部层析 | 两个不同联合态，至少被一项乘积实验的联合概率区分 | 组合需要复核允许联合探针与关系参数；尚未要求只靠各方读取的联合统计就足够 | 新增候选 |
| 纯条件化 | 纯双系统上，一方原子效应的非零结果使另一方条件态纯 | 来源日志、记录完整均不保证条件态无混合 | 新增候选 |
| 纯化及本质唯一性 | 每个态有纯整体扩张；固定环境时，纯化差别可由环境侧可逆操作联系 | 整体与历史保留较弱；第172轮已给反例 | 新增候选 |

“非内部态”对应原文的not completely mixed；在通常量子锥中是非满秩，**不是“不等于I/d”**。原子效应在通常实复矩阵模型中对应正秩一射线，不能解释成任意粗测量结果。

## 3 同一套条件下的模型对照

表中均指理论允许的理想操作，不将项目某一组有噪声原语的权限等同于整个理论。

| 条件 | 普通有限经典概率 | 通常实量子及实张量组合 | 标准复量子／操作等价实表示 |
|:---|:---:|:---:|:---:|
| 因果性 | 是 | 是 | 是 |
| 完美可区分性 | 是 | 是 | 是 |
| 理想压缩 | 是 | 是 | 是 |
| 局部层析 | 是 | 否 | 是 |
| 纯条件化 | 是 | 是 | 是 |
| 每态纯化及本质唯一性 | 否：存在性失败 | 是 | 是 |

可直接核对的理由：归一化给出因果性；支持的正交补给出完美区分；支持子空间或经典非零标签集合给出压缩。纯量子联合态的系数矩阵记为C，秩一环境效应给出的非零条件态为向量外积；经典纯联合态是单个顶点，条件化后亦然。

实理论失败的局部层析由第59、83轮的显式核见证，实纯化及唯一性由第173轮的谱分解与等Gram证明。经典纯化失败由第172轮给出。经典和复模型的乘积效应分别张成联合概率表空间与全部Hermitian算符空间。

因此，**纯化与局部层析互不蕴含**：实模型和经典模型分别给出反例。它们在这三个候选中的筛选力很明确，但这个三列对照不是对所有广义概率理论的分类，也没有证明这两条单独构成完整重建公理。

## 4 不能忽略的权限与精度

局部层析不是“双方各自的边缘决定整体”，而是保留乘积测量结果之间的联合统计。它通常描述理想概率的唯一性，不保证一份样本识别未知态、有限样本零误差或任意噪声下高效估计。

联合操作、共同参考、辅助探针和预共享状态也须声明。第174轮实Bell辅助可以校准完整过程，第83轮已知参考可帮助重建受承诺的输入族；这些不等于通常实理论所有联合态已具有无辅助局部层析。检验原则时不能在这两种任务间切换。

准备非情境性与本表也分开：它约束隐藏变量解释，是第21轮额外要求，不是标准量子理论普遍成立的公理。“知道自己的准备动作”尚未推出它。
