## 独立算术

以原文十进制数重新计算，使用60位Decimal平方根；97.5%正态分位数由`erfc`反演，不导入作者函数。定义统一为“观测减预测”。主线已在采用账修正原来相反的符号口径，两种方向的双侧尾概率本来等价。

与保存结果比较18项，最大绝对差$4.0\times10^{-15}$。独立算法可用以下短程序复现；它不计算核网，也不拟合参数：

```python
from decimal import Decimal as D, localcontext
from math import erfc, sqrt
lo, hi = 0., 5.
for _ in range(100):
    mid = (lo + hi) / 2
    if erfc(mid / sqrt(2)) > .05:
        lo = mid
    else:
        hi = mid
q = (lo + hi) / 2
with localcontext() as ctx:
    ctx.prec = 60
    for mu, error in [('2.442', '.040'), ('2.444', '.037'), ('2.512', '.042')]:
        delta = D('2.527') - D(mu)
        sigma = (D(error)**2 + D('.030')**2).sqrt()
        z = delta / sigma
        interval = [delta - D(str(q))*sigma, delta + D(str(q))*sigma]
        print(delta, sigma, z, erfc(float(z)/sqrt(2)), interval)
```
