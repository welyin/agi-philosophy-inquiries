# 多份成熟采用怎样共同使用：公共分支与重叠范围

2026-10-09。**范围核查，计0；不立1063，不改原ROADMAP、历史资产或物理参数。** 本文核对的是已有采用之间的使用规则，不是新增物理机制、全局存在定理或经验拟合。

## 1. 结论：已有公共核，不是34条无条件合取

本次检查采用的是紧致轴子周期采用新增前的目录快照，共有34份以`adoption.md`结尾的采用正文；34不是随后目录的实时计数。它们包含标准分支的有效描述、替代动力学、扩展物种和不同准备条件，不能把文件数量视作同一个现实模型的34项同时通过。

但也不能因为它们涉及不同实验和宇宙准备，就否认已有共同使用的范围。[原M2、M4、M5](../../ROADMAP.md)允许有限任务内的实际映射、明确采用的GR恢复及不同背景；只在声称同一连续历史时要求状态和资源实际接续。**一台装置承载全部现象、从无生成初态、构造完整宇宙史或先解全UV，不是这些验收的通用前提。**

以下“可并用”指：在各自已声明的保留阶、背景和准备中，共用参数与已有匹配规则；它不表示所有局部近似已获一个统一数值误差界，也不表示所有经验摘要已有共同拟合。

## 2. 可以明确保留的公共分支

取[P981原父合同](../../archive_956_989/981/drafts/common_parent_contract_v1.md)中的3+1 Lorentz几何、常数Planck系数的Einstein作用、现实荷表示的三代可重整化SM。需要中微子质量时，另外声明原合同的Weinberg项及其系数；不能仍称最小SM独自给出了质量。额外高维项按各任务保留阶处理，不能无说明设为零，或在不同部门分别改值。

|已经存在的共同核|可直接复用的实际关系|仍须保留的输入或边界|
|---|---|---|
|同一电磁与质量字典|1059的反冲—磁矩使用同一低能电荷；[电子曲率采用](qed_curvature_adoption.md)把同一电子贡献接到传播和度规变分|圈阶、重整化方案、其它Wilson系数、背景和材料匹配；1059的标定张力并未消失|
|同一弱流与Higgs字典|1052使用共同弱流的μ／e比值结构，共同归一在比值中消去，未使用绝对Gμ标定；1061与[绝对弱归一](electroweak_absolute_normalization_adoption.md)共用缪子标定。低能修正与电弱匹配不重复计入，质量／宽度定义同步运输|CKM、质量方案、强子矩与共享误差；参考点检查不是新的现实W质量预测|
|同一强子及中性物质对象|[核子来源](nucleon_source_adoption.md)区分Higgs荷与总引力质量；[核弱](nuclear_weak_source_adoption.md)及[质量—LNV匹配](neutrino_lnv_matching_adoption.md)保完整质量、流和有效核的同方案关系|强子／核矩及截断误差不能从总质量或振荡资料推出；有限动量完整率尚有自己的合同|
|同一度规及保留阶来源|1027—1029的共同来源规则，原子钟、原子干涉、反氢及双脉冲星在各自有效域使用同一质量、作用和几何；[多信使传播](multimessenger_propagation_adoption.md)只取其声明的最低阶窗口|这些是不同任务／背景，不能合成一份共同实测；电子曲率修正也不违反“最低阶共同锥”的准确表述|
|同一材料的记录、响应与热账|正常接触的传输谱连接电／热／噪声；自主反馈的同一联合跃迁连接记录、后续率和热流；LIGO保读数与辐射压的共同耦合|材料参数、储库状态与维持条件继续是输入；不同装置不必共享一份准备，但声明连续使用时不能免费重置|
|同一标准热分支|[中微子退耦](neutrino_decoupling_adoption.md)的谱同时进入能源与核弱率，声学采用共用电离史和碰撞项|热准备、占据、背景参数和版本不能悄悄更换；仅同一N_eff数字不等于完整谱相同|

这里已包含真实的跨部门义务，而非只说“都属于SM”：同一贡献不能在传播与来源两处分别拟合；同一质量矩阵不能在振荡、β和LNV中分别重选；同一弱标定不能在比值检验后从绝对关系里消失。

原P981明确说它不是全部门有限正实现的存在证明。本文不撤销这点，也不将上述成熟匹配变成那个更强的存在结论。复合材料若尚缺微观匹配，则保持其条件材料合同；不可仅因字段名称相同，就把旧965的全部实际参数认作已从SM计算出来。

|PQ轴子、实单态门户等扩展|不是彼此自动互斥，但也不自动属于原P981字段。若共存，必须登记同一总作用、能源、占据和丰度；不可把每个候选的“全部暗物质”条件同时赋给不同物种。若其MeV贡献不可忽略，不能原样领取标准退耦数值。|

## 4. 已经达到的有限验收，不应重新列为空白

1. [1050＋1053共同范围](joint_scope_after1062.md)：同一个实际Coulomb过程保未知输入、参考、指针后态及受控电子Newton来源。总装置有限G反馈是升级任务，不能反过来取消这份局部共同证书。
2. [1002／980／1045资源范围](m3c_scope_after1062.md)：声明初始资源后的有限写入闭合及实际状态接续已经存在；控制者、实体末读整链未全验收，不等于没有任何有限资源闭合。
3. [最新端点与弱归一整合](integration_endpoint_weak_after1062.md)：均值位置部门已按声明拓扑、预算和正常准备截面接425；完整传播子不恒等不是位置商失败。它不补整个Lorentz／钟尺接口，也不推出三维来源。绝对弱归一则完成另一保留阶公共参数匹配，二者无需强拼同一实验史。

原M4的有限GR恢复和认知生成分开。已有共同作用的变分、Ward和守恒工具应复用，不应为每个新现象重造全源装置。只有某项实际任务确实要求选择后态、总源、后续几何及新读口同时保留时，才承担该更强共同过程的误差义务。

## 5. 真正仍须做什么，本次在哪里停止

**公共分支的理论兼容与其经验同时通过是两项结论。** 前者可按已有作用、参数和匹配接口逐项核查；后者不能靠本文的归类取得。1059已经留下给定误差合同下不相容的共同α标定，早晚宇宙审计也保留原分支张力；本次既未消解它们，也未把它们升级为整个认知纲领的反证。

下一项有判别力的工作应明确：哪两个已采用描述真正重叠、共享哪个参数／态／全局结构、旧映射缺哪一项，以及什么结果会拒收该组合。上节紧致轴子与全束周期是这样的待核接口；其地位不同于“再增加一种成熟现象”。若该接口也被旧结果直接覆盖，就计0停止，不能为立号扩大候选工程。

本次除上述正在独立处理的接口外，**没有发现应另立科学轮的第二个净新命题或新的有限预测矛盾**。更强全仪器任务仍可研究，但没有证据说明它是现有34份采用共同使用的统一前置门槛。本文到此停止，不新增拟合、模型或经验组；原M1—M6整体完成与否仍须依各项原验收证据判断。
