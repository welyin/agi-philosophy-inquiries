## 4 最小可复算诊断：保热边缘不保联合无功性

仅取有限矩阵及1020采用的循环酉功定义，不称新科学结果。令h=diag(0,1)、τ=diag(2/3,1/3)，对应β=ln2。两qubit总裸能源H=h⊗I+I⊗h：

$$
\rho_{\rm prod}=\tau\otimes\tau,
\qquad
\rho_{\rm corr}=\tfrac23|00\rangle\langle00|
+\tfrac13|11\rangle\langle11|.
$$

两者的每份边缘均为τ、总平均能源均为2/3。乘积态的全局被动能就是2/3，可提功0；相关态本征值(2/3,1/3,0,0)按能级(0,1,1,2)重排后的最低能源为1/3，故同一循环操作合同下W_max=1/3。

显式U以第二qubit R控制翻转第一qubit S，将|11〉与|01〉互换。输出为|0〉〈0|_S⊗τ_R，达到1/3，且R边缘精确保留。可是S:R互信息从h₂(1/3)=0.6365141682948128降至0；联合资源没有复位。因此它不是“记录边缘返回，所以可无资源无限循环”的例子。

这里未实现循环控制器、低熵电池或测量器，也未把平均电池增能等同于纯功。若显式增加电池及能源守恒扩张，就仍须把电池熵、关联和控制复位计入；已有1020、975与1002的警告继续适用。反例不选择温度、H、物种或几何，只防止把完整记录误换成边缘状态。

```python
import numpy as np
tau=np.diag([2/3,1/3])
H=np.diag([0.,1.,1.,2.])
prod=np.kron(tau,tau)
corr=np.diag([2/3,0.,0.,1/3])
U=np.eye(4); U[:,[1,3]]=U[:,[3,1]]
def energy(r): return float(np.trace(r@H).real)
def ergotropy(r):
    return energy(r)-float(np.sort(np.linalg.eigvalsh(r))[::-1]
                           @np.linalg.eigvalsh(H))
def marginals(r):
    x=r.reshape(2,2,2,2)
    return (np.trace(x,axis1=1,axis2=3),
            np.trace(x,axis1=0,axis2=2))
def entropy(r):
    z=np.linalg.eigvalsh(r); z=z[z>0]
    return float(-np.sum(z*np.log(z)))
def mutual(r):
    a,b=marginals(r)
    return entropy(a)+entropy(b)-entropy(r)
out=U@corr@U.T
for r in (prod,corr):
    for m in marginals(r): assert np.allclose(m,tau)
assert np.allclose(out,np.kron(np.diag([1.,0.]),tau))
assert np.isclose(ergotropy(prod),0)
assert np.isclose(ergotropy(corr),1/3)
assert np.isclose(energy(corr)-energy(out),1/3)
print(energy(prod),energy(corr),ergotropy(prod),ergotropy(corr),
      mutual(corr),mutual(out))
```
