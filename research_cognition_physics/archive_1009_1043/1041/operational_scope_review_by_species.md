因此这里没有把233已给DAG的商图充要定理直接套到物理时空。复用的是其有限二值闭环见证：

\[
Z=\sum_{x_1,\ldots,x_m}\prod_jT_j(x_{j+1}\mid x_j)
=\operatorname{Tr}(T_m\cdots T_1).
\]

全复制给2，恰一翻转给0，均不等于确定性仪器所需的1。实际受限过程可能改变前提；这些无效总权重不是预测到的合法实验概率。

逆向也有范围：共同严格时间使所有允许的非零传播边增加，有限图因此可按拓扑次序接普通CPTP机制，结果求和归一化。同点局部仪器不另外引入反馈边。报告§6.2的有限位移转换只服务于指定反例；若拿它们证明另一菜单的正向排序，转换边也须计入。冻结稿§4.2已明确这两点。

## 2. 同一事件不同于同一地点、同一状态或同一读数

三段的完整坐标端点为

\[
0,\quad(6/5,0,0,0),\quad(3/5,4/5,0,0),\quad0.
\]

在本轮**采用仿射点作为实际事件身份**的合同中，末端确为起始事件，能够形成同一端口的闭接线。第一坐标尚非共同时间，不能只看其增减判断单部门“倒流”。

若实际事件为 \(e_0\prec e_1\prec e_2\prec e_3\)，而一个宏观投影恰将它们显示为上面四个坐标，则 \(e_3\ne e_0\)。它仍是有初态和末端丢弃的开放有序线路：

\[
Z_{\rm open}={\boldsymbol1}^{T}T_3T_2T_1p=1,
\]

而非矩阵迹。这一差别不靠是否能看见微观状态；它来自事件身份与端口接法本身。只给有限读数箱、重复样式或不单射的涌现坐标时，不能把末端丢弃改接为起点输入。

因此1041不排除持续前进后重访同一空间地点，不排除状态或记录复现，也不要求微观历史不能再次出现相同局部样式。它只排除所声明字典中的真实闭合事件线路与普遍普通操作合同同时成立。

## 3. 有限误差条款

报告§6.1的方向余量是给定辅助范数下的几何界，不等于识别真实同一事件的统计置信度。§6.2明确实际转换位移、可调节末段和能源仍需交付；总位移预算本身不制造转换器。两项均未被包装成真实仪器认证。

§6.3的模型是三份明确二元对称信道，允许错误率互不相等：

\[
Z_{\pm}=1\pm\prod_{j=1}^3(1-2\epsilon_j).
\]

当各 \(\epsilon_j\in[0,1/10]\) 时，缺陷至少 \(64/125\)。报告未将该公式推广到任意相关噪声、任意编码器、任意量子通道或未知转换噪声。若一段为完全重置，此见证消失；这恰好确认信息传递权限不能省略。

在作者冻结前自行编写并运行下列有限二值枚举，未调用作者科学函数；冻结后只读运行两个作者入口。这里的枚举是审阅核算，不是新科学组，也不代替解析全称证明。

|审阅者独立检查|结果|
|---|---|
|三事件、每处四种确定性二值函数|64份菜单；闭环权重0／1／2分别为4／56／4份|
|同一64份通道保四个有序事件，初态为(2/5,3/5)、末端丢弃|64／64权重为1，即使摘要坐标回到原值|
|三份错误率分别从0、1/100、1/10选择|27份不等噪声组合，逐标签求和与 \(1\pm\prod r_j\) 精确相同；最小缺陷64/125|
|一处常0或常1重置，其余两处任意确定性函数|32／32闭环权重为1|

采用Python标准库Fraction作精确有理计算。可将以下片段直接送入既定缓存Python的标准输入复算；不写入任何作者资产：

~~~python
from fractions import Fraction as F
from itertools import product

def matrix(f):
    return [[F(f[x] == y) for x in range(2)] for y in range(2)]
def ring(t):
    return sum(t[0][x[1]][x[0]] * t[1][x[2]][x[1]]
               * t[2][x[0]][x[2]] for x in product(range(2), repeat=3))
def path(t):
    p = [F(2, 5), F(3, 5)]
    return sum(p[x[0]] * t[0][x[1]][x[0]] * t[1][x[2]][x[1]]
               * t[2][x[3]][x[2]] for x in product(range(2), repeat=4))

functions = list(product(range(2), repeat=2))
counts = {0: 0, 1: 0, 2: 0}
for fs in product(functions, repeat=3):
    t = list(map(matrix, fs))
    counts[int(ring(t))] += 1
    assert path(t) == 1
assert counts == {0: 4, 1: 56, 2: 4}

def bsc(e):
    return [[1-e, e], [e, 1-e]]
defects = []
for es in product((F(0), F(1, 100), F(1, 10)), repeat=3):
    t = list(map(bsc, es))
    r = (1-2*es[0]) * (1-2*es[1]) * (1-2*es[2])
    assert ring(t) == 1+r
    assert ring(t[:2] + [t[2][::-1]]) == 1-r
    assert path(t) == 1
    defects.append(r)
assert len(defects) == 27 and min(defects) == F(64, 125)
for f, g in product(functions, repeat=2):
    for reset in ((0, 0), (1, 1)):
        assert ring([matrix(reset), matrix(f), matrix(g)]) == 1
print(counts, len(defects), min(defects), "all checks passed")
~~~
