## 2 一般锥定理核验

1. **紧性成立，未偷设锥和闭。** 有限个闭锥的单位截面之并S紧。有限维Carathéodory把convS表示为S^(d+1)与闭单纯形的连续像，故convS紧。此处不需要先证明ΣC_a闭。
2. **零和与凸组合双向成立。** 非零段按长度归一，得到0的凸表示；反向把正权重乘回单位向量即可。零权重去掉后，每段非零。按采用的常量锥、平移和自由切换权限，向量零和才可解释为实际同一点的接力候选。
3. **严格余量成立。** 0不在紧凸集K时，最近点z≠0满足z·(s−z)≥0；取单位n=z/||z||得所有s∈S上n·s≥||z||>0。反向对闭环求和直接矛盾。最短点存在性和不等式均已具备完整前提。
4. **段数和传播包络范围正确。** d+1是采用空间维数给的有限证书上界，不是最小段数、部门数或空间维数推导。单位n、σ≤1给报告(4)的横向上界；此界随辅助范数运输，未被认作唯一物理度规或光速。
5. **必要边界已保留。** 非闭上半平面加正水平射线确实无有限零和却没有严格共同n。一般曲流形的可积性／拓扑、有限任务样本到全部截面的升级，都没有被该证明覆盖。

下列片段保存这项独立算法和异质噪声证书。使用既有Python、Fraction与NumPy环境；不安装依赖，不计新增科学组。

```python
from fractions import Fraction as F
from itertools import combinations, product

axes = [[F(1),F(0),F(0),F(0)],
        [F(-3,5),F(4,5),F(0),F(0)],
        [F(-3,5),F(-4,5),F(0),F(0)]]
points = []
for u in axes:
    for j in (2,3):
        for sg in (-1,1):
            p=u[:]; p[j]+=F(sg,8); points.append(p)
def det(A):
    if len(A)==1: return A[0][0]
    return sum(((-1)**j*A[0][j]*det(
        [r[:j]+r[j+1:] for r in A[1:]])
        for j in range(len(A))), F(0))
counts = []
first = None
for size in (2,3,4):
    count = 0
    for subset in combinations(range(12),size):
        A=[[points[j][r] if r<4 else F(1)
            for j in subset] for r in range(5)]
        b=[F(0)]*4+[F(1)]
        for rows in combinations(range(5),size):
            M=[A[r] for r in rows]; bb=[b[r] for r in rows]
            d=det(M)
            if not d: continue
            w=[]
            for c in range(size):
                B=[r[:] for r in M]
                for r in range(size): B[r][c]=bb[r]
                w.append(det(B)/d)
            if all(x>0 for x in w) and all(
                sum(x*y for x,y in zip(ar,w))==br
                for ar,br in zip(A,b)):
                count+=1
                if first is None: first=(subset,w)
            break
    counts.append(count)
assert counts==[0,0,16]
assert first[0]==(0,1,4,9)
assert first[1]==[F(3,16),F(3,16),F(5,16),F(5,16)]
func=list(product(range(2),repeat=2))
hist={0:0,1:0,2:0}
for fs in product(func,repeat=3):
    z=sum(all(bits[(j+1)%3]==fs[j][bits[j]] for j in range(3))
          for bits in product(range(2),repeat=3))
    hist[z]+=1
assert hist=={0:4,1:56,2:4}
eps=[F(1,20),F(1,10),F(1,7)]
zs=[]
for flip in (0,1):
    z=F(0)
    for bits in product(range(2),repeat=3):
        q=F(1)
        for j,e in enumerate(eps):
            wanted=bits[j]^(flip if j==0 else 0)
            q*=1-e if bits[(j+1)%3]==wanted else e
        z+=q
    zs.append(z)
assert zs==[F(53,35),F(17,35)]
print(counts, first, hist, zs)
```
