## 3 原文核查及成熟结果边界

**Hamilton代数。** [Sahoo，quant-ph/0301044v3，§III与§V](https://arxiv.org/html/quant-ph/0301044v3)的定理1允许不同量子常数的两个代数组合，式(24)/(42)保留局部Lie括号的比例。统一常数是在另采用式(43)的局部括号限制条件后，由式(42)—(45)得到。故“能复合／有交互”与“保局部括号归一”不是同一个输入。本审计不把该成熟结果作为新定理。

**关系钟。** [Hausmann–Schmidhuber–Castro-Ruiz，2308.10967v4，§4—5](https://arxiv.org/html/2308.10967v4)已区分有限资源钟下的twirled-observable与purified-measurement任务；它们可以给不同的条件演化。§4.1已经给有限钟的物理能谱交集限制。仅重推Page–Wootters谱匹配、条件内积或有限钟非幺正，并不能确定共同能源来源，更不能把两种实验合同的差别改称物理矛盾。因此未把它作为本次正式候选。

以上是原文采用。下面的短判据及反例由本次直接计算，范围是给定有限矩阵和实际任务账目；不声称新发现普朗克常数唯一性。

## 4 精确双账交换判据

设有n个部门，给定同一时间参数t、各自可校准的能源算符E_i，以及隔离接口上的生成元字典K_i=a_iE_i+b_iI，a_i>0。只有在时间和能源单位已共同标定后，a_i差异才有物理意义；这里不允许事后分别换单位消去差异。把其余钟、控制、相互作用及环境全部列入，写

$$
Q=\sum_iE_i+Q_R,\qquad K=\sum_i a_iE_i+K_R+\text{常数}.
$$

K为实际闭合自主演化的生成元，因而其平均值守恒。Q是另经共同来源字典识别的能源；要求本次任务中它也守恒。**这个Q的身份和守恒是前提，不能把任意对易量都改名能源。** 不要求全体数学操作均可实施。

对每个声明且已实现的任务r，定义初末平均能源差x_i^(r)=Δ〈E_i〉。若辅助部分满足Δ〈Q_R〉=Δ〈K_R〉=0，则

$$
\mathbf1\cdot x^{(r)}=0,\qquad a\cdot x^{(r)}=0. \tag{1}
$$

这里仅需要两份辅助账的期望复位；完整辅助态复位是充分但更强的条件。残留关联可以存在，前提是所有跨边界项均已进入Q_R、K_R并实际核算，不能以辅助边缘未变代替这些项复位。

令M的各行为实际x^(r)。在这些账目能够提供的约束范围内，

$$
M\mathbf1=0,\quad Ma=0;
\qquad
\boxed{\ker M=\mathrm{span}\{\mathbf1\}
\Longleftrightarrow\mathrm{rank}M=n-1.} \tag{2}
$$

当且仅当右侧成立，这些方程迫使a_1=…=a_n。若秩更小，取非恒定b∈kerM，a=1+εb在足够小的非零ε下仍逐项正且不相等，故仅由账目不能统一。此逆向只表明线性约束未排除，不保证每一正a都存在完整物理实现；下一节另外给真实有限矩阵实现。

若声明菜单确实包含连通图上每一条边的非零纯二部门交换x=q(e_i−e_j)，其关联矩阵秩n−1，因此足够。**仅声明存在多部门相互作用、或把多体反应画成连通超图，不够。** 两部门非零交换是n=2的特例。

有限误差下，令r_E=Δ〈Q_R〉、r_K=Δ〈K_R〉；精确总守恒给1·x=−r_E、a·x=−r_K。若总守恒本身仅在误差内成立，还需分别加入其残差。它们不能隐去后继续使用(1)。本次不优化奇异值误差界，因为那仍是既定菜单的稳定性分析。

## 5 三部门连通、两份守恒、换算不统一的反例

三个qubit，N=|1〉〈1|，下标标部门：

$$
(E_A,E_B,E_C)=(N_A,N_B,2N_C),\qquad
a=(1,3,2),
$$


$$
V=|110\rangle\langle001|+|001\rangle\langle110|,
\quad Q=E_A+E_B+E_C+V,
\quad K=E_A+3E_B+2E_C+V. \tag{3}
$$

E_i、Q、K均非负；Q谱为(0,1,1,1,3,3,3,4)，K谱为(0,1,3,3,5,5,7,8)。两被耦合态具有同一裸能源2和同一裸生成元本征值4。因此[Q,K]=0；真实自主酉exp(−itK)严格保持Q全部谱概率及K，不只保持其均值。

初态|001〉在t=π/2变为相位乘|110〉。过程中

$$
|\psi(t)\rangle=e^{-4it}
(\cos t|001\rangle-i\sin t|110\rangle),
\qquad x(t)=\sin^2t(1,1,-2).
$$

全程〈V〉=0，因此初末两份相互作用账均复位；但M只有一个独立方向，rankM=1<2。a·(1,1,−2)=0且1·(1,1,−2)=0。三部门在同一相互作用里全部出现，换算仍未统一。额外不变量N_A−N_B解释剩余自由：K=2Q+(N_B−N_A)−V，且此模型中N_B−N_A、V均守恒。

式(3)是一份数学上自洽的给定Q/K字典反例，针对“连通＋守恒已够”的推理。它没有证明真实能源来源就是Q，也没有实现全体A1—A7、实际独立能源校准或通用记录装置。因此不能据此声称现实世界有多个普朗克常数。初态准备及末端人口读数是声明的有限校准权限。

**未复位相互作用的两部门对照。** 取同隙E_A=N_A、E_B=N_B，K_0=E_A+2E_B，V=|10〉〈01|+h.c.，K=K_0+V，Q=E_A+E_B。从|10〉出发，在t=π/√5转移概率4/5。Q守恒且交互非零，但Δ〈K_0〉=4/5、Δ〈V〉=−4/5。失谐由真实相互作用账补偿；删除它会伪造(1)。此对照也未提供Q的共同来源身份，作用仅是显示“自主＋有交换”不能替代复位条件。

## 6 可复算片段与实际运行

使用既有Python及NumPy，2026-10-08实际运行。没有安装依赖、生成图片或写入作者冻结资产。以下片段可直接复算全部关键反例；其有限检查不是一般秩判据的证明。

```python
import numpy as np
I = np.eye(2)
N = np.diag([0., 1.])
k = np.kron
E = [k(k(N,I),I), k(k(I,N),I), 2*k(k(I,I),N)]
a = np.array([1.,3.,2.])
E0 = sum(E)
K0 = sum(x*y for x,y in zip(a,E))
V = np.zeros((8,8)); V[1,6] = V[6,1] = 1
K, Q = K0+V, E0+V
psi = np.eye(8)[:,1].astype(complex)
def evolve(H,v,t):
    w,U = np.linalg.eigh(H)
    return U @ (np.exp(-1j*w*t)*(U.conj().T@v))
def ev(A,v):
    return float(np.vdot(v,A@v).real)
out = evolve(K,psi,np.pi/2)
flow = np.array([ev(x,out)-ev(x,psi) for x in E])
M = np.array([[1.,1.,-2.]])
assert np.allclose(flow,[1,1,-2])
assert np.linalg.norm(K@Q-Q@K,2) == 0
assert np.linalg.matrix_rank(M) == 1
assert np.allclose(M@a,0)
assert abs(ev(V,out)-ev(V,psi)) < 1e-14
print(flow, abs(out[6])**2, np.linalg.eigvalsh(Q))
EA,EB = k(N,I),k(I,N)
V2 = np.zeros((4,4)); V2[1,2] = V2[2,1] = 1
K02 = EA+2*EB
K2,Q2 = K02+V2,EA+EB
p2 = np.eye(4)[:,2].astype(complex)
o2 = evolve(K2,p2,np.pi/np.sqrt(5))
assert np.linalg.norm(K2@Q2-Q2@K2,2) == 0
assert np.allclose([abs(o2[1])**2,
    ev(K02,o2)-ev(K02,p2),ev(V2,o2)-ev(V2,p2)],[.8,.8,-.8])
print(abs(o2[1])**2, ev(K02,o2)-ev(K02,p2),
      ev(V2,o2)-ev(V2,p2), ev(Q2,o2)-ev(Q2,p2))
```

实际值：三部门流为(0.9999999999999996,0.9999999999999996,−2)，转移概率0.9999999999999996，相互作用账差4.48×10⁻¹⁷；[K,Q]范数0。两部门转移0.7999999999999994，裸K账差0.7999999999999989，相互作用账差−0.7999999999999998，Q账差−4.44×10⁻¹⁶。
