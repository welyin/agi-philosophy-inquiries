## 2. 一般证明复核

1. 中心元素z在(a,b,n,q)上的字符为 \(\exp[2\pi i(2(a+2b)+3n+q)/6]\)。对 \(\Gamma_p=\langle z^{6/p}\rangle\) 下降恰是原式(1)。没有将p阶子群与余中心的6/p阶混淆。
2. 固定SM菜单中，z在每个字段上平凡，因此也在任意词及子表示上平凡。p<6的纯荷p单态确实能下降至G_p且有非平凡z字符；这直接排除任意词长，有限扫描不是必要性证明。
3. p=6时，颜色D、Dbar和弱H的Cartan最高权分量为(a,b,n)，总荷q0=−2a+2b+3n。中心条件与q−q0可被6整除等价。加E或其共轭补荷完成充分性；完全可约性保证最高权分量确实出现。
4. 开放菜单加一对±p单态后，q−q0可被p整除，对每个p均完成相同构造；残核恰为Γ_p。允许质量及所列局部反常均逐项相消。它没有证明全部全局反常或低能修正严格为零。

## 3. 审阅者独立计算

没有导入作者科学函数；通过Python标准库在内存中执行下面两项算法。

**完整中心网格。** 枚举 \(\mathbb Z_3\times\mathbb Z_2\times\mathbb Z_{60}\) 的360点，以所有SM字段的实际中心字符直接求核，不先假定核是z的幂。得到

```text
[(0,0,0), (0,1,30), (1,0,40), (1,1,10), (2,0,20), (2,1,50)]
```

这恰为 \((k\bmod3,k\bmod2,10k)\)。加入荷p单态后，p=1,2,3,6的核大小分别为1,2,3,6。完整连续中心核还由E的荷6先将U(1)相位限到这六值，因此本有限网格没有遗漏潜在的连续核。

**表示分解。** 使用Pieri递推而非作者的张量升算符矩阵：

\[
(a,b)\otimes3=(a+1,b)\oplus(a-1,b+1)\oplus(a,b-1),
\]

共轭基本表示的规则交换a、b；删去负指标。对0≤a,b≤7的64份 \(3^{\otimes a}\otimes\bar3^{\otimes b}\)，逐步保存全部不可约重数。目标(a,b)重数恒为1，且 \(\sum m_{uv}(u+1)(v+1)(u+v+2)/2=3^{a+b}\) 精确成立。最大总维数4,782,969，只用整数递推，没有分配这一尺寸的稠密矩阵。该独立实现支持最高权构造，但全体表示量词仍由§2证明承担。

最小复算核心如下（Python标准库）：

```python
from collections import Counter
def step(c, anti):
    out = Counter()
    for (a,b), multiplicity in c.items():
        terms = ([(a,b+1),(a+1,b-1),(a-1,b)] if anti
                 else [(a+1,b),(a-1,b+1),(a,b-1)])
        for item in terms:
            if min(item) >= 0:
                out[item] += multiplicity
    return out
for a in range(8):
    for b in range(8):
        c = Counter({(0,0): 1})
        for j in range(a+b):
            c = step(c, j >= a)
        assert c[(a,b)] == 1
        assert sum(m*(u+1)*(v+1)*(u+v+2)//2
                   for (u,v),m in c.items()) == 3**(a+b)
```
