## 2. 解析结论复核

1. 全左手归一下，SM一代的X荷及重数给15个模4荷1分量；N也是荷1，H荷2。$\nu=15n_g+n_+-n_-$ 的模16条件正确。
2. 任意三代合法菜单仅满足 $n_+-n_-=3\pmod{16}$。最少总新增数目才给唯一(3,0)；允许任意代数时n₊=n_g均可，所以没有预测三代或每代必须配一份N。
3. 连续U(1)_X另有 $\sum X=5(n_N-n_g)$、$\sum X^3=125(n_N-n_g)$，比离散同余严格。普通spin、Spin-Z4和连续U(1)不得互换。
4. ℓ=lH的荷为3，故ℓN中性、NN和ℓℓ均为荷2。H†H插入不改变它；原45分量与固定非零C₅不能直接采用精确K_X。反常抵消与作用不变性是两项独立检查。
5. 荷2实标量S使SNN中性；$U^TK(-S)U=K(S)$ 真正移动了背景。把S冻结而保持原变换不是同一个精确对称。Schur匹配及C₆伸缩自由在其树级质量类别内成立。

## 3. 独立η核算：不复用作者立方公式

从原文式(2.48)的五维透镜空间L(2;1,1,1)直接求和。唯一非平凡根λ=−1，普通Z₂荷s与奇Z₄荷q满足q=2s+1；因此

$$
\eta=\frac12\frac{(-1)^s(-1)^2}{(1-(-1))^3}
=\frac{(-1)^s}{16}\pmod1.
$$

这给一个模16生成检测，复核原稿的手征符号和归一。用Fraction对q=−101,−99,…,101的102份奇荷计算此单根表达，再与原稿第一坐标比较，差全部为整数；取值仅1/16和15/16。一般反常分类及其生成性仍采用原始定理。

```python
from fractions import Fraction as F
for q in range(-101,102,2):
    s = (q-1)//2
    lens = F(1,16) * (-1 if s % 2 else 1)
    polynomial = F(11*q**3-5*q,96)
    assert (lens-polynomial) % 1 == 0
```
