## 已得候选恒等式

沿785/786的P,K,L,Pi。令另一线性规范条件为F，A=FK；假定A及A†在所声明局部支持类别有双侧退迟/超前Green逆G_A±、G_A†±。原波型规范F=K†满足A=K†K=−D0；切片端F=L满足A=I。定义

```
T_F± = I − K G_A± F
Tdual_F± = I − F† G_A†± K†

G_F± = [[T_F± G_Pi± Tdual_F± − xi K G_A± G_A†± K†, K G_A±],
        [G_A†± K†,                                      0    ]].
```

注意同号ret/adv的Tdual不是简单写成(T_F±)†；形式伴随会交换ret/adv，应为(T_F∓)†。通过方程

```
P v + F† b = j,
F v + xi b = beta,
A† b = K† j,
v = w+Kq, Lw=0
```

先解b，再解受约束w及Aq，可导出上述块核。纯代数消去给

```
Pi (G_F±)vv Pi† = G_Pi±.
```

因此若只比较**同一自由物理子代数**，可在取任何规范参数极限之前完全消去规范依赖，不必先证明整份非物理传播核平滑收敛到零阶接触。这没有证明非线性插入或量子接触也可同样交换极限。
