# 第1410—1452轮　家族交换、真空相位与质量层级

[阶段总目录](../README.md) · [第18篇论文](../18_标准模型的条件选择与现实参数的剩余自由_阶段论文.md) · [全阶段参数账](../archive_1798_1815/_shared/standard_model_coverage.md)

如果用少数交换或共同真空为不同家族赋予质量和相位，哪些夸克、轻子及核反应还能独立检验？

两次等幅味交换给出 CKM 元素比与夸克质量比的关系，可由树级衰变检验。在指定双 Higgs 真空和同序实旋转下，夸克 CP 相位可预报相反的轻子相位。九个带电质量还可限制特定味标量的轴子—光子反常。 [第1412轮](research_note_1412.md) · [第1416轮](research_note_1416.md) · [第1428轮](research_note_1428.md) · [第1445轮](research_note_1445.md) · [第1450轮](research_note_1450.md)

这些关系随实旋转次序、味荷、标量作用和新增交换改变。振荡数据与一个相位预报相容，仍容许其它来源。

第1410轮提出三端循环选择。第1452轮核对实现味层级的信使在规范跑动中的作用，第1453轮转入统一表示的三代质量和式。
