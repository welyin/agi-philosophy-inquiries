# 第1746轮准入

研究对象为第1744轮物质谱上的家族共同作用。第1743轮独审给出秩二不变量与 Majorana 相位上界，第1745轮排除了固定家族轴的对角收缩。新增的是指定三奇异值的全方向逆判据、独立的可复算非对角解、真实分段低能见证和该实例未用于选点的重端 Higgs 源重叠。验收项为主程序、独立程序及从见证重新反推物质顶角的补充程序，均使用原 Python 与 NumPy。适用范围为三条正的带电奇异值、秩二正常排序、两条非简并的非零白化 Takagi 值及非零加权干涉。适用的一圈模型、家族来源与两部门定标分别记账。新增认知公理零，独立定出的现实标准模型参数零。[研究报告](../research_note_1746.md)
