# 第1709—1752轮　共同味传递的物质实现与独立质量检验

[阶段总目录](../README.md) · [第18篇论文](../18_标准模型的条件选择与现实参数的剩余自由_阶段论文.md) · [全阶段参数账](../archive_1798_1815/_shared/standard_model_coverage.md)

已有味方向如何由实际重质量矩阵传递？撤掉下夸克质量、重组家族投影或测量质子衰变后，机制还保留哪些预报？

在具名回返规则中撤掉下夸克质量仍有合格见证。夸克到轻子的同一转接可以连到中微子振荡、格点质量比和质子衰变。家族对角方案受限后，非对角作用仍存在共同解；在部分具体模型上，两条已知中性源与带电谱将其连续强度压缩成有限候选。 [第1712轮](research_note_1712.md) · [第1718轮](research_note_1718.md) · [第1725轮](research_note_1725.md) · [第1732轮](research_note_1732.md) · [第1746轮](research_note_1746.md) · [第1748轮](research_note_1748.md) · [第1752轮](research_note_1752.md)

非对角方向、反射的符号和重质量实现需要物质来源。实际搜索排除的是给定接线和匹配方案，其他同谱模型可保留不同作用。

从检验夸克幅能否决定中性源开始，到中间谱线反号的完整色行列式。第1753轮撤去三代先验，反问交换实验能计数多少家族。
