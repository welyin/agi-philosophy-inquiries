# 第1545—1585轮　统一物质表示、两源质量与家族数

[阶段总目录](../README.md) · [第18篇论文](../18_标准模型的条件选择与现实参数的剩余自由_阶段论文.md) · [全阶段参数账](../archive_1798_1815/_shared/standard_model_coverage.md)

在已给定物质表示和破缺背景时，哪些条件能选择家族数、超荷嵌入或中微子质量？

指定 Pati–Salam 场表的离散重子保护与左弱耦合斜率可把家族数选为三。在指数一、完整 SU(N) 表示和无额外净手性等条件下，净物质谱唯一固定标准超荷方向及六阶中心商群像。对两份复对称味张量的纯 I 型候选，十九个指定观测量可有十九个独立局部变化方向。 [第1545轮](research_note_1545.md) · [第1554轮](research_note_1554.md) · [第1556轮](research_note_1556.md) · [第1572轮](research_note_1572.md) · [第1573轮](research_note_1573.md) · [第1578轮](research_note_1578.md)

群像与家族数的判定均有明确表示条件。具备所需净指数的候选仍可能留下许多无质量伙伴；局部满秩也不保证全实验窗有解。

第1545轮联合家族计数与绝对规范斜率，第1585轮以左右双双重态的两个味变通道收束。第1586轮转向凝聚、辐射等质量形成机制。
