# 908工作记录：原材料闭环的完整第一jet来源

日期2026-10-06。正式仍907／累计3692，尚未新增轮次。

已实现磁参考Mh对度规、时钟梯度及颜色曲率的独立离壳变化，接原三类关系读数的直接连接项和路径位移项。背景由902同一原初值在±.00025内演化，有限Fourier/Hermite只作数值求值工具；尚无连续时空误差证书。

首次装置候选将中心Jacobian作用于物理方环，当作整个固定材料曲线。这只是切向近似，不是原有限曲线的材料像：L=.08的中心环也出现逆图求解失败。原失败参数和残差见initial_anchor_failure.json。检查实际初始曲率后，改用901已保存的显式初始ψ多项式，将同一个L=.08物理方环的完整非线性材料像固定为标签曲线，不重新拟合场变分或网格细化后的曲线。

该固定曲线通过中心环检查；较宽四维锚点候选仍未通过，未签收为物理装置。将未定装置的x/y锚点宽从.002改为.00002后，16个四维求积锚点的逆图可解，环大小L=.08保持。最终候选宽为(2e−5,2e−5,2e−5,.005)，使用固定紧光滑bump。这是863允许的局部原测量菜单的一次明确实例化，不能据此删除将来要求恢复的更大尺度实验。所有采样点可解也不是完整支持的连续证书。

当前已有三份原合法表示读数、完整第一jet弱来源，纯颜色规范与时空平移检查。初次结果中度规与探针即使没有直接连接变化，也通过材料路径给非零响应；下一项独立重建扰动后的路径做有限差分，并检查路径、锚点及背景细化。完整强来源数组、Π†、受迫总和和观测误差仍未完成。
