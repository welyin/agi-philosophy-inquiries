正式报告、科学代码、结果及当前迁移清单纳入Git。README、研究方向、研究状态只在正式位置维护一份，修改记录交给Git；重复导航备份、迁移ZIP及旧版大型清单不再作为研究依赖。外部原始PDF按来源收据取得，详见[版本管理说明](../scripts/GIT_STORAGE.md)。
