- **[第369轮：模包含与有限维几何接口](archive_231_/research_note_369.md)**：核对半侧模包含的共同表示条件；有限代数不能给非平凡共同循环真包含，仿射生成元有全范数障碍，但指定观测窗口允许保参考的受控近似。14项检查。
- **[第370轮：雷达记录与端口辨识维数](archive_231_/research_note_370.md)**：同样三字段适用于任意给定d；空间局部辨识秩为1加端口切向响应秩。粗端口、重复随机读出与新增观察点的能力分别记账。14项检查。
- **[第371轮：方向比特定理与概率角度](archive_231_/research_note_371.md)**：对接Müller–Masanes三维定理；方向最小性和物理旋转接口仍为输入。非正交混态概率可恢复角度，并给含Gram校准误差的界。14项检查。
- **[第372轮：量子位正锥与Lorentz接口](archive_231_/research_note_372.md)**：复量子位正锥给既有1＋3锥对应；主动boost须计完整过滤分支，被动表示须连同归一化效应变换。归一化态的正序不能直接充当事件因果序。18项检查。

- **[第374轮：稳定两带交叉与Weyl来源](archive_231_/research_note_374.md)**：一般光滑两带交叉的余维三及C²线性化给条件性Weyl接口；非零拓扑荷不保证满秩或不可分裂，周期模型保留双节点与湮灭条件。13项检查。

- **[第375轮：兼容连接与完整传播辨识](archive_231_/research_note_375.md)**：固定LC时兼容旋量连接只剩中心一形式；放宽无挠后存在五维连接核，曲率非零但完整Weyl传播不变。另用指定Landau块区分会改变传播的中心曲率。16项检查，几何、无挠与场动力学来源仍未推出。
- **[第376轮：方向秩与可达空间](archive_231_/research_note_376.md)**：三个光滑输运方向的局部秩不固定可达维数：指定模型中不可积时可达四维，可积时各叶三维；给出精确回路、有限资源分辨界和保参考量子接口。14项检查，控制与位置读出仍为输入。
- **[第377轮：各向同性与位置身份](archive_231_/research_note_377.md)**：完整水平各向同性仍允许三个局部方向生成六维构形、控制球体积指数9；仅访问位置商时可保留三维描述。13项检查，构形可读性不自动等于物理位置身份。
