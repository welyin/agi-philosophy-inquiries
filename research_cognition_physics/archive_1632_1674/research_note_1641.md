# 第1641轮　用奇底介子的两个树衰变读取同一弱相位

用 $B_s^0\to D_s^-K^+$ 和 $D_s^+K^-$ 的时间变化组成一对复数，二者相除即可消去强相与未知衰变幅比，留下树角 $\gamma_s$ 与混合角之和。直接使用 LHCb Run 2 的四个实测干涉系数及其相关矩阵，得到总角 **72.31°**，$\Delta X=1$ 的剖面为 **61.29°–83.82°**。实验结合 Run 1 和 Run 2 后独立发表的总角为 **$79^{+12}_{-11}$°**，两者包含重复样本。[推导和来源](1641/proof.md)

该组合与已登记的混合控制角共同给出一宽树角 **69.203°–95.985°**；加入2024年带电 $B$ 样本，并沿用其粲与中性 $K$ 校准后，缩为 **69.203°–74.800°**。第1639轮普通三代旋转在全质量带、全部奇底相位上只能给 **66.4595°–66.4705°**，所以这一宽间隔至少 **2.732°**。两宽或单用 Run 2，间隔消失。新读数能检验此前固定的普通旋转，并没有选定唯一角度或排除整个物质表示。新增公理0，独立定值的现实参数新增0。[复算结果](1641/results.json) · [独审](1641/independent_review.md)
