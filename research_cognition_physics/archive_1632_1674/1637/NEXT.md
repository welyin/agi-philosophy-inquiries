# 第1637轮后续判别

优先检验下型单态和异超荷双态的反向 Yukawa 元能否由已登记的内部表示选择律强制为零，或能否把乘积 $KE$ 对齐。用同一批保证非零底投影的普通电弱 Yukawa 和硬质量逐项检验。若要引入额外对称、软破缺或自由相位，先登记可检验后果。另一项独立检验是向该纹理传递同一上型顶味方向，查看是否出现不对齐的不变量。

实际比较中子数据前，应核定匹配尺度、在同一 UV 基中的完整有色行列式、其他 CP 奇算符及其对 EDM 的贡献。只算出规范允许的边或一个阈值灵敏度，无法给出 UV 阈值的真实大小。若有独立 UV 模型，固定其系数后再检验本轮的精确相位扇区；检验失败时可直接排除该组系数和匹配假设。
