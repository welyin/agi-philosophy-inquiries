# 第1632轮独立审阅　下型单态的换味中性流与两种介子读数

**复核结论。** 在所列低能字典、矩形工作窗及 LHCb Run 3 的接受条件下，规范耦合给出的同号左手 $Z$ 幅，无法同时通过两种稀有衰变和带电半轻子检验，除非登记的普通短程振幅还含有足够大的剩余项。CMS 两宽、混合相位完全自由时，在归一化比较中仍有毗邻的圆盘边缘。两份缪子样本分别使用。[独立程序](independent_check.py) · [所有输出](independent_results.json)

## 规范与味因子

对三只标准弱双态与两只下型单态，$K$ 为带电流的 $3\times5$ 子块，$F=K^\dagger K$。对沿 Higgs 真空方向的一只物理标量，$vY_h=F\,{\rm diag}(m_i)$。三种中微子味分别感受同一 $Z$ 作用。按中微子全流 $1-\gamma_5$ 和缪子轴流 $\gamma_\mu\gamma_5$ 归一，它们的标准轻子 $Z$ 顶角系数相同。在左手夸克源下，固定普通振幅参考后有 $A_\nu=1-k+kP_\mu$，所有量可为复数，$k=C_{10}^{\rm SM}/C_L^{\rm SM}\in[0.60,0.70]$。正交轻中微子末态求和给 $R_\nu=|A_\nu|^2$。第1406轮只选一代轻子投影，第1464轮的相对号来自右手夸克流；此处使用它们保存的数据，不移植其味张量。[第1406轮输入](../../archive_1364_1409/1406/inputs.json) · [第1464轮物理量归一](../../archive_1453_1496/1464/proof.md)

## 双缪子时钟的全复相位检验

若 CMS 的双缪子信号轴与普通重态时钟对齐，$P_\mu=x+iy$ 满足 $x^2+w y^2\le R_\mu^{\max}$。对固定 $k,w$ 在椭圆上求最远点，是区间 $|x|\le\sqrt{R_\mu^{\max}}$ 上的凹二次优化。全 $k$ 窗只需比两个端点，因为固定 $P_\mu$ 后振幅模是 $k$ 的凸函数。两宽 $w\ge0.75$ 给出 $R_\nu\le1.37454$，低于 Belle II 矩形下端 1.70497。允许模板时钟相对于普通弱相位有任意取向，则外包只给 1.70922。

对上面这条狭窄交界，令 $\chi$ 为椭圆重轴相对于普通实轴的最小无向夹角。所有时钟角的振幅模上确界可由单位方向投影计算：

$$
\max_{0\le\theta\le\pi/2}\big[(1-k)\cos\theta+
 k\sqrt{R_\mu^{\max}}\sqrt{1+(1/w-1)\sin^2(\theta+\chi)}\big].
$$

反射可将最优方向选在该象限，再取 $\theta+\chi\le\pi/2$；超过它时减小 $\theta$ 可同时改善两项。这个最优值随 $\chi$ 单调不降。程序在 32768 等间隔上对解析函数加最近网格的 Lipschitz 误差，角导数绝对值上界为 $1-k+k\sqrt{R_\mu^{\max}}(1/w-1)/2$，另按振幅加 $10^{-13}$ 的浮点余量。在最宽松的 $w=0.75$ 处，CMS 两宽与 Belle 下端能有交集所需的轴幅临界倾角在 **81.10°—81.25°**。独立标量分量、效率或相位观测会进一步限制可行性。此角是针对模板的数学条件，没有给混合相位赋予实测值。

LHCb 2024—25 年独立 Run 3 样本的 $w\ge0.78$ 如成立，则对任意钟相位都给两宽 $R_\nu\le1.40819$。若增添右手 $Z$ 幅，记 $P_\mu=1+z_L-z_R$、$A_\nu=1+k(z_L+z_R)$。因此即使容许任意钟取向，恢复这一下端仍需 $|z_R|\ge0.08505$，单位是普通双缪子轴幅。可再用不同末态检验这样的右手作用。[Belle II](https://arxiv.org/abs/2311.14647) · [CMS](https://arxiv.org/abs/2212.10311) · [LHCb](https://arxiv.org/abs/2611.00230)

## 放开普通左幅后由带电流独立检验

按第1464轮绝对单位，$N=L+F_{sb},P=kL+F_{sb}$。独立程序从公开率、时间、格点衰变常数与形状因子标定重新计算 $(n_-,n_+,p_+)$。两个环相减给 $|L|\ge (n_- -p_+)/(1-k)$，$F=(P-kN)/(1-k)$。在 LHCb Run 3 两宽，这要求 $|L|\ge0.0009014728$、$1.7539\times10^{-5}\le |F_{sb}|\le0.00615933$。

只用矩形 $|K_{cb}|\le0.046,|K_{ub}|\le0.005$，令 $C=|K_{us}K_{ub}|+|K_{cs}K_{cb}|$，对 $s$、$b$ 列的 $u,c$ 两分量应用柯西不等式得 $C\le\sqrt{0.046^2+0.005^2}$。这是五态弱流投影的约束。以 $c\le0.017$ 表示共同归一的顶环系数绝对值，附加振幅余量为 $\epsilon$，则从 $|L|\le c(C+|F_{sb}|)+\epsilon$、$|F_{sb}|\le p_++k|L|$ 推出

$$
\epsilon\ge (1-ck)\frac{n_--p_+}{1-k}-c(C+p_+).
$$

右侧随 $c$ 增大而减小。对 $k$ 的导数为 $(1-c)(n_--p_+)/(1-k)^2>0$。LHCb Run 3 两宽要求 $C\ge0.0519635$（若 $\epsilon=0$），或 $\epsilon\ge9.67750\times10^{-5}$（若承接带电输入）。即使放开顶环上盖到接近 0.0190444，这个矩形仍有正的剩余幅要求。额外矢量样重物质的一圈、其他味源、强子与接受度的传递均需按其实际算符重新匹配。如果还有独立的双缪子赝标量可以相消，需另给它的幅度预算。CMS 两宽按自由时钟处理，只用这些条件时没有正的剩余幅下限。

## 希格斯握合与反例范围

物理 $h$ 标量通过 $\bar s(F_{sb}m_bP_R+m_sF_{sb}P_L)b/v$ 换味。相对于新 $Z$ 轴流在 $B_s$ 中的幅度，其标量双缪子幅模比含 $m_{B_s}^2 |m_b-m_s|/[m_h^2(m_b+m_s)]$（强度还有轻子速度因子）。在 $m_h=125.1$ GeV 时不超过 0.001841。缪子自旋求和把标量和赝标量分开，未用小数值来论证零干涉。两 CP 分量在同一未标记时钟模板下分别给非负贡献。

独立脚本在狄拉克表示中求质量非零的自旋迹，将 $h\to b\bar s$ 和 $h\to s\bar b$ 分别计入。若以同一个树级质量字典作示例，取 $(m_h,m_b,m_s)=(125.1,2.8,0.055)$ GeV，$[\Gamma_{bs}+\Gamma_{sb}]/\Gamma_{bb}^{\rm SM,Born}=1.0023941 |F_{sb}|^2$。完整强子宽度需要在相应的方案、标尺和运动学下算 QCD 与顶角修正；实际 $hbb$ 顶角还含 $F_{bb}$。若有第二个 Yukawa 方向、独立右手交换，或对全部额外振幅不作预算，当前树级对应会改变。

框内结论为同一候选的条件判别。无新认知公理，无新现实参数独立定值。
