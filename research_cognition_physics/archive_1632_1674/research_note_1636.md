# 第1636轮　同一批重夸克能否同时解释奇底衰变和奇底振荡

固定第1635轮的底、奇混合及相位，单独报出的双缪子拟合率可以通过各自的一宽。独立的 $B_s$ 振荡改变了结论。只算普通顶箱与树级同手征 $Z$ 时，两点都给 $17.609\ {\rm ps}^{-1}$。把这只重双态本身产生的右手硬箱，以及右手电流经顶 Yukawa 产生的混手征项一并加入后，1.6 和 2.6 TeV 两个质量点分别给 **23.002、24.844**，实测为 **17.7683**。重质量可通过混合箱区分原来在稀有率上几乎简并的两个点。[推导及原始文献](1636/proof.md)

在保留的两宽格点与匹配范围、控制衰变相位预算 0.020 rad 内，要同时接回实测频率和相位，两点各需至少 **13.70% 和 20.13%** 的额外复混合幅。回代同一时钟后的 LHCb Run 3 双缪子率仍分别为 $3.690$ 和 $3.696$，单位 $10^{-9}$。这个缺口约束已计算的两点和匹配内容；其它相位、重阈值以及完整低能匹配仍可检验。新增公理0，独立定值现实参数0。[复算结果](1636/results.json) · [独审](1636/independent_review.md) · [下一步](1636/NEXT.md)
