# 第1632—1674轮　从底夸克弱荷到三代带电谱与中微子振荡

[阶段总目录](../README.md) · [第18篇论文](../18_标准模型的条件选择与现实参数的剩余自由_阶段论文.md) · [全阶段参数账](../archive_1798_1815/_shared/standard_model_coverage.md)

底夸克和奇夸克的弱流、同尺度的三代带电质量和中微子振荡，能否由同一味转接说明？

中性介子的有向树衰变可以限定弱相位。用夸克和部分带电轻子质量校准后，电子质量可作为留出；进一步要求同一带电标架同时承担反应堆与束流读数，便能检验原本自由的味相位。一个伴随态输运给出 3∶2 的两路幅及 7/25 的返回概率。 [第1632轮](research_note_1632.md) · [第1641轮](research_note_1641.md) · [第1657轮](research_note_1657.md) · [第1661轮](research_note_1661.md) · [第1669轮](research_note_1669.md) · [第1672轮](research_note_1672.md)

固定相位、固定能量切片和完整实验似然承担不同信息。3∶2 的返回还要求指定的物理回路和端点，不能单由群的表示维数得到实际传播。

从真实奇底介子与带电流联合约束开始，到重中性态在三种带电轻子上的弱流检验。第1675轮正式撤去 CKM 弱相位作盲检。
