# 第1641轮独立复核

从 LHCb 原表的五个系数、统计与系统两套相关矩阵重建高斯二次型，另将 $C_f$ 和两个干涉振幅的物理约束 $u^Tu=1$ 放回拟合。固定总相位时，写 $u=(D\cos\delta,D\sin\delta,C_f)$，以一个拉格朗日乘子解球面上的三元二次型。程序核验乘子半正定性、范数、驻点和模 $180^\circ$ 周期。数值角度搜索给 $72.034^\circ$，$\Delta\chi^2=1$ 区间为 $60.951^\circ$ 至 $83.726^\circ$；主报告的四系数值是 $72.308^\circ$。两者都只复算 Run 2，组合实验结果另行引用。[LHCb 测量](https://arxiv.org/abs/2412.14074) · [复算](independent_check.py) · [数值](independent_results.json)

由两份冻结轻带电矩阵直接计算 $\arg(\lambda_c/\lambda_u)$，都得 $66.464968^\circ$。采用组合样本一宽下端 $68^\circ$ 和校准后的混合角上端 $-0.021$ rad，必有 $\gamma_s\ge69.203^\circ$。和冻结旋转的整个奇底相位上界比较，间隔为 $2.733^\circ$。两宽、末态相位输入或实验样本变化时，这个结论按各自窗口重算。实验拟合的频率、寿命及粲相位校准随数据承接，独审不为不合格频率的候选赋予时间似然。
