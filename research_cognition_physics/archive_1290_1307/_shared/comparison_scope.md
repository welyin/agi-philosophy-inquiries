# 长程目标的共同有效比较范围 v1

2026-10-18。主线事前登记。本文落实[目标](goal.md)M1的比较范围，不修改目标，不增加公理或科学轮次，不表示M1的结构选择成果已经取得。已考虑[独立范围输入](comparison_scope_review_input.md)；其中所列原子／组合／有效层和S／Q／O资格区分在本比较中采用。

## 1. 比较什么

研究对象是同一认知操作体系能够容纳的物理有效实现，比较其**群与全局形式、物种／手性／代际／荷、相互作用、质量与混合、实际共同过程**。标准模型是重要比较分支；不把它的场表、三代、三个群因子或Higgs机制预先固定为整个类别的定义。

第一外层类别采用：已有时空与局域组合阶段所规定的有效四维背景接口；紧Lie内部群（允许有限群与不连通群）；每个模型有限的内部字段／表示和重数；每个任务明确的有效阶、有限时空域、正常准备与误差。四维与时空接口按后续已采用公理承接，不能因1062历史稿尚未闭合它们就重新列为全缺口。紧群、所选场论形式、谱／正性和特定参考相态仍各按其实际来源登记，不能全部倒称为四原则单独推出。

质量分支开放Dirac、Majorana、基元Higgs和具名的替代机制；维五及其它合法有效项不被静默排除。没有统一的物种数上限。尚未给具体作用或匹配的分支留作开放问题，既不算通过，也不算排除。连续规范场的证明不直接排除有限规范群；有限图父合同若没有认证映射，也不自动成为四维场论。

每份候选须填同一个对象账：有效域、全局群／背景菜单、字段／统计／表示、作用和相态、状态／参考、实际操作和后态、来源／资源、误差及公共任务解释映射。并列不同对象账不是共同实现证明。

## 2. 资格分层与比较规则

|层次|所需证据|可作的判断|
|---|---|---|
|S：结构|全局群表示、经典约束、质量和顶点许可、同一声明阶作用|该明确结构类中的必要关系或代数分类|
|Q：声明量子域|所调用的统计／正性／局域性、量子态和算符域，以及实际背景上的反常等一致性|指定域内量子一致；不等于全UV存在|
|O：共同操作|合法未知输入与任意被动伙伴、同一准备和实际交互、全部所需结果／后态、参考／控制／来源及有限误差|同一实际任务中的实现、排除或可辨自由|

每个结论写明其资格，不能把S、Q及另一对象的O拼成完整反模型。未知伙伴量词只作用于已声明合法码；Gauss区域、带电裸场或费米模式不自动领取独立张量子系统的全部权限。源均值、源涨落、资源分布与有界记录是不同测试，普通通道误差不会免费控制无界来源。

新增任务在计算前列明：公共输入和输出、原本允许的至少两个候选或分叉、匹配和固定量、新条件的认知含义与层次、失败标准、预计改变的结构判定。未经过具体任务认证的物理常数与成本权重保持输入身份。

## 4. 全链问题不得遗漏

|问题|下一证据必须解决的事|当前判定|
|---|---|---|
|群／全局商／荷格|新的独立任务是否跨接已有表示与实际来源；保连续／离散及全局背景差别|已有条件分类；整个共同类未终判|
|物种／手性／代际|有无独立要求限制字段或复制；若主张自由，扩展必须保共同资格|旧反常、质量数目与菜单条件可用；三代未生成，也未给全类自由证明|
|规范与物质顶点|1015、1016、1284等同作用关系在所选物种分支如何共同采用|条件接口已有，不重证；不是任意作用已唯一|
|质量机制、谱和流|Dirac／Majorana／其它质量机制怎样改变可访问的物理通道|1010—1014、1034—1036、1289等分叉保留；不由质量数值代替粒子身份|
|共同参考、记录与来源|扩展或比较的同一模型是否保实际调用权限与完整测试|已有具名O证书；不得拼成所有字段通用装置|
|量子与几何接续|已调用热学／CT／HG接口的对象、参考、来源和误差是否一致|现有有效引力结论继承；新物种不能因形式协变就免除新增来源|

上表中的“未终判”仍是未完成任务。不得把它改名为输入就通过目标§6.3；也不因此要求每一轮先解决全部UV或任意设备制造。

## 5. 已执行的首轮筛查与停止线

1. **原整数荷族混合反常：复用，停止。** 1060已经覆盖。重新做同态、母表示或数值矩阵没有新命题。
2. **电弱Higgs参考、弱流与相对味码：复用，停止纯代数扩建。** [独立筛查](../_admission/independent_lead_screen.md)给真实残余电磁荷的接线。共同Dirac质量和完整弱顶点对全部k仍相容；1289纯SU(2)的三方向不能未经着装就叫三个全电弱局部读口。已有荷表的有限中性响应阈值是条件推论，当前未由认知生成其实际测量前件。
3. **静态单模闭轨电荷相位：候选未准入，停止。** [完整平方检查](../_admission/charge_echo_screen/selection.md)复用965：补回自极化项后，单个完整周期的额外电荷相位消失，所提电子校准前件不成立。这是这一候选的失败，不是电荷比较不可能，也不是某个k被排除。
4. **有限任务下非零门户扩展：进入有界准入。** 重点是新增自由源基线和源矩，不能只用小耦合的态距离界宣布共同自由。κ趋零不删除新增场的自由能源、真空来源或涨落。旧旁观扩展审计必须先复用；只有同一候选的实际来源和记录条件共同补齐才有新研究价值。

## 6. 后继与范围变更

优先判断扩展／复制规则究竟保持哪些既有认知操作要求，哪些会在共同几何、热参考或实际源测试处失败。这是在决定能否证明结构剩余自由，不是先假定所有新增物种合法。若没有合格共同母实例或所需连续性界，只记录精确缺口，不给反证称号。

该方向与新的正向认知机制筛查并行；不能让一个门户器件或某份调节器成为整阶段的前置门槛。任何范围修订保存原因和影响；不改写旧目标、冻结证明及本版本来缩小验收责任。当前1290科学编号尚未准入，以上为真实的前期审计记录。
