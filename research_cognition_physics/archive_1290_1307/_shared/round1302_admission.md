# 第1302轮事前准入：路径交接身份的局部量子保护与物种分类

2026-10-18。接已验收[1301](../1301/acceptance.json)及其[NEXT](../1301/NEXT.md)。本轮只检验新增的具名组合角色，不采用新公理，不改变长程目标或全链比较范围。

## 1. 问题与认知层次

同一质量交接机制在经典层面保留的身份，能否在实际规范量子交换中仍由这些参与者自身保留，而不转交给参考、规范场的补偿响应或额外部门？这是组合层的精确身份要求候选；普通资源总账、有限记录稳定和一般认知交流都不自动要求它。不得把目标物种数写入该要求。

在1301的连通不同荷角色路径上，要求身份在同荷味内取同一数、S中性且每个实际质量边保该身份，给非零身份唯一至整体比例。归一后为 $F_i=(-1)^i,\ F_S=0$。质量保持条件是 $F^{\mathsf T}M+MF=0$，不是普通对易条件。F是连续身份生成元，不是费米奇偶本身，也不任意扩成所有全局身份。

## 2. 事前共同类别与新增要求

完整继承1301：四维普通Spin、忠实紧U(1)及本原整数荷格，有限非空完全手征Weyl谱，单个带荷S；非零经典背景代表，h=1平凡点稳定子；只用维四多项式S/S† Yukawa使全部字段满质量；实际不同荷角色图连通；原费米谱的线性与三次规范反常均为零。

新增要求：将上述具名F与外部诊断源耦合时，**原费米表示自身的局部混合反常 $A_{g^2F}=\sum_i n_iq_i^2F_i$ 为零**，并检查其它纯F、混合及引力系数。保原规范Ward身份，不添额外费米、拓扑流入、Wess–Zumino/Green–Schwarz补偿或规范helicity身份重定义。诊断源不是新增动力学规范场，也不意味着制成实际参照仪器。

主定理签这一表示与菜单的局部反常条件，不签全局背景、非微扰存在或全认知体系必然性。若解释成局部反项无法消除障碍，必须限定原在完整S场空间正规、含S=0的多项式菜单；不能泛称一切有效补偿皆不可能。

## 3. 核心证明责任

复用1301路径及非负整数匹配流x，检验：
1. 角色身份的唯一性及同一实际Yukawa矩阵保持。
2. 全部两U(1)局部三次和混合引力系数，区分原条件与唯一新增系数。
3. 无荷截断的整数流矩论证；检验零点重数对完整允许N集合的限制。
4. 在同一S、同一规范群、同一满秩且实际连通质量对象中给必要充分全族构造。有限代码只诊断，不代替全族证明。
5. 删除新增F保护时直接用1301已合法的12、20场例；不重写旧证据或新计旧实验。

初步解析候选是 $N=16c,\ c\ge1$。此数是待核结论，不是准入条件；不解释成标准模型一代、Spin(10)、三代或现实粒子总数。

## 4. 必须保留的补偿边界

在单个处处S非零的Higgs补丁，可令 $\theta=\arg S,\ a=A-d\theta$，则a在h=1规范变换下不变。诊断源B下的 $B\wedge a\wedge dA$ 型局部项可能改变F Ward代表和身份流。须显式核其变分，说明它在S=0不正规、不是原多项式菜单，也不据局部形式声称全局定义或实验可实现。

因此“原费米自身保护”与“包含参考/规范响应的总身份保护”是不同任务。后一项仍是合法替代方向，本轮不得把它默认为违规或整个研究失败。高维项、多个参考及其它质量机制同样超出本分类。
