# 长程目标启动：先找跨主线的结构选择力

2026-10-18。本文是[正式目标](goal.md)的启动计划，不新增科学轮次、实验组或公理。

## 1. 首项工作

在现有共同候选与自由账基础上，事前登记一份覆盖规范群／全局结构、物种／手性／荷、质量／混合及记录来源的比较范围。每个待选结构必须有现存候选、原约束、未闭合连接和可判别后果；不得把旧1010—1043成果重新列成待证明清单。

初始重点是确认哪种认知组合或稳定操作要求能够连接两项目前独立的结构输入。有限资源下的共同可辨性是一条候选，不预定它必有选择力；群、物种或质量分支中的其它真正缺口可以并行筛查。

## 2. 首轮准入检查

正式1290立题前须回答：

1. 比较哪两个明确的现存候选或哪一类未决分叉？它们在旧合同下为何仍被允许？
2. 新条件有何独立认知动机，约束原子、组合还是宏观有效层？
3. 使用何种同一任务、准备、物理读数及完整来源作判断？精度、预算和归一哪些仍是输入？
4. 成功或失败会改变哪项群、表示、物种、质量或跨主线共同资格？
5. 哪些成熟结论可直接复用，哪些才是本轮的新命题？

只有准备清楚后才写准入记录和编号报告。一般矩阵稳定性、普通补偿荷守恒、多参考秩或重复反常枚举若没有新连接，直接引用，不以它们凑1290。

## 3. 承接范围

- [1043条件生成链](../../archive_1009_1043/research_note_1043.md)用于分清共同作用中的旧接口与各自独立的反例；不能拿不同弱条件下的自由例子拼成整链不充分性证明。
- [1035](../../archive_1009_1043/research_note_1035.md)明确量子反常、表示承载及Dirac／Majorana条件之间仍可能有分叉；引用前核原证明、复算与审阅状态。
- [1288—1289自由账](../../archive_1288_1289/_shared/stage_requirement_and_freedom_ledger_after1289.md)已排除单纯循环扩建、提高同一背景局部算符次数和多参考直接秩推广的重复选题。
- [认知—社会—物理方法](../../../猜想/从认知问题到社会机制再到物理检验的研究方法论.md)用于提出机制；[层级接口猜想](../../../猜想/层级认知接口与尺度依赖空间维数猜想.md)用于审查组合和对外描述，二者都不自动授予物理权限。

## 4. 连续推进约定

每项完整轮次验收后，更新相应主线及联合依赖，立即推进下一项。独立主线可并行；共同定义和索引由主线维护。阶段内可以发布中间总结，但只有[整体五项结项要求](goal.md)全部满足后，才结束长程目标。

当前没有已预约的并行科学编号，也没有正在运行的科学试验。本次设置目标后，从M1的事前比较范围与1290准入继续。
