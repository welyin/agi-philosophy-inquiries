# 第1405轮 · 用两条混合时钟检验稀有缪子衰变的寿命端点与手性来源

对 $B_s\to\mu^+\mu^-$，其他末态给出的重、轻混合时钟允许在读取缪子数据前计算两个寿命端点。按 HFLAV 的中央宽度，纯重态为 $1.61069$ ps，纯轻态为 $1.43031$ ps。LHCb 的 Run 1–3 更新给 $1.60\pm0.16\pm0.01$ ps。其中央值靠近纯重态，将两个误差幅度线性相加的一宽工作窗口仍覆盖两个端点。早期 LHCb 数据已包含在更新中。CMS、ATLAS 的单独比较与 LHCb 的率重拟合收在证明中。[LHCb 更新](https://arxiv.org/html/2611.00230v2) · [外部混合时钟](https://hflav-eos.web.cern.ch/hflav-eos/osc/PDG_2026/)

设两个寿命为 $h>l$，实测有效寿命为 $\tau$。经时间接受度校正后，重态在已积分率中的占比是 $(\tau-l)/(h-l)$。再有绝对分支率即可恢复两种初始强度。分支率本身的提取也要依照寿命模板。LHCb 对同一 Run 3 样本分别重拟合，给 $A=+1,0,-1$ 三种模板对应的瞬时分支率 $3.114,3.430,3.829$，单位 $10^{-9}$。实验没有给出同样的合并样本三模板转换。[推导、原始读数与适用条件](1405/proof.md)

即便两个强度精确给定，任意标量份额仍能通过相对复相位产生同一整条时间分布。只有独立限制标量与赝标量的弱相位后，份额才进入较窄且可达的区间。独审另给定归一和平均寿命后对二阶矩的预报，可独立检验双指数模型。所用混合传播与振幅公式承接已有物理，本轮将实际接受度、两条独立时钟以及手性的等价族放在同一计量条件下检验。[复算入口](1405/check.py) · [数据](1405/inputs.json) · [结果](1405/results.json) · [独立审阅](1405/independent_review.md) · [后续判据](1405/NEXT.md)
