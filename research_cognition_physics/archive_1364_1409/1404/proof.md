# 由中性 B 介子振荡留出两条稀有衰变

## 哪两件事必须来自同一物质作用

第1351轮用已登记的夸克混合和格点矩阵元检验两项中性 $B$ 混合。本轮改问：同一顶—弱味因子若同时进入混合和缪子对衰变，单独用一条缪子对率定标后，能否跨预测另一条以及衰变时间？使用 Buras 2003 年已经建立的关系，以及 De Bruyn 等已给出的有效寿命转换。新的检验是用 CMS 的早期资料和格点输入对照2026年 LHCb 的另一种介子、另一个探测器和采集时段，并量化哪些非普适修正仍能同读。[1351混合检验](../../archive_1323_1352/1351/proof.md)；[Buras](https://arxiv.org/abs/hep-ph/0303060)；[有效寿命的原文](https://arxiv.org/abs/1204.1737)

设 $q=d,s$。局域有效理论中，混合只保留标准左—左算符，$\Delta M_q\simeq2|M_{12}^q|$；稀有衰变由轴矢量算符及标准缪子质量抑制主导。两者共享 $\lambda_q=V_{tb}V_{tq}^*$，混合正比于 $|\lambda_q|^2 M_{B_q}f_{B_q}^2\widehat B_q$，衰变在 $t=0$ 的味平均率正比于 $|\lambda_q|^2 M_{B_q}f_{B_q}^2m_\mu^2\beta_q$，$\beta_q=\sqrt{1-4m_\mu^2/M_{B_q}^2}$。顶主导、两部门相同短程归一、相同算符和末态辐射约定属于输入；不同局域算符、非局域效应或新的味相位要另行匹配。认知动机是把同一物质作用放到两个实验中核对。弱算符及其系数已有具体的物理含义。采用这些算符本身不会从认知操作中确定它们。

在 $|q/p|=1$、无新相对 CP 相位的纯轴矢量参考下，奇异 $B$ 的 $\mathcal A_{\Delta\Gamma_s}=+1$，无标记信号有重本征态寿命 $\tau_{H,s}$。普通 $B$ 的宽度差在本精度取零。记 $\bar{\mathcal B}_q$ 为时间积分的分支比，取 $\tau_d=\tau_{B^0}$、$\tau_s=\tau_{H,s}$。振荡与衰变相除得

$$
\bar{\mathcal B}_q=K_q\,\frac{\Delta M_q\,\tau_q\,\beta_q}{\widehat B_q},\qquad
K^{\rm ref}=\frac{3G_F^2 M_W^2m_\mu^2}{\pi^3}
              \frac{|C_A(5\,{\rm GeV})|^2}{S_0(x_t)\eta_B}.
$$

$\Delta M$ 用 ps$^{-1}$，$\tau$ 用 ps，乘积无量纲。$C_A$ 与这里 $\widehat B_q,\eta_B$ 的约定取自同一计算，不能直接换入另一套归一的 $C_{10}$。只要用同一顶端口的统一实系数重标两道轴流和混合，$K_s=K_d$ 仍成立，即使该共同数并非标准值。$f_{B_q}$ 和夸克混合因子都在各自的比值内消去；格点袋参数的 $s/d$ 依赖仍可测。[HPQCD 式(12)、(14)、(19)—(22)](https://arxiv.org/pdf/1907.01025#page=12)

## 固定短程运行，先检验绝对量级

为使定标可追踪，统一使用 HPQCD 2019 年工作记录的输入。$\Delta M_s=17.757(21)$、$\Delta M_d=0.5065(19)$ ps$^{-1}$，$\tau_{H,s}=1.615(9)$、$\tau_d=1.520(4)$ ps。四活跃海夸克格点计算给 $\widehat B_s=1.232(53)$、$\widehat B_d=1.222(61)$、相关比值 $\widehat B_s/\widehat B_d=1.008(25)$。这组历史输入是一个冻结的基准，未声称为2026年最新世界组合。绝对计算沿用其 $m_t(m_t)=163.07(38)$ GeV（由历史直接质量按极点解释后转换）、$x_t=4.116(19)$、$S_0=2.313(8)$、$\eta_B=0.55210(62)$、$C_A=0.4694(36)$。用标准单自变量 Inami–Lim 函数直接代 $x_t$ 得 $2.31258$。短程环计算和格点不是对 $B\to\mu\mu$ 的直接测量。[历史输入与运行约定](https://arxiv.org/pdf/1907.01025#page=10)；[本轮输入](inputs.json)

计算得 $K^{\rm ref}=1.63809\times10^{-10}$，$\bar{\mathcal B}_s=3.81005\times10^{-9}$、$\bar{\mathcal B}_d=1.03119\times10^{-10}$，复现原文公布的 $3.81(18)\times10^{-9}$、$1.031(54)\times10^{-10}$。现代更高阶计算处理电弱、软辐射及旁观夸克非局域 QED 作用，一般不能证明所有差别在两道间精确消去。原始研究表明相对修正可达约百分之一。这里只把冻结参考的算符关系用于相应精度，未把它认定为全标准模型的精确恒等式。[QED物质项](https://arxiv.org/abs/1708.09152)；[Bobeth 与 Buras 的高阶分析](https://doi.org/10.5506/APhysPolB.52.1189)

## 只给奇异 B 定标，真正留出普通 B

放开 $K$，独立规定 $K_d=K_s$。从两种 B 的振荡及格点的直接相关袋比，得到

$$
r_0=\frac{\Delta M_d}{\Delta M_s}
     \frac{\tau_d}{\tau_{H,s}}\frac{\widehat B_s}{\widehat B_d}
     \frac{\beta_d}{\beta_s}=0.02706015,\qquad
\bar{\mathcal B}_d=r_0\,\bar{\mathcal B}_s .
$$

在此等式里短距顶质量不再出现。CMS 以2016—2018年13 TeV、140 fb$^{-1}$样本给 $\bar{\mathcal B}_s=(3.83^{+0.38+0.24}_{-0.36-0.21})\times10^{-9}$。仅据此定标 $K_s=1.64666\times10^{-10}$，从而预报 $\bar{\mathcal B}_d=1.0364\times10^{-10}$。在校准前也可直接用相邻公式消去 $K_s$；分开计算两只袋参数再相除会丢掉原文的格点相关性。[CMS 原始分析](https://cms-results.web.cern.ch/cms-results/public-results/publications/BPH-21-006/index.html)

| 对照及用途 | 公开读数 |
|---|---|
| LHCb Run 3 的普通 B，主留出 | $(1.26^{+0.51+0.06}_{-0.47-0.05})\times10^{-10}$，单样本信号相对零信号为 $3.0\sigma$ |
| LHCb Run 1—3 的普通 B，精度对照 | $(1.14^{+0.42+0.06}_{-0.39-0.05})\times10^{-10}$，合并为 $3.2\sigma$ |
| LHCb 同一拟合给出的直接比值 | Run 3 为 $0.038^{+0.016}_{-0.014}\pm0.002$，Run 1—3 为 $0.035^{+0.014+0.002}_{-0.012-0.001}$ |
| 早期 CMS 同样本内的 $d$ 搜寻 | $1.9\times10^{-10}$ 的95%置信上限 |

LHCb Run 3 用2024—2025年13.6 TeV、18 fb$^{-1}$的碰撞。它的事件与用于定标的 CMS 事件不同，两合作组仍可能共享归一化衰变数据等外部输入。LHCb 合并包含自己的 Run 3，合并率、直接比值、寿命也共享部分事件。统计上没有将它们连乘。应优先采用论文直接报告的 $d/s$，Run 3 两项率的线性相关为 $-3\%$；没有全似然时不能靠比值中心重建联合似然。这些是测量非零信号的显著度，不能移作检验 $K_d=K_s$ 的显著度。[LHCb 2026 预印本 v2](https://arxiv.org/html/2611.00230v2)

计算保存无需独立高斯假设的确定性包络。每项实验误差分量先按同侧加宽，将全部输入的边际半宽同时乘一或二，再利用正数乘除的单调性。不赋联合置信率。只从 CMS 及格点等输入得到一宽的 $d$ 预报为 $[0.8490,1.2504]\times10^{-10}$，与独立采集的 Run 3 $d$ 读数一宽 $[0.74,1.83]\times10^{-10}$ 相交。设 $\rho=K_d/K_s$；两处中心给 $\rho=1.216$。用 LHCb 合并直接比值作另一种检验给 $\rho=1.293$，一宽可容纳 $[0.7829,1.9582]$ 内的修正。相容不意味着两部门严格共同。

作为可分辨竞争，保持所有校准及参考相位，仅让普通 B 轴流模增为 $\sqrt3$ 倍；混合项不变，则 $\rho=3$。即使让比值另乘试探性的 $[0.98,1.02]$，两宽全盒的竞争预报仍 $\ge0.07365$，高于同样口径的 LHCb 比值上端 $0.067$。该有限误差判别不带频率学排除显著度，2%也没有被证明为所有 QED 或新算符模型的误差上限。[复算](check.py)；[完整结果](results.json)

## 寿命提供什么独立信息

在无标记、两指数的范围内，用 $w=(1+\mathcal A_{\Delta\Gamma_s})/2$ 和真实的 $s$ 初始总率 $\Gamma_{0,s}$ 写分布为 $\Gamma_{0,s}[w e^{-t/\tau_H}+(1-w)e^{-t/\tau_L}]$。归一化积分 $T=w\tau_H+(1-w)\tau_L$ 和有效寿命相连。

$$
\tau_{\rm eff}=
\frac{w\tau_H^2+(1-w)\tau_L^2}{T},\qquad
\frac1T=\frac{\tau_H+\tau_L-\tau_{\rm eff}}{\tau_H\tau_L}.
$$

因此若在同一实验定义下实际校准无偏的积分率与一阶矩，可以消去未知的重态份额；两道转移中的分母应将 $\tau_{H,s}$ 换成 $T$。它首先限制衰变与混合间的相对相位及 CP 组成。两个 $\tau$ 相等的极限仍可用于归一，但不能区分 $w$。参考合同 $w=1$ 留出 $\tau_{\rm eff}=\tau_{H,s}$；名义预测 $1.615(9)$ ps 可同 LHCb Run 3 的 $1.42\pm0.18\pm0.02$ ps、合并的 $1.60\pm0.16\pm0.01$ ps 分别核对。以早期 LHCb 非稀有 $J/\psi K^+K^-$ 角分析的中央 $\Gamma_s,\Delta\Gamma_s$ 独立重建两只钟，得 $\tau_L=1.42745,\tau_H=1.61277$ ps。即使两机制的真实积分率相同，轻态与重态主导时恢复的初始率仍可相差12.98%。LHCb 的合并一阶矩精度尚难区分这两端。[独立强度—钟标定](https://arxiv.org/abs/1411.3104)；[时间矩与新相位](https://arxiv.org/abs/1204.1737)

读出有衰变时间选择效率。LHCb Run 3 将假设的 $\mathcal A_{\Delta\Gamma_s}=+1$ 改为0或 $-1$ 时，重新拟合的 $s$ 分支比分别上调4.0%与9.2%。所以不能固定发表的名义分支比，再将任意新相位代入上式当成现实重拟合；需要实验的接受度或有相应假设的发布结果。任意部门分别选择 $K_q$ 时两道率当然都可被拟合；同时重标 $C_A\to a C_A,\ |S|\to a^2|S|$ 甚至保持两份 $K_q$ 不变。独立顶/弱数据才能恢复绝对解释。零个新增公理，零个新独立选定的现实标准模型参数。
