# 第1364—1409轮　共同质量来源的弱流与 Higgs 基准

[阶段总目录](../README.md) · [第18篇论文](../18_标准模型的条件选择与现实参数的剩余自由_阶段论文.md) · [全阶段参数账](../archive_1798_1815/_shared/standard_model_coverage.md)

同一份物质质量及弱流混合，足以预测哪些 Higgs、规范或稀有衰变读数？

在单个额外下夸克的树级模型中，轻质量与弱流把重质量压到至多二次的谱条件。另一项检验把规范耦合确定的夸克与轻子权重带回带电质量谱，发现无新阈值的一圈方案给出的权重过小。给两份重中性质量指定共同弱流以后，辐射缪衰变提供了独立约束。 [第1364轮](research_note_1364.md) · [第1369轮](research_note_1369.md) · [第1377轮](research_note_1377.md) · [第1392轮](research_note_1392.md) · [第1409轮](research_note_1409.md)

这些检验依赖具体的重粒子表示、质量矩阵和匹配尺度。重伙伴的质量来源及 Higgs 对它的响应可以分别改变。

从阶段的单重夸克判据开始，到两份重中性质量完成弱流与稀有衰变的核对。第1410轮改由三端循环生成味方向。
