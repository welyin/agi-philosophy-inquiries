# 第1404轮　同一顶—弱交换能同时解释两种中性 B 介子的振荡与稀有衰变吗？

只用 CMS 的 $B_s\to\mu^+\mu^-$ 率定标，在共同短距离作用、标准局域算符及重本征态时间分布的条件下，预报 **$\bar{\mathcal B}(B^0\to\mu^+\mu^-)=1.0364\times10^{-10}$**。LHCb 用2024—2025年独立采集的 Run 3 样本测得 $(1.26^{+0.51+0.06}_{-0.47-0.05})\times10^{-10}$；两者相容。截至2026年11月，这一衰变已有单实验非零信号的证据，Run 3 为 $3.0\sigma$，LHCb 合并三个运行期为 $3.2\sigma$。早期 CMS 的 $1.9\times10^{-10}$ 仍是其自身的95%置信上限。[CMS 定标](https://cms-results.web.cern.ch/cms-results/public-results/publications/BPH-21-006/index.html)；[LHCb 2026 原文](https://arxiv.org/html/2611.00230v2)

### 振荡如何给出跨部门约束

Buras 的关系用每种介子自己的振荡频率消去其衰变常数和 CKM 因子。余下格点袋参数、实际寿命和轴流与混合短距离作用的比。冻结 HPQCD 的格点、顶质量运行及振荡输入，能先复算其标准模型下的 $s,d$ 绝对率 $3.8101\times10^{-9}$ 和 $1.0312\times10^{-10}$。若放开共同短距离强度，只要求两部门共享，仍可独立预报积分率之比 $d/s=0.027060$。实验直接拟合的 LHCb Run 1—3 比值为 $0.035^{+0.014+0.002}_{-0.012-0.001}$。合并样本与 Run 3 重叠，未作为第二份独立证据相乘。[Buras 原关系](https://arxiv.org/abs/hep-ph/0303060)；[HPQCD 格点与振荡](https://arxiv.org/pdf/1907.01025#page=12)；[本轮推导](1404/proof.md)

### 已能分辨的偏离

若普通 B 轴流幅度单独增加到 $\sqrt3$ 倍，其余定标与相位保持原值，两道的短距离率之比提高三倍。允许格点与其他输入在全部两倍边际宽度内变化，再允许额外2%的相对读数修正，这个竞争仍预报 $d/s\ge0.07365$，高于同口径的直接测量上端 $0.067$。这是登记误差预算内的分离；2%属于试探预算，未赋予联合排除显著度。更小的部门差别仍有宽广空间。[计算](1404/check.py)；[完整包络](1404/results.json)

时间分布另有判别力。标准参考要求有效寿命为重本征态寿命；LHCb 合并测得 $1.60\pm0.16\pm0.01$ ps。在放开参考相位时，校准过的积分率与一阶时间矩共同确定初始率，但实验选择效率也随寿命改变，报告给出了真实重拟合的幅度。本轮得到同一个有效作用的低能检验，未从这些量单独确定现实顶质量或轴、混合两项系数。[时间约定与限制](1404/proof.md)；[下一步](1404/NEXT.md)
