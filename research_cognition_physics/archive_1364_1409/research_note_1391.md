# 第1391轮　同一个重下夸克能否生成弱 CP 破缺并松弛强角？

**结论。** 在实 CP、微扰 PQ 对称且全部带荷真空相位只形成一条 PQ 轨道时，所有微扰弱 CP 奇不变量为零。两个同荷标量提供一个共同角和一个相对角。给同一个重下夸克以这两个标量产生的手性质量及实的电弱混合，能构造出强角在 QCD 真空为零、轻夸克带电流仍有非零 CP 四元组的同一实例。两个角足够的陈述仅覆盖这里给定的场内容与势。真实 Yukawa 数值、PQ 的来源与质量尺度仍是输入。[解析证明](1391/proof.md)

| 同一实例的读数 | 结果 |
|---|---|
| 相对相位 | 正支 $\delta=\arccos(1/3)$，负支为其 CP 共轭 |
| 共同相位 | 正支 $\phi_*=0.122360745$，此处完整质量行列式为正实数 |
| 轻带电流不变量 | 见证 $J=-0.00298844$，共轭支翻号；重尺度趋于无穷仍有 $J=-0.0008514964$ |
| PQ 色反常及电磁比值 | 一个基本色三重态、弱单态、电荷 $-1/3$ 的重费米子给 $N=1,\ E/N=2/3$ |
| 相对角的稳定性 | 在固定径向的匹配势中，额外 PQ 不变能量起伏小于 $4\kappa v_S^2 v_T^2/9$ 即足以排除 CP 守恒极小 |
| 实际味线对接 | 在单个味流、轻且不可见等前件下，历史 E787/E949 数据要求 $F/(|C_{ds} f_0(0)|)>3.4654\times10^{11}$ GeV |

普通上右质量列在本例允许且非零。转动共同角只给重左手行一个相位，因而不改微扰弱观测，却改变 $\bar\theta$。实相互作用把相对角写入基不变的三投影读数 $I=-2t^2\sin\delta$。在同一 $3\times4$ 带电流 $V$ 上，普通 Higgs 径向与共同 PQ 方向分别读取 $X=V^\dagger V$ 和 $1-X$。历史介子窄线只是这一关系的直接应用，后续第1393轮专门检验实际 $d,s$ 味端口、更新搜索及额外衰变振幅。表中的任意单位质量没有代入真实介子数据。[原实验](https://arxiv.org/pdf/0709.1000#page=94)

QCD 在每个相对角上都可松弛共同角，剩余的零角真空能还可随夸克质量改变。作者给出控制相对角的能量预算。独审另外找到一整族相对角不同、夸克质量谱严格相同的模型，整套纯 QCD 的零点能对相对角恒定，同时轻弱四元组仍可翻号。在这两个实例中，电弱及标量修正、额外显式 PQ 破缺、宇宙学弛豫和现实味质量匹配各有独立内容。[独审证明](1391/independent_review.md)
