## 3. 第二种几何推导不能替代完整物质来源

Finster、Krpoun，[arXiv:2607.13871v1](https://arxiv.org/html/2607.13871v1)，定理6.8，在光滑支持、短程核和真空贴合等条件下构造Lorentz几何及有效Einstein形式。右端由几何/正则展开定义，Λ包含其中而未定。这提供非EH机制模板，尚不等于本项目全部钟、材料、控制与记录的物理能动量；也不能只凭守恒命名就认定二者相同。

下一次引用须分别指明：前一论文的Dirac物质核、后一论文的几何有效源、我们原过程的实际完整来源。三个名字中的“来源”不构成自动等同。该区分直接延续1188后参考场审计中的完整资源要求。

## 4. 量子接口：复用旧证据，避免设置错误门槛

[757](../../../archive_742_763/research_note_757.md)、[829](../../../archive_819_853/research_note_829.md)、[833](../../../archive_819_853/research_note_833.md)、[844](../../../archive_819_853/research_note_844.md)已经处理低阶关联不完备及其后续影响。故不再为“四模同二点、不同四点”另建代码或研究轮次。

须区分两种接法：

- 仅保存单粒子密度/二点函数，并用它替换声明任务的全部未知输入与参考：旧结果不允许这种普遍替换。
- 保留完整Fock态、参考和共同演化；只在声明的态族、观测菜单、有限尺度上用二点结构描述有效几何：仍然允许，不能用旧反例否定。

也不能把期刊多激发的“可忽略干涉”说明，误解为其投影线性部门绝不容许相干。在固定背景、同一个正则和线性化算子下，单粒子模式的叠加仍是Dirac解；已投影双线性来源的交叉项可用极化恒等式复用。此项代数延伸不产生实际仪器、全部未投影分量或保参考的物质—几何通道，不单独编号。

## 5. 有限尺度如何判断，不把UV变为前置门槛

小参数渐近余项不自动等于声明实验窗口中的误差证书。真正要核的是：在同一有限能量、曲率、时间和实际记录菜单上，遗漏分量及正则余项造成多大的预测/来源误差。

如果可以对这些任务给统一误差，并在同一完整量子过程中保留其它自由度，则无需先完成无限高能理论。反之，若遗漏分量影响当前允许的钟、信号或原物质反馈，就必须在此有限范围内解决。不能只因其名称是“高阶”或“非几何”而删除。

无迹方程加守恒得到完整Einstein形式的成熟步骤直接复用；带余项时须同时传播误差，不能从渐近式无条件宣布有限参数下的精确方程。Λ的常数自由仍保留。

## 6. 认知机制解释与下一项唯一值得投入的问题

认知层的问题是：一个共同协调规则能否同时约束关系改变与参与者实际承担的变化，而不是把各部门账目分别拟合。社会对应是同一次协作的资源账与相互影响必须可相互追溯。这一动机支持研究同源变分机制，**没有唯一选出CFS的谱作用**，本页不将其公理化。

可检验的接入要求是：在一个事前声明的有限材料任务上，保留未投影的双线性扰动及全部输出；从同一规则给出实际钟/空间/信号响应与完整来源，再比较文献中的几何响应，系数不能按扰动逐项改动。这里要求承接所有实际影响许可任务的分量，或证明其属于规范冗余/受控余项，不要求每个形式Clifford分量都有独立可观测身份。

**本次来源补核已完成：** [独审§4](source_review.md)追查原文指定的Ref14，确认已有补偿工具另需势、真空部门和正则条件，未找到可直接承接当前完整过程与实际读口的结果。因此停止直接接入，不转为修补整个CFS。 两模式极化、二点不完备反例、相同位置效果反例和预置Einstein解的数值演示均不再做。下一项若有科研编号，必须补这项实际连接或取得别的目标级新证据，不能只复述条件清单。

当前取舍是：停止1178旧父的被动变换/稳定子分类与CT条件继续叠加；保留1188及参考场审计的限定结果；CFS仅进入条件机制库。两类共同暗部门可能性继续按[既有记录](../dark_sector_joint_generation.md)追踪，不凭新论文中的剩余项命名暗物质或暗能量。
