# 1185后筛查：完整守恒四极与实际来源的分界

2026-10-13。接[1185后选题](../after1185_exchange_selection.md)。本包保存一项决定方向的数学筛查及实施范围审计；不新增研究编号、科学检查组、公理或经验校准。最新正式验收仍为1185。

## 得到的结论

复用940的完整弱场交换核，在声明的径向紧支双四极源类内，密度、动量和应力一并保留后，剩余约束配对严格非零。固定有限见证的精确值为

$$
\pi\mathcal I_C=-\frac{2771}{77837760}<0.
$$

因此，不能用“所有这类守恒源都只留下接触项”停止这一方向。另一方面，确实存在全接触的不同源族，也存在静止密度读口的方向盲点；二者都已明确区分。

在同一退迟处方下，完整GR核对处处类空分离的这些数学源配对为零，候选核给 $\mathcal I_\xi=(\xi-1)\mathcal I_C$。这尚不是远端概率差，也没有选择 $\xi$。两传播模式、弱场类别、源资格和传播处方仍为输入。

## 真正剩下的一步

要把数学源接到同一实际过程，须明确整个器件的背景耦合，包括材料、控制、位置/反冲、参考和记录；再证明它产生所需的完整来源插入，并接到原远端非选择读口。只复现平直处末端门，不能固定对几何扰动的响应。新增曲率耦合可以在平直处不可见、却改变来源；不能默认为零。

下一项限于一个有限任务的来源匹配与概率身份，不继续扫描外置源，也不要求先解决完整UV。共同过去首先指同一候选内两种后来的局部设置；跨候选比较须另外匹配物理准备和记录语义。
