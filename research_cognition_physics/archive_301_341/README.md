# 301—341轮：连续几何与条件性引力

## 研究问题

给定哪些连续与物质条件，才能接到几何反作用和共同光锥？

## 阶段成果

- 在明确的Lorentz流形分支中连接因果共形类、物理体积与度量；接入Jacobson路线并核其熵、能流和平衡条件（301—320）。
- 给出共同物质度规的受限判据、非普适耦合反例，以及已输入作用下的有效匹配（321—335）。
- 在指定模型和稳定预算下建立共同光锥的条件性吸引及探针窗口（336—341）。

## 适用范围与未完成项

光滑流形、维数、部分作用与熵条件没有从认知原则推出；模型内的共同光锥不等于独立生成Einstein动力学。

这是研究过程的主题分期，不代表本阶段全部开放问题已关闭。认知动机、附加建模输入、解析证明和数值校准按原报告区分。
