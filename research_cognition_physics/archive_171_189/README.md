## 核心问题

真正要选择的是哪类操作结构，纯化、层析与组合分别增加什么？

## 本段成果

- 区分复数表示与实Kähler等价描述；历史保留、纯化、局部校准并不互相替代。
- 在明确矩阵候选族中分析组合与纯化筛选；审查齐次性、自对偶和Jordan重建接口。
- 记录共享参考校准的充要条件与未知参考歧义，统一登记量词和权限。

## 适用范围

条件性重建与认知动机的必要性分开；纯化单独不能排除通常实量子。
