# 第1586—1631轮　电弱破缺、辐射轻子质量与味对称

[阶段总目录](../README.md) · [第18篇论文](../18_标准模型的条件选择与现实参数的剩余自由_阶段论文.md) · [全阶段参数账](../archive_1798_1815/_shared/standard_model_coverage.md)

由同一凝聚、辐射机制或离散味对称产生质量时，哪些味方向和电弱读数必须一起出现？

已知弱流、Higgs 阈值和轻质量对重中性态的强度施加联合限制。带电轻子与两条中性质量源共用左手方向时，第三个带电来源受到实际振荡列约束。单调带电背景加一条任意复方向无法产生观测混合；在指定的正定加性模型中，两条独立列已足够。 [第1587轮](research_note_1587.md) · [第1594轮](research_note_1594.md) · [第1603轮](research_note_1603.md) · [第1613轮](research_note_1613.md) · [第1625轮](research_note_1625.md) · [第1630轮](research_note_1630.md)

列数定理限制来源的数量和方向，实际混合角及耦合强度仍须选择。由某个离散群精确给出的角度也可能被改变尺度或输入的测量区分。

从顶夸克凝聚与 Higgs 四次项开始，到可产生三重态的混合及固有寿命。第1632轮开始用奇底弱流检验有色伙伴的具体实现。
