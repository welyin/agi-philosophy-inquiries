## 主问题

上一阶段在明确物理类别内建立了条件生成链。本阶段准备进一步检验：**主体、记录、交互、资源、来源与跨尺度描述必须由同一量子物理过程承担，这些认知操作要求，是否对自然动力学提供超出既有物理一致性条件的独立约束？**

若有，须指出哪一项先前开放的物理选择被哪一项认知要求排除；若没有，须在明确模型类和任务域内证明剩余自由。允许从成熟物理反推候选原则，但须声明新增内容，另检验非循环性及选择力。

研究纲领继续覆盖量子、时空、物质、引力和跨尺度。首个有限检验只承担它实际覆盖的命题，不代表整个物理统一已经实现或失败。

## 准备的第一项：1044准入检验

**优先检验一项真实物理耦合的量子共同过程，而非再造抽象门角反例。** 正式开始时先完成以下内容，再决定是否值得投入后续实现：

1. 从已有947／951、955／957、956／958、977等共同接口中选择可复用起点，列出其已经满足的条件及仍需补的映射。不得把这些不同对象拼成一个完整父模型。
2. 明确一族正量子物理过程，以及在变动物理参数时保持相同的任务要求：参与者和访问、未知输入与被动参考、准备和真实测后态、参考与能源、来源和所声明反馈、有限时间与误差。事先规定哪些实验程序、参考和读数定义固定，哪些校准允许随参数变化；允许的校准须给内部实现和代价，不能借重调任务抹去物理差异。禁止一切校准也不是已采用的认知原则。
3. 逐项判断新合同是否比929有限六协议和1031经典父族更强，新增部分是否真正触及自然物理参数。若只是改门角、改变单位、重命名，或重复同一有限自由证书，取消该候选，不占用新研究轮次。
4. 准入后才求两个合格且可辨的参数实例，或证明一个明确选择条件。不得先假定整族全部实现，再把连续性当成共同实现的证明；预算上限相同也不等于完整物理资源态相同。

可比较固定装置合同，也可比较事先声明且计入内部资料、时间、能源和误差的校准策略。后者允许装置设置随校准记录变化，不允许无代价读入真实参数或事后改变成功标准。某个任意选定任务阈值排除了一个参数，只证明该任务的能力限制；若要称为自然规律的认知选择，还须解释为什么该合同由被检验的原则要求，而非由研究者偏好指定。

特别回查958：其一般耦合的精确谱／来源关系和随耦合调整的读取时间已经存在。再次扫描该参数、重调时间得到同一逻辑操作，或只论证小参数变化的连续性，不构成下一阶段所需的新选择结果。

这里预留的是问题顺序，不是提前给1044编号结论。正式报告必须有新增解析结果或限定反例、可复算材料和明确验收；若准入未通过，保存准备审计并报告真正阻碍。

## 阶段交付与停止条件
