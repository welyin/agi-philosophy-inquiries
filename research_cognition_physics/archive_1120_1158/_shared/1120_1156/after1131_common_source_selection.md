# 1131之后：按共同来源增益选择路线

2026-10-11。接[已验收1131](../../research_note_1131.md)及[其下一步](../../1131/NEXT.md)。本文件是接续筛选，不是新增科学轮次，不改阶段目标和已采用公理。1132尚未准入。

## 1. 已完成的有限筛选不扩大为全局障碍

1131在新增两准备菜单M1131下，证明原同H的实际裸B概率区间，并给有独立端点误差资格的纯梯度候选匹配下界。归一梯度逃过该见证，但仍未获得正常量子实现、封闭四动量或实际接收权限。只保旧单准备菜单的候选也未被排除。

这已足够结束本项筛选。继续增加源率、调整同一误差常数、找第三个梯度例子，都不会自动减少阶段共同接口的缺项。

## 3. 候选排序以减少接口缺项为准

### 优先筛选：明确材料的局部标量交互

允许选新材料共同实例，优先回查942与既有局部场方法，考察标量质量交互能否避免为交互另给一支外部时间方向。此处只确立筛选优先级，不声称已经构造成功。

准入必须在同一有限任务中新增至少一项此前没有的实际证书：正常未知Q/R的接收访问与完整源后态，或与该过程相同的四动量交换及实际支撑。只写新的质量矩阵、形式Lorentz标量或Noether张量不另立一轮。有限分辨率、场准备、实际读口及近似误差都需明示。

一个需要先核的身份差异是：标量耦合$-g(\phi)\bar\Psi\sigma_x\Psi$在Hamiltonian中给$\beta g(\phi)\sigma_x$，而1129使用的材料脉冲没有这个$\beta$。因此不能直接继承原旋量码、B目标模式或误差常数。若选择新近静止材料，就明确换码并重新证明实际访问；这仍不等于重新做942的一般质量编码。

### 备选：少体相对论有效过程

直接相互作用或相互作用质量算符可能较容易给出完整相对论表示，但表示代数不能代替原CO事件、空间局部接触、接收记录和因果预测。只有能给两份实际材料的任务及其有限时窗证书，才值得比对；不因某个构造名称此前未用过就准入。

### 暂不投入：归一梯度的全面技术补全

归一梯度仅解决一项时向表示问题，未自动消除原空间部署及平滑核的来源责任，还新增类时域、源动量字典和量子定义的选择。先判断它能否减少共同接口缺项，再决定是否研究这些技术问题；不能因1131未排除它就默认沿它无限推进。

## 4. 下一轮所需的最小任务说明

先选择任务身份：原1111的细化必须保原Q_r及允许后续；新材料共同实例则声明其自己的接收访问，并证与原CO/SR位置和钟的关系。两个选择都在现行目标范围内。

计算前登记以下内容：

1. 哪些实际参与者、未知输入与参考、正常准备、位置与终时保持；哪些是新材料许可。
2. 接收者实际能够读取和继续做什么；不能只给一个逻辑码的名称。
3. 动力学、驱动、部署支撑、源和接收器由哪一份完整生成元共同决定。
4. 完整物理平移和四动量作用于哪些对象；局部交换与总平衡如何对应。
5. 有限任务和因果预测误差，以及独立的能源／来源误差；普通状态距离不能代替后者。

若只能补一个候选内部的形式恒等式、重复一般守恒扩张，或把旧固定码投影冒充完整物理动量，不准入新轮。若已有可证明的有限接口增量，则立即开展，毋须等全部UV或全物理完成。

只读代理筛选与主线回查同意上述优先级。下一候选可用“未知Q/R接收、两项不对易读取及一次继续操作”作为最小访问示例，同时保完整任务误差和一份非空锥外干预菜单；这只是具体任务的选择，不新增普遍认知公理，也不以两个读口代替全未知量子态的证明。目前三条路线都还没有这份新证书，因此不提前把1132写成已完成研究。

阶段目标继续active，新增认知公理0，科学校准0。既有反例只按各自模型、菜单与误差量词使用。
