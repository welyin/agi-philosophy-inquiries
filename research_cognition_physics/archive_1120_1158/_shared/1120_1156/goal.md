# 阶段目标：从认知操作到局域相对论有效场

2026-10-11。用户明确授权启动，首轮1120，工作目录`archive_1120_`。本文件是阶段目标的阅读版，完整工具目标与状态见[启动回执](goal_start_receipt.json)。

## 要回答的问题

现行认知公理及哪些必要的认知扩展，能够使同一实际过程同时具有区域操作、相对论性因果传播、局域交互和共同能动量来源？从这些条件出发，能接入哪些已知场论和引力结构，哪些自由仍需保留？

四原则、CO、SR和D-P继续分层共同使用。SR-S只在明示定标分支采用；生成完备G不是本阶段默认前提。上一阶段的已知世界线、有限内部类型及材料资格原样保留，扩展时另行证明资格。

## 验收标准

1. 事前声明参与材料、未知输入与任意参考、原端口、区域、实际钟、操作权限、内部资源、时间窗、能量范围和误差。
2. 证明区域操作及其因果接续在同一对象上成立，解释局域性由什么权限和条件保证。未给全部区域操作权限时，不把受限无信号升级为全部可观测代数的微因果性。
3. 给出窗口内局域过程与原有限有效边界、总动力学和实际任务的连接。保原接收者、期限、完整后态及允许后续；新增局部作用或自由模式作为明确条件登记。
4. 给出局部能动量及流与已有总四动量的同一身份，证明守恒／平衡和完整反作用，或提供声明范围内的误差证书。局部应力响应不能仅由末读概率接近替代。
5. 对1015—1019、1027—1029等旧成果逐项登记可复用前提与未补连接；不重复分类，不预置Einstein作用再宣称从认知生成引力。
6. 整理真实减少的输入、正式采用的认知扩展、剩余自由和失败范围，完成报告、复算及独立审阅后再结项。找到一个相容例子与证明现行公理迫使全部对象如此，是不同强度的交付。

若形成否定结论，应精确定义被否定命题，并认证反例满足其全部前提。某一器件、某类模型或一条连接失败不自动否定本阶段共同方向。尚未找到证明也不等于独立性已经证明。

## 方法与边界

- 先审计方向及条件的实际选择力，再投入候选内部细节；连续无有效进展时记录真正阻碍及可检验替代。
- 遇到机制缺口，依[认知问题—社会机制—物理检验方法](../../../../猜想/从认知问题到社会机制再到物理检验的研究方法论.md)提出候选认知机制。保留[层级接口与尺度猜想](../../../../猜想/层级认知接口与尺度依赖空间维数猜想.md)中的跨层责任，不假定所有尺度具有相同有效几何。
- 认知动机、原子／组合／宏观层次、正式公理、模型输入、解析证明、数值校准及经验确认分别登记。新公理需有明确认知含义、量词、非循环性、失败标准和共同相容证据；公理采用不冒充旧公理推导。
- 不预设微观连续或最小尺度；不要求完成全部QFT、所有物种、标准模型、GR或无限高能理论才允许有限有效结项。
- 回查四根导航、最新报告及结果，保护历史和正在编写的内容。每轮根部保存`research_note_编号.md`，资产放编号目录，复用现有Python／NumPy，不做图像检验。
- 本目标在当前任务内执行；不创建新应用任务或定时任务。用户停止或改向时遵从。
