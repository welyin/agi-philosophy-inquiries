## 阶段交付

1. 同一材料、实际钟、三维位置、信号和空间区域的共同身份。
2. 物理演化、温度和运动/加速测温的条件连接。
3. 独立定义的边界面积与熵响应，以及系数和尺度的剩余自由。
4. 完整能流、守恒、反作用与几何响应的共同接口。
