令 L＝2f|κJ|。在κF交互绘景中，V_I(t)范数≤v_*，且||V_I(t)−V_I(s)||≤L|t−s|。一次V只跳一步、改变当前颜色或保持位置。根不标记，故所有一、二阶时序乘积均不能产生根reply；三阶只允许跳出、标记、跳回。
