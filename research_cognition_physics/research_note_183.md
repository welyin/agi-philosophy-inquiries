# 第一百八十三轮：单体的自对偶与可逆对称仍不足，结构选择需要复合层级闭合

日期：2026-09-16。接续第181—182轮，比较自对偶、齐次性与纯态传递，构造两个明确的非标准复量子单体，并登记一条已有的操作重建路线。

**结果：正五边形给出“自对偶但不齐次”的例子；四维球则同时自对偶、齐次并有连续纯态传递，单体仍不是复量子位。关键限制出现在要求同样结构对复合系统也成立时。本轮没有为四维球构造一个满足全部重建条件的完整复合理论。**

## 1 自对偶不自动保证内部态互达

取正五边形锥的射线

\[
v_k=(1,r\cos(2\pi k/5),r\sin(2\pi k/5)),\qquad
r^2=1/\cos(\pi/5).
\]

其标准内积满足v_i·v_j≥0；且v_i恰与v_{i+2}、v_{i+3}正交，指标按5取模。这两个邻接顶点构成一个面，v_i就是它的内向法线。五个面与五条射线穷尽，因此C=C*，是内积自对偶锥。

连续锥自同构必须固定每条射线，因为有限射线的置换不能连续变化。取前三条射线为基，第四条在此基下的三个系数都非零：否则归一化截面中有三个五边形顶点共线。保持这四条射线迫使三个特征缩放相同，所以恒等分支只剩整体缩放。全部射线置换仅有限种，故其轨道不能遍历二维归一化内部，自对偶不蕴含齐次性。

## 2 自对偶与齐次合用，也还留下球模型

令

\[
L_{d+1}=\{(t,x)\in\mathbb R\times\mathbb R^d:t\ge\|x\|_2\},\qquad u(t,x)=t.
\]

归一化状态是单位d维球，纯态为单位球面。Cauchy–Schwarz不等式保证两个锥内向量内积非负；对任意锥外(t,x)，若x≠0，则(1,−x/‖x‖)给出负配对，若x=0则用(1,0)。所以该锥恰等于其数学对偶。

对内部目标r，令γ=(1−‖r‖²)⁻¹ᐟ²，取Lorentz型矩阵

\[
B_r=\begin{pmatrix}
\gamma&\gamma r^T\\
\gamma r&I+\frac{\gamma^2}{\gamma+1}rr^T
\end{pmatrix}.
\]

B_r保持t²−‖x‖²及未来锥，B_r⁻¹=B_{−r}。T_r=B_r/γ将(1,0)送到(1,r)，正比例与T_sT_r⁻¹使任意内部锥向量互达，故锥齐次。这是状态参数空间里的计算，没有由此推出物理时空或洛伦兹对称。

归一化可逆旋转(1,x)↦(1,Rx)中，SO(d)对d≥2的单位球面连续传递，故任意两个纯态可经连续可逆路径联系。上述锥亦是已知的spin factor：

\[
(t,x)\circ(s,y)=(ts+x\cdot y,\;ty+sx),
\]

给出其Jordan乘法。这里“spin factor”是代数名称，不是已经给模型确定了物理自旋。

## 3 四维球不是标准复量子位

取d=4。归一化态有4个连续参数，未归一化线性维数K=5。其不受限二元效应e=(a,b)要求

\[
\|b\|_2\le\min(a,1-a).
\]

若某效应在一个归一化态上概率为1，则a+‖b‖≥1，故a≥1/2。一个能完美区分k个态的测量有k个对应成功效应，且Σa_i=1，所以k≤2；相反方向的两纯态可由(1,±n)/2区分，因此容量恰为N=2。

它的(N,K)=(2,5)，而普通经典位、实量子位、复量子位、四元数量子位分别为(2,2)、(2,3)、(2,4)、(2,6)。四维球不是上述完整单体态空间之一；这不否认它可通过受限矩阵嵌入来表示。

| 单体例子 | 内积自对偶 | 齐次 | 纯态可逆传递 | 连续纯态传递 |
|:---|:---:|:---:|:---:|:---:|
| 非平凡经典单纯形 | 是 | 是 | 是 | 否 |
| 第181轮立方体 | 否 | 否 | 是 | 否 |
| 正五边形 | 是 | 否 | 是 | 否 |
| 四维球 | 是 | 是 | 是 | 是 |
| 通常实、复量子单体 | 是 | 是 | 是 | 是 |

因此上述单体性质不足以选择复量子；连续纯态转换虽排除了有限经典单纯形，却仍保留实模型及其他球模型。

## 4 文献提供一条更明确的条件桥梁

[Barnum、Ududec、van de Wetering，2023预印本](https://arxiv.org/html/2306.00362)给出：齐次性加纯态传递可推出自对偶及Jordan结构；再要求其复合框架中的每个系统都齐次、连续纯态传递且复合局部层析，定理7选择复矩阵态空间。本轮核对定理2、7及附录A.4，不重新证明所有技术引理。

这条路线使“自对偶”和第180轮预设的矩阵族有机会成为结论，但以新的强操作要求为代价。结论涉及状态锥的结构；具体可用效应与仪器权限仍要按框架声明，不能据此认定项目现有原语已经覆盖全部量子操作。

相较第180轮，这里最关键的新量词是：**单体、两体及后续每一级整体，都须满足同样的条件。** 对d=4球，局部层析要求K_AA=25。若进一步落实简单Jordan复合及秩乘法，整体秩为4；已知秩4简单Jordan候选只有实、复、四元数矩阵，维数分别10、16、28，没有25。spin factor秩为2，例外Albert代数秩为3，不能补这个缺口。这个计数解释该单体为何无法沿这条重建路线闭合。

这里简单性、秩乘法及其组合条件由文献路线中的其他步骤提供，不能只从单体K=5就无条件宣布一切组合不可能。也没有构造一个反驳完整重建定理的复合理论。

## 5 对原认知假说的实际推进

“每层保持原有认知结构，组合后也能继续作为主体”现在有了可检查的数学位置：它可能要求某些结构在递归组合后仍成立，而不是只要求单体长得相似。但究竟保持哪些结构仍需独立理由。

- 从“模型能预测检验”到自对偶：第181轮反例挡住了直接推论。
- 从“能调整模型”到内部态概率可逆互达：第182轮显示需增加过滤、权限及成本条件。
- 从“纯认知方式可切换”到连续可逆纯态传递：这是新增候选，有限标签切换并不满足连续版本。
- 从“组合要自洽”到各级局部层析：仍未推出；带辅助的关系审计可以更弱。

下一主任务收敛到一组具体条件的依赖审计：**同维辅助系统上的普遍系综实现、连续纯态可逆传递、各级局部层析**。先将第179轮的具体系综构造与“对每个系统、全部状态、同一个同维辅助类型”的普遍量词比较。文献的steering→齐次路线有不可约性和维数条件，须保留；单个Bell例子不够。再检查连续性及组合条件是否有独立认知依据。

以上三项可以作为候选公理方案提出，但当前没有被原认知原则全部推出。后续目标是找出可支持或否定这套具体方案的操作任务，减少只换名称、不断后移假设的研究。
