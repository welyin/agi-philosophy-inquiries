# 第1477轮准入　用质量与两个无符号分支比检验同一破缺方向

承接第1475轮的规范动力学问题，分别登记标量物质、共同规范动能、真空及普通轻子的质量来源。第1375、1474轮检验七重态及其额外双电荷态；1394轮用标准模型的辐射预测检验 $M_W$；1470轮利用产生振幅干涉检验 $hWW/hZZ$ 符号。本轮选可被区分的不同输入，一个给 $\tau$ 质量的双重态、一个 $Y=1$ 复三重态及任意规范单态。检验是否可以消掉所有中性混合角，独立限定125 GeV态在两种矢量与轻子测量中的相对响应。放入一个实三重态作竞争。新增公理零。

用 SLD 的电子极化角、CMS 直接 $M_W$ 与 LEP $M_Z$ 构造破缺比的工作范围。用 Run 1 的 $\tau\tau/ZZ$ 校准两个振幅符号分支，用不同事例的 CMS Run 2 $WW/ZZ$ 检验；同次拟合的 $\tau\tau/ZZ$ 另作比较。在两个实验的理论迁移与低能到极点匹配上分别登记预算。检验两侧符号、破坏等式所需增量、同一真空中可达的例子。既有研究未把这三个读数接到同一三重态的带符号标量导数。[实验记录](../1477/inputs.json) · [第1470轮](../1470/proof.md) · [第1474轮](../1474/proof.md)
