# 知行公理（最小集）

> 性质：知行哲学的第一份地基文件。**从哲学端、纯粹逻辑地立**，不依赖任何具体物理结论。
> 物理研究中的 F/U/C/P 等操作公理是"发现的脚手架 / 验证端"，不是本公理的来源；第 5 节给出对应关系，仅作回溯印证。
> 状态：v0.1 骨架，待迭代。

---

## 0. 立场

- 知行本体论不回答"物质第一还是精神第一"，而是**把这个问题取消**：最基本的范畴是"知—行"的关系操作本身。
- 凡存在，皆在"可被知、能起行"的关系中。
- 本文件只立最小公理，不展开全部推论；数学、物理、社会是往下的派生层。

---

## 1. 未定义原始词（不再往下定义，只指明用法）

| 原始词 | 用法 |
|---|---|
| 认知单元（主体） | 能进行操作的最小存在 |
| 状态 | 认知单元在某一时刻的确定情形 |
| 操作 | 引起状态变化的最小动作 |
| 关系 | 单元与单元、状态与状态之间的连接 |
| 表征 | 状态在认知单元内部的把握方式 |

这些是起点，不能再往下还原——否则要么循环，要么无穷后退。

## 2. 五条公理

### A1 存在即操作（本体论公理）
- **陈述**：凡存在者，必处于"可被知（可被某认知单元读取）"与"能起行（能与某事物发生作用、引起变化）"的关系之中；不存在既不可被任何单元把握、也不发生任何作用的存在。
- **大白话**：一个东西如果谁都感知不到、它也对什么都不产生影响，那它和不存在没有区别。
- **派生**：取消"物自体"式的独立本体；存在 = 知行关系中的项。

### A2 知行对偶（核心结构公理）
- **陈述**：知与行是同一操作不可分割的两面——知是"状态→表征"的读取，行是"表征→状态"的施加；**无行之知为空**（不产生任何可观测后果的"知"无内容），**无知之行为盲**（不基于任何状态读取的"行"无方向）。
- **大白话**：知道一件事却完全不影响你怎么动手，这"知道"是空的；闭着眼瞎动手、不看结果，这"动手"是盲的。
- **派生**：知行合一（本体论版，非伦理版）；唯物（抓行）、唯心（抓知）各对一半。

### A3 闭环更新（动力学 / 时间公理）
- **陈述**：知与行通过反馈闭环相互规定——行的结果被重新知（读取）→ 表征更新 → 引导下一次行；状态在每一轮闭环中被重新生成，不存在一劳永逸的终态。
- **大白话**：干一下、看一眼、改一下、再干——世界就是这样一轮轮变出来的，没有哪一轮是"定死的结局"。
- **派生**：时间箭头、动力学、反宿命论、反不可知论（只有"尚未达成"，没有"原则上不可知"）。

### A4 关系组合（整体论公理）
- **陈述**：认知单元通过关系组合成整体；整体状态由单元间关系构成，**不能还原为孤立单元的简单相加**——关系是构成性的。
- **大白话**：两个东西连在一起，会冒出单独看谁都没有的新性质；把它们拆开，这个性质就没了。
- **派生**：关系优先于实体；纠缠、整体大于部分、社会 / 制度作为关系整体。

### A5 有限可区分（确定性公理）
- **陈述**：任何可被确定把握的状态，都是有限的、可与其他状态区分的；纯粹无规定、不可区分的"存在"等于无。
- **大白话**：说不清、和什么都没区别的东西，就等于什么都没有。
- **派生**：有限性、信息的可度量、测量的前提、"无"的辩证法。

---

## 3. 五条公理的关系（一句话）

A1 立"存在"，A2 立"知行"，A3 立"更新（时间）"，A4 立"关系（整体）"，A5 立"有限（确定性）"。

它们是一个闭环，不是并列清单：A2 的知行在 A3 中更新、在 A4 中组合、受 A5 约束，整体落实 A1。

---

## 4. 可证伪 / 反驳条件（怎么算错）

| 公理 | 出现什么情况就算错 |
|---|---|
| A1 | 存在一个"原则上不可被任何认知把握、也不产生任何作用"却真实存在的东西 |
| A2 | "完全不影响行动的知"或"完全不依赖读取的行"能稳定成立 |
| A3 | 世界存在一个不再更新、写死的终态（宿命论成立） |
| A4 | 一切整体性质都能被完全还原为孤立单元 |
| A5 | 存在无限、不可区分却有确定内容的状态 |

---

## 5. 与物理操作公理的脚手架对应（仅作回溯印证，不是来源）

| 哲学公理 | 物理 F/U/C/P 脚手架 | 已复现的物理 |
|---|---|---|
| A5 有限可区分 | F 有限维因果凸框架 | 复量子状态锥 |
| A2 知行对偶 | C 连续可逆纯态传递；U 系综导引 | Born 规则、Schrödinger 形式 |
| A4 关系组合 | P 本地校准可迁移 | 三维关系空间、纠缠 |
| A3 闭环更新 | 动力学 / 反馈条款 | SR 动力学、（有效）GR |
| A1 存在即操作 | 整体操作框架 | 观测者内化 |

**纪律**：物理目前只完成"相容性 ＋ 条件性充分性（一致性恢复）"，必要性、新颖预测、实验认证空缺；那些是物理端的任务，本哲学公理不冒领。
