# 00 知行哲学总纲（体系总览）

> 这是知行哲学的入口地图。一句话：**"存在即操作，知与行对偶，在关系整体中持续有限区分、闭环更新、无终态"——一切哲学立场都是这个闭环上某个环节的绝对化，一切学科都从这个闭环派生。**

---

## 1. 立场：哲学是什么

- 哲学是**纯粹的精神研究**：用逻辑构建的思维大厦，出发点和方法内在，不依赖物理结论。
- 但区分两种"纯粹"：
  - **纯粹的是方法/创造**（门内不夹物理）；
  - **不是对象/真理认证**（门外靠物理与工程验收）。
- 即"**门内纯粹，门外验收**"。

## 2. 起点：可理解性

- 不从"物质"或"精神"出发，而从"一个世界要能被理解，必须满足什么条件"出发。
- 这是先验论证的入口，不可绕过。

## 3. 五条公理（最小集）

| 编号 | 公理 | 一句话 |
| --- | --- | --- |
| A1 | 存在即操作 | 凡能被理解、能进入话语的，都已在一个操作中 |
| A2 | 知行对偶 | 无行之知为空，无知之行为盲 |
| A3 | 闭环更新 | 知在闭环中持续更新，无终态 |
| A4 | 关系组合 | 关系是构成性的，整体不可还原为孤立个体 |
| A5 | 有限可区分 | 凡能被理解的，必能在有限操作中被区分；无规定即无 |

## 4. 核心结构：知行闭环

```
行（操作）→ 产生可区分状态
   ↑                ↓
指导下一轮      知（读取、组织为表征）
   ↑                ↓
   └──── 闭环更新（无终态）────┘
```

## 5. 统摄：所有哲学立场都是闭环环节的绝对化

- 总机制：**任何立场，都是在知行闭环上选取某个环节、某个视角并把它绝对化。**
- 已统摄 54 个立场/专题（含 60 余种具体"论"，三判据逐项可复核，详见 02 文件）：

| 大类（绝对化的环节） | 立场 |
| --- | --- |
| 一、知端（观念论） | 唯心、理性主义、苏格拉底、柏拉图、亚里士多德、康德、胡塞尔、分析哲学、唯识、陆王、属性二元/泛心 |
| 二、行端（实在论） | 唯物、马克思、法家、行为主义、存在主义、兵家、操作/工具主义、晚期希腊、同一/取消、机械/还原 |
| 三、更新（过程/流变） | 黑格尔、道家、过程哲学、叔本华、尼采、禅宗、科学哲学、京都学派、魏晋玄学 |
| 四、关系（整体/结构） | 儒家、结构主义、华严、社群主义、整体/突现、阴阳家、解释学、现代新儒家、西方法学、社会契约/罗尔斯、中观、批判理论、后结构、中世纪 |
| 五、区分（经验/个别） | 经验论、唯名论、程朱、名家、逻辑原子、经验批判、义务论 |
| 六、闭环整体（知行合一） | 实用主义、墨家、功能主义、具身/延展、相容论、王阳明 |
| 七、自我否定（试金石） | 怀疑论、相对主义、虚无主义、不可知论、唯我论、宿命论、副现象论 |

- 统一裁定：
  - 西方各立一端、未统一为开放闭环；
  - 东方直触知行、甚至说出"知行合一"，但用在向内修养、未走向向外工程；
  - 墨家最接近"知行工程"（逻辑＋科学＋技术），却零散、中绝；
  - 知行本体论补的是"**可数学推导、可工程验证、无终态的完整闭环**"。

## 6. 向下派生（指针）

- 数学/逻辑：闭环中"关系组合（A4）"与"有限区分（A5）"的形式化；
- 物理：知行闭环在"被作用对象"侧的普遍结构（F/U/C/P 为其物理端脚手架）；
- 社会/法：闭环在"多主体共识—规则—执行"层的展开；
- 工程：闭环"行"端的物化与验收。

## 7. 边界：三方分工

| 领域 | 回答 | 不回答 |
| --- | --- | --- |
| 哲学（先验） | 任何可理解世界的条件 | 现实必要性、具体物理 |
| 物理（实验） | 现实世界为何如此、必要性、可区分预测 | 先验奠基 |
| 工程（实现） | 造出来、物化验证 | 纯形式真理 |
