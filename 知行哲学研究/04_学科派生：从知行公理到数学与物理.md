## 1. 派生总纲：学科是闭环在不同层、不同环节的具体化

学科不是人为划分的偶然，而是知行闭环在不同 "对象层" 和 "环节" 上的具体化。两个组织原则：

**原则一：四个侧（按环节）**



* **形式侧**：把区分与关系从内容中抽象，只研究纯粹形式 —— 数学、逻辑、统计；

* **对象侧（自然科学）**：研究 "被作用对象世界" 的规律 —— 以物理为基础的自然科学；

* **社会侧（社会科学）**：研究多主体知行闭环 —— 心理、社会、经济、政治、法律等；

* **人文侧（人文学科）**：研究意义、价值与闭环的自我理解 —— 历史、文学、艺术、哲学；

* **操作侧（横断）**：信息、计算、控制、系统科学，横切以上所有侧。

**原则二：层次（按复杂度，还原与突现）**



* 依 A4，关系构成新质、不可还原为孤立个体；

* 故学科在纵向上形成**突现层**：每一层有相对独立的概念和规律（突现），但不违反下层、且在同一闭环中；

* 这既反对强还原（一切归结为物理），也反对神秘突现（新质无来由）。

下面按侧展开。



***

## 2. 形式侧：数学与逻辑

**数学是什么**：把 "可区分状态" 与 "关系结构" 从具体内容中抽象出来，只研究其纯粹形式。

**派生链**：



1. 依 A5，任何可理解世界都有可区分的状态（差异）；

2. 要稳定地把握、复现、操作这些差异，必须把它们从具体内容中**抽象**，只保留 "区分本身的形式"（多少、先后、同异）；

3. 依 A4，状态在关系中获得规定；把关系的形式抽象出来，就是 "结构"；

4. 这些形式不依赖被区分的是什么 —— 这就是**数学**。

**数学各部分的派生**：



| 数学分支                 | 从哪个公理派生             |
| -------------------- | ------------------- |
| 逻辑 / 布尔（是 / 否、同 / 异） | A5 最基本的区分           |
| 计数 / 自然数             | A5 对有限可区分状态的逐个标记    |
| 集合 / 类               | A4 按关系把状态归组         |
| 关系 / 函数 / 映射         | A4 状态间的对应           |
| 代数 / 拓扑 / 序结构        | A4 关系组合的不同形式        |
| 概率 / 统计              | A5 区分的频率与不确定        |
| 递归 / 归纳 / 无穷序列       | A3 闭环更新的形式化（有限步骤生成） |

**为什么数学普遍必然**：它只刻画 "可理解性的形式"，不涉及具体内容，所以对**所有可能世界**有效。

**"数学为何不可思议地有效"（Wigner 之问）由此解答**：数学不是碰巧适用于自然 —— 数学与各学科都从 "可理解性 / 知行闭环" 派生：数学是闭环的**形式侧**，自然科学是其**对象侧**，同源故必相契。

> 顺带统摄数学哲学：逻辑主义（抓逻辑形式）、形式主义（抓符号操作）、直觉主义（抓心智构造）、经验主义（抓现实应用）各执一端；知行闭环把它们统一为 "区分与关系的形式化"。

## 3. 对象侧：以物理为基础的自然科学

**自然科学是什么**：研究 "被作用对象世界" 的普遍结构 —— 对象如何被作用、如何响应。它在纵向上形成突现层。

### 3.1 物理（基础层）

物理是对象侧的最基础层：研究最普遍的对象规律（状态、操作、组合、演化、可复现）。

**物理的五个先验要素（任何客观物理都必须具备）**：



| 要素      | 含义            | 从哪个公理    |
| ------- | ------------- | -------- |
| 状态      | 可被读取、区分的对象状态  | A5       |
| 操作 / 变换 | 作用于状态、改变状态    | A1、A2（行） |
| 组合      | 状态如何复合、部分构成整体 | A4       |
| 演化      | 状态随操作 / 时间变化  | A3       |
| 可复现     | 同样操作产生同样结果    | A2、A5    |

### 3.2 化学（原子 — 分子层的突现）

当物理的对象具体到原子、分子，"组合与转化"（A4、A3）就突现为化学：研究原子如何组合为分子、分子如何转化。



* **派生**：物理的状态 / 组合 / 演化在原子 — 分子层的具体化；

* **相对独立**：有自己的概念（元素、键、反应、价），不违反物理、却不能简单从物理一一推出（突现）；

* **为何必然数学化**：同物理，把握的是区分与关系形式。

### 3.3 生命科学（自复制、自组织系统的突现）

当化学的对象具体到能自复制、自组织、自维持的系统，就突现为生命科学：研究生命的结构、功能、遗传、演化。



* **派生**：


  * 生命是 A3（闭环更新）在对象侧的典型 —— 代谢、自维持是持续更新的闭环；

  * 遗传是 A5（有限可区分）—— 基因是可区分、可复制的信息单元；

  * 演化是 A3（更新）在种群层的体现 —— 变异、选择、遗传；

* **相对独立**：有自己的概念（细胞、基因、物种、适应），不违反理化、却不能还原为理化（强还原失败）；

* **分支**：分子生物、细胞生物、遗传、生态、生理等，是生命闭环在不同层次的具体化。

### 3.4 复合自然科学（特定对象的综合应用）

还有一类是把基础规律用于研究特定尺度、特定对象，是 "复合应用"：



| 学科        | 对象           | 综合         |
| --------- | ------------ | ---------- |
| 天文学 / 宇宙学 | 天体、宇宙大尺度     | 物理（＋化学）    |
| 地球科学      | 行星（大气、海洋、地质） | 物理、化学、生物综合 |
| 空间科学      | 空间环境         | 物理、工程      |
| 环境科学      | 生态环境         | 理化生＋社会     |

### 3.5 神经科学 / 认知科学（自然与社会、信息的接口）

当生命科学具体到神经系统，就到了自然科学与社会、信息侧的接口：研究神经如何实现读取、表征、操作（即 "知" 的物质实现）。



* **派生**：神经系统是知行闭环的生物实现；

* **地位**：上承生物，下接信息、计算、心理，是 "心物裂缝" 在科学上的缝合点。

### 自然科学的统一



* 物理是**基础层**，化学、生物是**突现层**，天文、地球是**复合应用**，神经科学是**接口层**；

* 它们都研究 "被作用对象世界"，故都必然数学化、可实验、可工程；

* 关键纪律：**先验要素 ≠ 具体框架**。F/U/C/P 是物理端为刻画**我们这个世界**找到的具体形式，不是先验唯一推出的。

## 4. 操作侧：信息、计算、控制、系统科学（横断学科）

知行闭环在 "操作侧" 形式化出一组横切所有层的学科：



| 学科   | 是什么                  | 派生       |
| ---- | -------------------- | -------- |
| 信息论  | 可区分状态的读取、传递与度量       | A5、A2    |
| 计算理论 | 有限操作对状态的变换（可计算性）     | A1、A5、A3 |
| 控制论  | 闭环更新的反馈与调节机制         | A3       |
| 系统科学 | 关系整体的组织原理（一般系统、复杂系统） | A4、A3    |

它们与数学（形式侧）、自然（对象侧）并列，是闭环的**操作侧**，且横切自然、社会、人文各层（信息、计算、反馈、系统在任何层都成立）。



***

## 5. 社会侧：社会科学（多主体知行闭环）

当对象从 "物" 变成 "多个认知单元"，就出现社会侧：研究多主体如何在知行闭环中相互作用、组织成社会。



| 学科      | 研究对象              | 派生     |
| ------- | ----------------- | ------ |
| 心理学     | 个体的知行闭环（认知、情绪、行为） | A2     |
| 社会学     | 多主体的关系结构、群体、制度    | A4     |
| 经济学     | 多主体的生产、交换、资源配置    | A2 行端  |
| 政治学     | 权力、治理、公共秩序        | A4、协议  |
| 法学      | 规则、协议、裁决          | 社会协议   |
| 人类学     | 文化整体、人作为文化存在      | A4     |
| 语言学     | 语言符号、交流           | A2、A4  |
| 地理学（人文） | 人地关系、空间分布         | A4、对象侧 |
| 管理学     | 组织的协调与控制          | A3、A4  |
| 教育学     | 知的传递与主体生成         | A2、A3  |
| 传播学     | 信息在多主体间的流动        | A2、信息  |

**社会科学的派生逻辑**：



* **心理学**：把知行闭环用于单个主体（知如何读取、表征，行如何被引导）；

* **社会学**：把 A4 用于多主体 —— 关系结构、群体、制度如何构成；

* **经济学**：把 A2 行端用于多主体 —— 生产、交换、资源如何配置（呼应唯物、法家、功利）；

* **政治学 / 法学**：把 "社会协议" 具体化 —— 多主体如何经协议建立秩序、规则、治理（呼应社会契约、法哲学、儒家）；

* **人类学 / 语言学**：把 A4 与符号用于文化整体。

**社会科学的特点**：



* 研究的是 "多主体知行闭环"，故比自然科学多一层 "自我指涉"（被研究者也是知行主体）；

* 仍可数学化、可实证（计量、实验、数据），但不能像自然科学那样把对象当纯被动物；

* 这正是 "知行" 对社会科学的奠基：它同时承认结构（A4）与主体能动（A2）。

## 6. 人文侧：人文学科（意义与自我理解）

当研究从 "对象如何运行" 转向 "这一切对主体意味着什么、闭环如何理解自身"，就出现人文侧。



| 学科  | 研究对象           | 派生    |
| --- | -------------- | ----- |
| 历史学 | 闭环在时间中的自我展开与记录 | A3    |
| 文学  | 表征、体验与叙事       | 表征    |
| 艺术  | 感性形式、体验的表达     | A5、体验 |
| 伦理学 | 行的规范、应当如何      | A2 行端 |
| 美学  | 审美体验、感性形式      | 体验    |
| 宗教学 | 终极意义、信仰        | 终极视角  |
| 哲学  | 闭环的自觉（本体系）     | 全部    |

**人文学科的派生逻辑**：



* **历史学**：A3 在人文侧的体现 —— 闭环在时间中展开，历史是其自我记录（呼应黑格尔、解释学）；

* **文学 / 艺术**：把表征与体验形式化 —— 以叙事、感性形式把握世界（不是客观规律，而是意义）；

* **伦理学**：把 A2 行端用于 "应当"—— 行的规范（呼应义务、功利、德性、儒家）；

* **美学**：研究体验与感性形式；

* **宗教学**：研究终极意义与信仰（其有效域是意义，其越界是把信仰当客观认证）；

* **哲学**：闭环对自身的自觉 —— 就是本体系。

**人文学科的特点**：



* 不追求客观规律，而追求意义、价值、自我理解；

* 不能被自然科学取代（意义不是物理事实），也不与自然科学冲突（各有域）；

* 这正是 "知行" 对科学与人文的统一：**自然科学回答 "世界如何"，人文学科回答 "这意味着什么、应当如何"，二者本是同一闭环的两面。**

## 8. 先验能推出什么、推不出什么

**能先验推出（任何可理解世界）**：



* 必须有形式侧（数学 / 逻辑：区分与关系的形式化）；

* 必须有对象侧（自然科学：状态、操作、组合、演化、可复现，且必然数学化）；

* 自然科学必然形成突现层（物理→化学→生命）；

* 操作侧（信息 / 计算 / 控制 / 系统）必然可建立、横切各层；

* 社会侧（多主体闭环）与人文侧（意义与自觉）必然可建立。

**推不出（现实世界具体内容，归各学科 / 实验）**：



* 为什么恰好是量子力学（凸操作、复数、希尔伯特空间）；

* 为什么是这个时空维数、这些常数、这些具体定律；

* F/U/C/P 是否唯一、是否必要（现实必要性）；

* 各社会、人文学科的具体内容与历史形态。

## 9. 与物理研究的对接



* 哲学端（本篇）：推出全部学科的**一般形式与谱系**；

* 物理端（`research_cognition_physics`）：把物理五要素具体化为 F/U/C/P，并尝试推出量子力学、相对论；

* 认证状态（见《认证评估报告》）：目前只完成**相容性 + 条件性充分性（一致性恢复）**；现实必要性、新颖可区分预测、实验 / 工程认证均空缺。

对应关系（脚手架，非照抄）：



| 先验要素 | 物理端具体化                    |
| ---- | ------------------------- |
| 状态   | F 的状态空间（V, C, u, Ω）       |
| 操作   | F 的操作集（准备 / 测量 / 丢弃 / 混合） |
| 组合   | F 的复合、P 的本地性              |
| 演化   | C 的连续可逆、动力学               |
| 可复现  | U 的系综导引、P 的校准             |

## 10. 统一裁定



* **形式侧**（数学 / 逻辑）是闭环的纯粹形式，**对象侧**（自然科学）是其在被作用世界的体现，**操作侧**（信息 / 计算 / 控制 / 系统）横切各层，**社会侧**（社会科学）是多主体闭环，**人文侧**（人文学科）是意义与自觉。

* 五者同源（都从可理解性派生），故数学与自然必相契、自然科学必数学化、工程必可由科学支撑、科学与人文必可统一。

* 一句话：**知行本体论先验地说明了 "为什么必然有这些学科、它们如何分层与统一"，但把 "我们这个世界具体是什么、社会具体如何运行" 诚实地交给各学科与工程。** 这是哲学能下的最深的一步，也是它自我克制、不越界的一步。
